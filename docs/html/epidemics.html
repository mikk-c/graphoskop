Epidemics

Epidemics: models of how something (a disease, a piece of information, a behavior) spreads from node to node through the edges of a network.

Nodes are in compartments (states), and move between them by contagion from their neighbors or spontaneously. In simple contagion (graphoskop.epidemics.simple_contagion), one infected neighbor is enough to infect a node: SI, SIS and SIR models. In complex contagion (graphoskop.epidemics.complex_contagion), the number of infected neighbors matters: one chance of infection per infected neighbor, or a threshold on their count or share.

Simple contagion

Simple contagion: compartmental models of epidemics where one infected neighbor is enough to infect a node (as opposed to complex contagion, which needs reinforcement from several neighbors). Every node is in a compartment, its state:

  • si_model(): Susceptible (S) or Infected (I); infected nodes stay infected forever;

  • sis_model(): infected nodes recover with probability mu per step and become susceptible again;

  • sir_model(): infected nodes recover with probability mu per step and become Removed (R): they cannot be infected again, nor infect.

Simulations run in discrete, synchronous time steps. At each step, every susceptible node with at least one infected neighbor becomes infected with probability beta, with one draw per node per step, whatever the number of its infected neighbors; at the same time every node infected at the start of the step recovers with probability mu. A node infected in a step can recover from the next one. In directed networks the infection follows the direction of the edges, from source to target; undirected edges carry it both ways. Edge weights, parallel edges and self loops do not matter. In multilayer networks the models run on the supra-graph: copies are nodes, and the infection also spreads along couplings and other interlayer edges.

The infection starts from seed nodes, chosen at random or from a ranking of the nodes (e.g. a centrality), and many independent runs are simulated in parallel and averaged. After the simulation, the state of every node at the end of the last run is stored as a qualitative node attribute ("S", "I" or "R"), from which a later simulation can start, e.g. to follow an epidemic one step at a time.

All the models can immunize nodes at step 0 (immunize): immunized nodes are never infected, so they never infect either. They are given as node ids, or as a number of nodes (a fraction of them if below 1) chosen by strategy:

  • "random": nodes drawn uniformly at random, anew in every run;

  • "friend_of_random": acquaintance immunization (Cohen, Havlin and ben-Avraham, 2003): a node drawn uniformly at random names one of its neighbors (out-neighbors in directed networks), drawn uniformly, which is immunized; drawn again until enough distinct nodes are immunized, anew in every run. By the friendship paradox, neighbors of random nodes have more connections than random nodes, so this immunizes hubs without knowing the network;

  • node values, such as a centrality or degree() with distribution = None (vector, dictionary or pandas.Series by node id, or the name of a numeric node attribute): the nodes with the largest values (targeted immunization).

Seeds are drawn among the nodes that are not immunized. Immunized nodes are in none of the states S, I and R of the table: S + I + R is 1 minus the share of immunized nodes. In the stored states they are "V" (vaccinated), which every model reads back when resuming. When resuming, only susceptible nodes can be immunized (infected and removed nodes given as ids are skipped), so a vaccination campaign can start in the middle of an epidemic.

import graphoskop as gsk

net = gsk.load_network("contacts.tsv")
si = gsk.si_model(net, beta = 0.1, seeds = 5, runs = 1000, seed = 1)   # random seeds, component 0
si.loc[10]                                                       # S, I and their intervals at step 10
sis = gsk.sis_model(net, beta = 0.1, mu = 0.05, seeds = 5)       # stops at the endemic plateau
sir = gsk.sir_model(net, beta = 0.2, mu = 0.1, seeds = 5)
sir[["S", "I", "R"]].plot()

k = gsk.degree(net, distribution = None, component = 0)
sir = gsk.sir_model(net, 0.2, 0.1, 5, ranking = k)               # the 5 hubs
sir = gsk.sir_model(net, 0.2, 0.1, 5, ranking = k, selection = "weighted")   # drawn proportionally
sir = gsk.sir_model(net, 0.2, 0.1, 0.01, ranking = "age")        # 1% of the nodes: the oldest

# one step at a time: the states are stored in the qualitative node attribute "state"
gsk.sir_model(net, 0.2, 0.1, 5, runs = 1, max_steps = 0)         # seeds infected, step 0
net.qualitative_node_attributes                                  # [..., "state"]
for step in range(20):
   gsk.sir_model(net, 0.2, 0.1, runs = 1, max_steps = 1, resume = True)
   states = net.get_node_attribute("state")                     # "S", "I" or "R" for each node

# immunization: 5% of the nodes, never infected ("V" in the stored states)
sir = gsk.sir_model(net, 0.2, 0.1, 5, immunize = 0.05)                                 # at random
sir = gsk.sir_model(net, 0.2, 0.1, 5, immunize = 0.05, strategy = "friend_of_random")  # acquaintances
sir = gsk.sir_model(net, 0.2, 0.1, 5, immunize = 0.05, strategy = k)                   # the hubs
sir = gsk.sir_model(net, 0.2, 0.1, 5, immunize = ["alice", "bob"])                     # these nodes
# vaccinating in the middle of an epidemic, one step at a time
gsk.sir_model(net, 0.2, 0.1, runs = 1, max_steps = 1, resume = True, immunize = 10, strategy = "friend_of_random")

net = gsk.load_network("contacts.tsv", device = "cuda")
sir = gsk.sir_model(net, 0.2, 0.1, 5)                           # runs batched on the GPU

Performance

With engine = "numba", each CPU thread simulates whole runs and only touches the nodes that can change and the edges of the nodes that changed, and runs scale linearly with the number of threads. With engine = "torch", the runs of a batch are simulated together on the device of the network; it is the default on a GPU, where it is the faster engine. SI model

graphoskop.si_model(net, beta, seeds=1, ranking=None, selection='top', runs=100, max_steps=1000, component=0, seed=None, engine=None, batch=None, attribute='state', resume=False, immunize=None, strategy='random')

Simulate the SI (Susceptible-Infected) model, and return the fraction of nodes in each state at every time step, averaged over independent runs.

At step 0 the seed nodes are infected, all the other nodes are susceptible. At every following step, each susceptible node with at least one infected neighbor becomes infected with probability beta (one draw per node and step, whatever the number of its infected neighbors; see the module description).

A run stops when nothing can change any more, or after max_steps steps. In the SI model, that is when no susceptible node has an infected neighbor, so that the infection has reached every node it can reach (all the nodes of an undirected component; in directed networks, the nodes reachable from the seeds). A finished run keeps its final value until the last run stops, so the table has one row per step up to the longest run.

Seeds are drawn anew for every run, among the nodes considered:

  • ranking = None: seeds nodes uniformly at random;

  • selection = "top": the seeds nodes with the largest ranking values, the same in every run (ties are broken by node order; NaN counts as the smallest value);

  • selection = "weighted": seeds nodes drawn without replacement with probability proportional to ranking (which must be non negative; NaN counts as 0).

ranking is any vector of node values, e.g. the output of a centrality or of degree() with distribution = None, on the same component, or the list of vectors of all components (as returned with component = None); a dictionary or pandas.Series from node id to value; or the name of a numeric node attribute.

After the simulation, the state of every node at the end of the last run ("S" or "I") is stored in the qualitative node attribute attribute, on the nodes considered (other components get NaN if the attribute is new). Like every qualitative attribute, it is listed in qualitative_node_attributes (not in node_attributes, which lists numeric attributes, stored in the node_attr tensors), and is read with net.get_node_attribute(attribute). With resume = True the seeds are not drawn: every run starts from the states in attribute (missing values count as susceptible). One step at a time, an epidemic is followed by running runs = 1, max_steps = 1, resume = True again and again.

The runs are independent, and are simulated in parallel. With engine = "numba" each CPU thread simulates whole runs, touching only the nodes that can change and the edges of the nodes that changed. With engine = "torch" the runs of a batch are simulated together, as vector operations on the device of the network; batch limits the number of runs at once (by default, so that batch times the number of nodes is at most \(2^{27}\)). By default, the torch engine is used for networks on a GPU, the Numba engine otherwise. Random numbers come from seed: with the Numba engine results are the same whatever the number of threads; the two engines give different draws of the same model.

The confidence interval of the mean at each step is the 95% Student’s t interval, from the standard deviation across runs (NaN with a single run).

Parameters:

  • net – A Network.

  • beta – Infection probability per step of a susceptible node with infected neighbors, in (0, 1].

  • seeds – Number of seed nodes, or a fraction of the nodes if below 1 (at least one node).

  • ranking – Node values used to choose the seeds, or None for random seeds.

  • selection – "top" or "weighted", how seeds are chosen from ranking.

  • runs – Number of independent runs.

  • max_steps – Largest number of steps of a run.

  • component – Index of the component (0 is the largest), or None for the whole network (seeds anywhere; the infection cannot leave the components of the seeds).

  • seed – Seed of the random numbers, or None for a random seed.

  • engine – "numba" (CPU threads), "torch" (device of the network), or None.

  • batch – With the torch engine, the number of runs simulated at once, or None.

  • attribute – Name of the node attribute holding the states, or None not to store them.

  • resume – Whether to start from the states in attribute instead of seeds.

  • immunize – Nodes immunized at step 0, never infected (see simple_contagion): a number of nodes (a fraction of them if below 1), chosen by strategy, or the node ids themselves; None for none.

  • strategy – With a number of nodes to immunize: "random", "friend_of_random", or node values (vector, dictionary or pandas.Series, name of a numeric node attribute) whose largest ones are immunized. Ignored with node ids.

Returns:

pandas.DataFrame indexed by step (0 is the start), with columns S and I (mean fraction of nodes in each state), S_low, S_high, I_low and I_high (confidence intervals).

Raises:

ValueError – If a parameter is not valid, if ranking does not give one value per node, if it has negative values with selection = "weighted", if fewer nodes than seeds have a positive value, or, with resume, if attribute is not a qualitative node attribute or has a value that is not a state of the model.

Example:

import graphoskop as gsk

net = gsk.load_network("contacts.tsv")
si = gsk.si_model(net, beta = 0.1, seeds = 5, runs = 1000, seed = 1)
si.plot(y = "I")                                                # epidemic curve
net.get_node_attribute("state")                                 # "S" or "I", end of the last run
hubs = gsk.si_model(net, 0.1, 5, ranking = gsk.degree(net, distribution = None))
pr = gsk.pagerank(net, component = None)
si = gsk.si_model(net, 0.1, 5, ranking = pr, selection = "weighted", component = None)

gsk.si_model(net, 0.1, 5, runs = 1, max_steps = 0)              # seeds only, step 0
for step in range(10):                                          # then one step at a time
   gsk.si_model(net, 0.1, runs = 1, max_steps = 1, resume = True)

SIS model

graphoskop.sis_model(net, beta, mu, seeds=1, ranking=None, selection='top', runs=100, max_steps=1000, component=0, seed=None, engine=None, batch=None, attribute='state', resume=False, window=100, tolerance=0.01, immunize=None, strategy='random')

Simulate the SIS (Susceptible-Infected-Susceptible) model, and return the fraction of nodes in each state at every time step, averaged over independent runs.

As si_model() (seeds, engines, stored states and resuming work the same way), but at every step each node infected at the start of the step recovers with probability mu and becomes susceptible again, at the same time as the infections.

A run stops when no node is infected, after max_steps steps, or when the infection has become endemic: the number of infected nodes fluctuates around a plateau. A run is at the plateau when the mean number of infected nodes over the last window steps differs by at most tolerance (relative) from the mean over the window steps before. From then on, the run counts with its mean over the last window steps, the estimate of its endemic level, and the stored states are those of the step where it stopped. In small networks the fluctuations can keep the test from passing (the runs then last max_steps steps): a larger window or tolerance helps. Near the epidemic threshold the number of infected nodes drifts slowly, and a small tolerance avoids stopping too early. window = None turns the test off.

Parameters:

  • net – A Network.

  • beta – Infection probability per step, in (0, 1].

  • mu – Recovery probability per step, in (0, 1].

  • seeds – Number of seed nodes, or a fraction of the nodes if below 1.

  • ranking – Node values used to choose the seeds, or None for random seeds.

  • selection – "top" or "weighted".

  • runs – Number of independent runs.

  • max_steps – Largest number of steps of a run.

  • component – Index of the component, or None for the whole network.

  • seed – Seed of the random numbers, or None.

  • engine – "numba", "torch" or None.

  • batch – With the torch engine, the number of runs simulated at once, or None.

  • attribute – Name of the node attribute holding the states ("S" or "I"), or None.

  • resume – Whether to start from the states in attribute instead of seeds.

  • window – Number of steps of each of the two windows compared by the plateau test, or None not to stop at the plateau.

  • tolerance – Largest relative difference between the means of the two windows at the plateau.

  • immunize – Nodes immunized at step 0, never infected (see simple_contagion): a number of nodes (a fraction of them if below 1), chosen by strategy, or the node ids themselves; None for none.

  • strategy – With a number of nodes to immunize: "random", "friend_of_random", or node values (vector, dictionary or pandas.Series, name of a numeric node attribute) whose largest ones are immunized. Ignored with node ids.

Returns:

pandas.DataFrame indexed by step, with columns S, S_low, S_high, I, I_low and I_high.

Raises:

ValueError – As si_model(), or if mu, window or tolerance is not valid.

Example:

import graphoskop as gsk

net = gsk.load_network("contacts.tsv")
sis = gsk.sis_model(net, beta = 0.1, mu = 0.05, seeds = 5)     # runs stop at the plateau
sis["I"].iloc[-1]                                               # endemic level
sis = gsk.sis_model(net, 0.1, 0.05, 5, window = None, max_steps = 2000)   # no plateau test

  • batch – With the torch engine, the number of runs simulated at once, or None.

  • attribute – Name of the node attribute holding the states ("S", "I" or "R"), or None.

  • resume – Whether to start from the states in attribute instead of seeds.

ValueError – As si_model(), or if mu is not valid.

Example:

import graphoskop as gsk

net = gsk.load_network("contacts.tsv")
sir = gsk.sir_model(net, beta = 0.2, mu = 0.1, seeds = 5, runs = 1000)
sir["R"].iloc[-1]                                               # final size of the epidemic
sir["I"].idxmax()                                               # step of the peak

Complex contagion

Complex contagion: compartmental models of epidemics where the number of infected neighbors of a susceptible node matters for its infection (reinforcement), as for behaviors and ideas that people adopt only after seeing several of their contacts adopt them. Recoveries are as in simple contagion: in the SIS and SIR models every infected node recovers with probability mu per step, whatever its neighbors.

Five kinds of reinforcement decide the infection of a susceptible node with \(c\) infected neighbors (in-neighbors in directed networks):

  • "classical": every infected neighbor tries to infect the node independently, with probability beta, so the node is infected with probability \(1 - (1 - \beta)^c\) (one coin flip per infected neighbor, instead of one in simple contagion, so a small beta spreads much more where nodes have many infected neighbors);

  • "threshold": the node can be infected only if \(c \ge k\), an absolute threshold, as in the threshold model of Granovetter (1978) in the form used for complex contagion by Centola and Macy (2007): hubs, with many neighbors, reach the threshold easily;

  • "cascade": the node can be infected only if \(c \ge \phi d\), a fraction of its in-degree \(d\), as in the cascade model of Watts (2002): hubs, with a large denominator, rarely reach the threshold;

  • "independent": the independent cascade model of Kempe, Kleinberg and Tardos (2003). When a node \(u\) is infected, it makes one attempt to infect each of its susceptible out-neighbors \(v\), at the next step, which succeeds with probability \(p_{uv}\); if it fails, \(u\) never tries \(v\) again (until \(u\) is infected anew, in SIS). The probability depends on both the origin and the target of the attempt, through a table of probabilities per pair of nodes, given as beta. Unlike "classical", where infected neighbors try again at every step, each edge carries one attempt per infection;

  • "decreasing": the decreasing cascade model of Kempe, Kleinberg and Tardos (2005), with one attempt per edge as in the independent cascade, but every failed attempt on \(v\) makes the next ones less likely: an attempt after \(f\) failed ones succeeds with probability \(p_{uv} \delta^f\), with decay \(\delta \in (0, 1]\) (\(\delta = 1\) is the independent cascade). Simultaneous attempts on a node count as made one after the other (in an arbitrary order, as in the original model); the count of failures restarts when the node is infected.

With the thresholds met, the node is infected with probability beta (beta = 1 gives the deterministic models of Granovetter and Watts). In the cascades, beta is the table of probabilities \(p_{uv}\) of the attempts from origin \(u\) to target \(v\): one probability for all edges, the name of a numeric edge attribute, a matrix (NumPy array, tensor or SciPy sparse matrix, rows for origins and columns for targets, indexed in the node order of the nodes considered, e.g. net.node_ids[0] for component 0), or a pandas.DataFrame with origin, target and probability in its first three columns (pairs not listed get 0). Only the pairs joined by an edge matter, and in undirected networks the two directions of an edge can have different probabilities. Independent cascades on SI are exactly the original model, in which infected (active) nodes stay infected; with SIR the spread is the same, and the infected nodes are removed at rate mu.

In the cascades every infection has one origin, the node whose attempt succeeded, so with forest = True the models also return who infected whom in the last run, as a directed Network: an edge from origin to target for every infection, with the step of the infection as edge attribute step, and the infected nodes (seeds included, even those that infected nobody) with their node attributes. In SI and SIR every node is infected at most once, so this is a forest: one tree per seed, rooted at it, and each tree is a weakly connected component (forest.components, connected_components_nodes()). In SIS a node can be infected again after recovering, and every infection is an edge, so the network can have parallel edges and cycles. When several attempts on a node succeed at the same step, its origin is the first of them in the order of the attempts. Thresholds are one value for all nodes, or one per node (a vector, a dictionary or pandas.Series from node id to value, or the name of a numeric node attribute), so that, e.g., heterogeneous thresholds can be drawn from a distribution. Degrees count edges: parallel edges count several times, and a self loop counts in the in-degree (but never as an infected neighbor of a susceptible node).

Everything else (time steps, seeds, runs, engines, stored states, resuming, the plateau of SIS) is as in simple_contagion. A seed node of a threshold model is infected whatever its neighbors; a node whose threshold is above its in-degree can only be infected as a seed.

import graphoskop as gsk

net = gsk.load_network("contacts.tsv")
si = gsk.complex_si_model(net, 0.02, "classical", seeds = 5)       # one coin flip per infected neighbor
si = gsk.complex_si_model(net, 1, "threshold", 2, seeds = 0.05)    # Granovetter: at least 2 infected neighbors
si = gsk.complex_si_model(net, 1, "cascade", 0.18, seeds = 1)      # Watts: at least 18% of the neighbors
sir = gsk.complex_sir_model(net, 0.5, 0.1, "threshold", 2, seeds = 0.05)
sis = gsk.complex_sis_model(net, 0.05, 0.2, "classical", seeds = 10)

# heterogeneous thresholds, one per node, from a numeric node attribute
import numpy as np
net.set_node_attribute("phi", np.random.default_rng(1).uniform(0.1, 0.3, net.number_of_nodes(0)))
si = gsk.complex_si_model(net, 1, "cascade", "phi", seeds = 5)

# independent and decreasing cascades (Kempe, Kleinberg and Tardos): one attempt per edge
si = gsk.complex_si_model(net, 0.1, "independent", seeds = 5)      # the same probability on every edge
net.set_edge_attribute("p", np.random.default_rng(2).uniform(0, 0.3, net.components[0].edge_index.shape[1]))
si = gsk.complex_si_model(net, "p", "independent", seeds = 5)      # one probability per edge (and direction)
P = np.random.default_rng(3).uniform(0, 0.3, (net.number_of_nodes(0),) * 2)
si = gsk.complex_si_model(net, P, "decreasing", decay = 0.5, seeds = 5)   # table: origins by targets

# who infected whom in the last run: a forest, one tree per seed
si, forest = gsk.complex_si_model(net, 0.2, "independent", seeds = 3, forest = True)
edges, nodes = forest.to_pandas_dataframes()                     # source infected target at step; node attributes
trees = gsk.connected_components_nodes(forest)                   # the nodes reached from each seed

On 100,000 nodes and 500,000 edges, 100 runs on two CPU threads with the Numba engine take about as long as simple contagion: 3.6 s for the classical SI model with beta = 0.02 (486 steps), 1.7 s for the threshold model with k = 2 and 1% of seeds, 1.2 s for the cascade model with phi = 0.1, 3.0 s for the classical SIR model with beta = 0.05, mu = 0.1, 1.8 s for the independent cascade with p = 0.2 (2.2 s with probabilities from an edge attribute), 1.3 s for the decreasing cascade with p = 0.3 and decay = 0.5 (10 seeds).

Complex SI model

graphoskop.complex_si_model(net, beta, reinforcement='classical', threshold=None, decay=0.5, seeds=1, ranking=None, selection='top', runs=100, max_steps=1000, component=0, seed=None, engine=None, batch=None, attribute='state', resume=False, forest=False, immunize=None, strategy='random')

Simulate the SI model with complex contagion, and return the fraction of nodes in each state at every time step, averaged over independent runs.

As si_model(), but a susceptible node is infected according to reinforcement (see the module description). A run stops when no susceptible node can be infected any more (in threshold models, the cascade may stop well before reaching all the nodes), or after max_steps steps.

Parameters:

  • net – A Network.

  • beta – Infection probability, in (0, 1]: per infected neighbor ("classical"), once the threshold is met ("threshold", "cascade"), or per attempt ("independent", "decreasing": one value, or a table of probabilities per pair of nodes, see the module description).

  • reinforcement – "classical", "threshold", "cascade", "independent" or "decreasing".

  • threshold – With "threshold", the number of infected neighbors needed (at least 1); with "cascade", the share of the in-neighbors, in (0, 1]; one value, or one per node. Ignored by the other kinds.

  • decay – With "decreasing", the factor of the probability of an attempt for every earlier failed attempt on the same node, in (0, 1].

  • seeds – Number of seed nodes, or a fraction of the nodes if below 1.

  • ranking – Node values used to choose the seeds, or None for random seeds.

  • selection – "top" or "weighted".

  • runs – Number of independent runs.

  • max_steps – Largest number of steps of a run.

  • component – Index of the component, or None for the whole network.

  • seed – Seed of the random numbers, or None.

  • engine – "numba", "torch" or None.

  • batch – With the torch engine, the number of runs simulated at once, or None.

  • attribute – Name of the qualitative node attribute holding the states ("S" or "I"), or None.

  • resume – Whether to start from the states in attribute instead of seeds.

  • forest – With "independent" or "decreasing", whether to return also who infected whom in the last run (see the module description).

  • immunize – Nodes immunized at step 0, never infected (see simple_contagion): a number of nodes (a fraction of them if below 1), chosen by strategy, or the node ids themselves; None for none.

  • strategy – With a number of nodes to immunize: "random", "friend_of_random", or node values (vector, dictionary or pandas.Series, name of a numeric node attribute) whose largest ones are immunized. Ignored with node ids.

Returns:

pandas.DataFrame indexed by step, with columns S, S_low, S_high, I, I_low and I_high; with forest, a pair (table, forest Network).

Raises:

ValueError – As si_model(), if reinforcement is not valid, if thresholds are missing or out of range, if probabilities per pair are out of [0, 1] or given for another kind of reinforcement, if decay is not valid, or if forest is asked for another kind of reinforcement.

Example:

import graphoskop as gsk

net = gsk.load_network("contacts.tsv")

si = gsk.complex_si_model(net, 1, "threshold", 2, seeds = 0.05)     # Granovetter: 2 infected neighbors
si = gsk.complex_si_model(net, 1, "cascade", 0.18, seeds = 1)       # Watts: 18% of the neighbors
si["I"].iloc[-1]                                                     # final size of the cascade
si = gsk.complex_si_model(net, 1, "cascade", "threshold", seeds = 5)   # thresholds from a node attribute

si = gsk.complex_si_model(net, 0.1, "independent", seeds = 5)       # Kempe et al.: one attempt per edge
si = gsk.complex_si_model(net, "p", "independent", seeds = 5)       # probabilities from edge attribute "p"
si = gsk.complex_si_model(net, P, "decreasing", decay = 0.5)        # P: matrix, origins by targets

si, forest = gsk.complex_si_model(net, 0.1, "independent", seeds = 3, forest = True)
edges = forest.to_pandas_dataframes()                               # source infected target at step
trees = gsk.connected_components_nodes(forest)                      # one tree per seed
