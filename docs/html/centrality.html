Centrality

Centrality of nodes based on shortest paths: closeness, harmonic and betweenness centrality, and betweenness centrality of edges; local reaching centrality of directed networks; and, not based on shortest paths, random walk (current flow) betweenness (flow_centrality()), eigenvector centrality (eigenvector_centrality()), Katz centrality (katz_centrality()), alpha centrality (alpha_centrality()), PageRank (pagerank()), hubs and authorities (hits()) and k-core centrality (k_core_centrality()). Any of them can be turned into a centralization of the whole network with centralization().

Paths are those of shortest_paths: lengths are the values of an edge attribute (weight) or 1, with inverse = True for attributes measuring affinity; directed networks are searched along edge directions; in multilayer networks paths run on the supra-graph, where changing layer along a coupling is a step, and every copy has its own centrality.

component selects what counts as the network: an index computes the centralities of that component as if it were the whole network (normalizations use its number of nodes), None computes them for all components at once, as one network whose nodes in different components are unreachable from each other (normalizations use the number of nodes of the whole network). Results are float64 vectors over the nodes of a component, ordered by internal index, on its device (a list of them, one per component, with component = None), ready for set_node_attribute().

The lengths of all shortest paths are the costly part. They can be computed once with all_pairs_shortest_path_lengths() (with the same component, weight and inverse) and passed as lengths, to all these functions and to average_shortest_path_length(); nothing is then searched again. Without them, lengths are found by Dijkstra on the CPU, in blocks of sources (in parallel processes for large work, see shortest_paths), and never stored all at once.

import graphoskop as gsk

net = gsk.load_network("edges.tsv")
P = gsk.all_pairs_shortest_path_lengths(net)             # computed once ...
c = gsk.closeness_centrality(net, lengths = P)           # ... used by all
h = gsk.harmonic_centrality(net, lengths = P)
b = gsk.betweenness_centrality(net, lengths = P)
eb = gsk.edge_betweenness_centrality(net, lengths = P)   # one value per stored edge
gsk.average_shortest_path_length(net, lengths = P)

# all components at once, comparable across components
c = gsk.closeness_centrality(net, component = None, lin = True)
h = gsk.harmonic_centrality(net, component = None)
graphoskop.alpha_centrality(net, component=0, weight=None, alpha=1.0, exo=1.0, direction='in', loops=False, tol=1e-10, max_iter=10000)

Alpha centrality (Bonacich and Lloyd, 2001): status received from the neighbors plus an exogenous source \(e_i\) of status for every node, \(x_i = \alpha \sum_j A_{ji} x_j + e_i\), i.e. \(x = (I - \alpha A^T)^{-1} e\).

It is the equation of katz_centrality() with \(\beta = e\), but defined by the matrix inverse rather than by the series of walks: \(\alpha\) can be any value for which \(I - \alpha A^T\) is invertible, also above \(1 / \lambda_{max}\) (where the series diverges and values can be negative) or negative. Results are not normalized. Defaults are those of R igraph’s alpha_centrality: \(\alpha = 1\), \(e = 1\), self loops ignored.

In directed networks, direction = "in" gives a node the status of the nodes with edges to it (as igraph), "out" that of the nodes it has edges to. Weights add up over parallel edges; a kept self loop counts once in undirected networks. In multilayer networks the status flows on the supra-graph, couplings included.

The system is solved as katz_centrality() does, by iterating the equation on the device of the network, which converges if \(|\alpha| \lambda_{max} < 1\), until the vector changes by less than tol per node. If the iteration diverges (or does not converge in max_iter steps), the system is solved exactly by sparse LU factorization (SuperLU, through scipy.sparse.linalg) on the CPU. This is fast on small or sparse, clustered networks, but its cost can grow quickly (to the cube of the number of nodes) on large networks with random-like structure, e.g. minutes for 20,000 nodes and 100,000 random edges. The default \(\alpha = 1\) is above \(1 / \lambda_{max}\) for most networks, so it always takes this route.

Parameters:

  • net – A Network.

  • component – Index of the component (0 is the largest), or None for all components.

  • weight – Name of the edge attribute used as edge weight, or None for unit weights.

  • alpha – Relative importance \(\alpha\) of the endogenous status.

  • exo – Exogenous status \(e\): a number for all nodes, the name of a numeric node attribute, or a dictionary (or pandas.Series) from input node id to value (missing nodes get 0).

  • direction – "in" or "out"; ignored in undirected networks.

  • loops – Keep self loops.

  • tol – Tolerance per node of the iteration.

  • max_iter – Largest number of iterations before the exact solve.

Returns:

Vector over the nodes of the component, or a list of them if component is None.

Raises:

ValueError – If direction is not valid, or the iteration does not converge and \(I - \alpha A^T\) is singular up to rounding (\(1 / \alpha\) is an eigenvalue of the adjacency matrix: a pivot of the LU factorization is below \(10^{-12}\) times the largest). If the matrix is singular but the iteration converges (e.g. \(e = 0\)), its result, a solution of the equation, is returned.

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv", directed = True)
x = gsk.alpha_centrality(net, alpha = 0.5, exo = "wealth")
graphoskop.betweenness_centrality(net, component=0, weight=None, inverse=False, normalized=True, lengths=None, batch_size=16777216, n_jobs=None)

Betweenness centrality (Freeman, 1977): the fraction of shortest paths between other nodes that pass through a node, \(B(i) = \sum_{s \ne i \ne t} \sigma_{st}(i) / \sigma_{st}\), with \(\sigma_{st}\) the number of shortest paths from \(s\) to \(t\) and \(\sigma_{st}(i)\) those through \(i\). All tied shortest paths count.

With normalized = True the sum over ordered pairs is divided by \((N - 1)(N - 2)\), the number of ordered pairs of other nodes, with \(N\) the number of nodes of the network considered (as NetworkX, also for undirected networks); otherwise the plain sum, over unordered pairs in undirected networks.

Paths are counted forward and then backward as in Brandes’ algorithm (2001), on the device of the network, for blocks of sources at once (about batch_size numbers in memory). With unit lengths (weight = None) the breadth first searches of a block of sources run together, level by level, as products of the sparse adjacency matrix with a dense matrix of one column per source, which count the paths as they go: no lengths are searched or stored, and lengths is not needed. With lengths, only the lengths of the shortest paths are needed: an edge \(u \to v\) of length \(w\) is on a shortest path from \(s\) exactly when \(d(s, u) + w = d(s, v)\), and the paths are counted along these edges. Edge lengths must be positive (a cycle of length 0 would give infinitely many shortest paths). Parallel edges count once, with the shortest length (igraph counts each parallel edge as a separate path), and self loops are ignored. With lengths, they must have been computed with the same weight and inverse, which are still needed to know the edge lengths.

Parameters:

  • net – A Network.

  • component – Index of the component (0 is the largest), or None for all components at once (see the module description).

  • weight – Name of the edge attribute used as edge length, or None for unit lengths.

  • inverse – Use the reciprocal of the edge attribute as length.

  • normalized – Divide by \((N - 1)(N - 2)\).

  • lengths – Precomputed lengths (see the module description), or None.

  • batch_size – Bound on the numbers held at once (about one per source and edge).

  • n_jobs – Number of processes for the searches, None for all CPUs.

Returns:

Vector over the nodes of the component, or a list of them if component is None.

Raises:

ValueError – If some edge lengths are not positive, or lengths does not match.

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv", device = "cuda")
P = gsk.all_pairs_shortest_path_lengths(net, weight = "weight", inverse = True)
b = gsk.betweenness_centrality(net, weight = "weight", inverse = True, lengths = P)
c = gsk.closeness_centrality(net, lengths = P)                 # same lengths, no new search
graphoskop.centralization(net, centrality='degree', component=0, maximum=None, **kwargs)

Centralization of a network for a centrality measure (Freeman, 1979): how much the most central node exceeds all the others, relative to the largest possible such excess in a network with the same number of nodes,

\[C = \frac{\sum_i (c_{max} - c_i)}{\max_{G'} \sum_i (c_{max}(G') - c_i(G'))}.\]

It is 1 for a star (for the usual measures), 0 when all nodes are equally central. The maximum is computed by running the same centrality, with the same options, on a star with the same number of nodes (in directed networks the largest over the star with edges out of the center, the star with edges into it and the star with edges both ways), so it follows the normalization and the options of the centrality used. The star is the most centralized network for degree, closeness and betweenness (Freeman, 1979) and for eigenvector centrality, as used by igraph’s centralization functions; for other measures it is the conventional reference but not necessarily the maximum (values can then exceed 1), and for some it is meaningless (a star has all core numbers equal to 1, so the result of k_core_centrality() is NaN): pass maximum then. See degree_centralization() for a centralization of degrees based on entropy and random networks instead.

Every edge of the star has, for each edge attribute of net, its mean value over the network considered, so that weight options work and the result does not depend on the units of the weights. The star has no node attributes: options naming node attributes (e.g. beta of katz_centrality() given as an attribute name) cannot be used without maximum. Measures that cannot be computed on the star raise an error asking for maximum: e.g. katz_centrality() and alpha_centrality() with an \(\alpha\) above \(1 / \sqrt{n - 1}\), the reciprocal of the largest eigenvalue of a star. The result also depends on how the centrality is normalized: e.g. eigenvector_centrality() has unit Euclidean norm, while igraph scales it to a largest value of 1, which gives a different centralization (pass a function rescaling the vector to reproduce it).

Parameters:

  • net – A Network.

  • centrality – A centrality function of this module (or any function taking the network, component and the options, and returning one value per node, or a list of vectors for component = None), or "degree" for the degree (options direction, "out", "in" or "total", and weight, as degree()).

  • component – Index of the component (0 is the largest), or None for the whole network (compared with a star of all its nodes).

  • maximum – Largest sum of differences, or None to compute it on the star.

  • kwargs – Options of the centrality, used for the network and the star.

Returns:

The centralization, a float (NaN for fewer than 2 nodes or a maximum of 0).

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv")
gsk.centralization(net)                                       # degree centralization
gsk.centralization(net, gsk.betweenness_centrality)
gsk.centralization(net, gsk.closeness_centrality, weight = "weight")
dnet = gsk.load_network("edges.tsv", directed = True)
gsk.centralization(dnet, "degree", direction = "in")
graphoskop.closeness_centrality(net, component=0, weight=None, inverse=False, direction='out', lin=False, lengths=None, n_jobs=None)

Closeness centrality: how close a node is to the nodes it reaches.

\(C(i) = r_i / \sum_j d(i, j)\), with the sum over the \(r_i\) nodes reachable from \(i\) (in an undirected connected network, \(r_i = n - 1\)); 0 if \(i\) reaches no node. Nodes in small components are close to the few nodes they reach, so with lin = True (Lin, 1976; Wasserman and Faust, 1994) the value is scaled by the fraction of the network they reach, \(C(i) = \frac{r_i}{N - 1} \frac{r_i}{\sum_j d(i, j)}\), with \(N\) the number of nodes of the network considered: use it with component = None to compare nodes of different components (or of directed networks where not every node is reachable). See also harmonic_centrality().

In directed networks, direction = "out" uses the lengths from the node to the others, "in" those from the others to the node (NetworkX uses "in"; its wf_improved is lin).

Parameters:

  • net – A Network.

  • component – Index of the component (0 is the largest), or None for all components at once (see the module description).

  • weight – Name of the edge attribute used as edge length, or None for unit lengths.

  • inverse – Use the reciprocal of the edge attribute as length.

  • direction – "out" or "in"; ignored in undirected networks.

  • lin – Scale by the fraction of the network reached.

  • lengths – Precomputed lengths (see the module description), or None.

  • n_jobs – Number of processes for the searches, None for all CPUs.

Returns:

Vector over the nodes of the component, or a list of them if component is None.

Raises:

ValueError – If direction is not valid, lengths are negative or NaN, or lengths does not match.

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv")
c = gsk.closeness_centrality(net)                              # largest component
cs = gsk.closeness_centrality(net, component = None, lin = True)   # comparable across components
net.set_node_attribute("closeness", c)
graphoskop.edge_betweenness_centrality(net, component=0, weight=None, inverse=False, normalized=True, lengths=None, batch_size=16777216, n_jobs=None)

Edge betweenness centrality (Girvan and Newman, 2002): the fraction of shortest paths between nodes that pass along an edge, \(B(e) = \sum_{s \ne t} \sigma_{st}(e) / \sigma_{st}\), with \(\sigma_{st}\) the number of shortest paths from \(s\) to \(t\) and \(\sigma_{st}(e)\) those using \(e\). All tied shortest paths count, and, unlike node betweenness, the pairs whose shortest paths start or end at the edge count too (an edge is on the shortest path between its own endpoints, unless a shorter path exists).

With normalized = True the sum over ordered pairs is divided by \(N (N - 1)\), the number of ordered pairs, with \(N\) the number of nodes of the network considered (as NetworkX, also for undirected networks); otherwise the plain sum, over unordered pairs in undirected networks.

Computed in the same pass as betweenness_centrality(), with the same algorithm, devices, memory bound and conditions on the lengths: the dependency of each edge on a shortest path is one of the terms of Brandes’ backward accumulation. In undirected networks an edge counts the paths along it in both directions. Among parallel edges, only the shortest (the first in input order on ties) carries the paths, the others get 0; self loops and edges of infinite length get 0.

Parameters:

  • net – A Network.

  • component – Index of the component (0 is the largest), or None for all components at once (see the module description).

  • weight – Name of the edge attribute used as edge length, or None for unit lengths.

  • inverse – Use the reciprocal of the edge attribute as length.

  • normalized – Divide by \(N (N - 1)\).

  • lengths – Precomputed lengths (see the module description), or None.

  • batch_size – Bound on the numbers held at once (about one per source and edge).

  • n_jobs – Number of processes for the searches, None for all CPUs.

Returns:

Vector over the stored edges of the component, aligned with edge_index (both directions of an undirected edge get its value), ready for set_edge_attribute(); a list of them if component is None.

Raises:

ValueError – If some edge lengths are not positive, or lengths does not match.

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv")
eb = gsk.edge_betweenness_centrality(net)
net.set_edge_attribute("betweenness", eb)
ebs = gsk.edge_betweenness_centrality(net, component = None)
net.set_edge_attribute("betweenness", ebs, component = None)
graphoskop.eigenvector_centrality(net, component=0, weight=None, direction='in', tol=1e-10, max_iter=10000)

Eigenvector centrality (Bonacich, 1972): a node is central if its neighbors are, \(\lambda x_i = \sum_j A_{ji} x_j\), with \(x\) the eigenvector of the largest eigenvalue \(\lambda\) of the adjacency matrix, non negative and of unit Euclidean norm.

In directed networks, direction = "in" gives a node the centrality of the nodes with edges to it (as NetworkX), "out" that of the nodes it has edges to. If the network is not strongly connected, nodes not reached from a strongly connected part with the largest eigenvalue get 0 (e.g. all of them in a directed acyclic network, where the iteration does not settle and a warning is raised): see stationary_distribution() for a measure that is positive everywhere. In multilayer networks the eigenvector is that of the supra-adjacency matrix, couplings included. Weights add up over parallel edges; a self loop counts once in undirected networks.

Computed by power iteration on \(I + A^T\) (same eigenvector, without the oscillation of bipartite networks), with one sparse product per step on the device of the network, starting from a constant vector (as NetworkX), until the vector changes by less than tol per node (1-norm of the change below \(n \cdot\) tol). Each component is computed and normalized on its own.

Parameters:

  • net – A Network.

  • component – Index of the component (0 is the largest), or None for all components (each normalized on its own).

  • weight – Name of the edge attribute used as edge weight, or None for unit weights.

  • direction – "in" or "out"; ignored in undirected networks.

  • tol – Tolerance per node.

  • max_iter – Largest number of iterations; a warning is raised if it is reached.

Returns:

Vector over the nodes of the component, or a list of them if component is None.

Raises:

ValueError – If direction is not valid, or some weights are negative.

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv", device = "cuda")
x = gsk.eigenvector_centrality(net, weight = "weight")
net.set_node_attribute("eigenvector", x)
graphoskop.flow_centrality(net, component=0, weight=None, normalized=True, endpoints=False, batch_size=16777216)

Random walk betweenness centrality (Newman, 2005), also known as current flow betweenness: as betweenness_centrality(), but with all random walks from \(s\) to \(t\) instead of only the shortest paths. A node counts the net number of times the walks pass through it, which equals the current through it when a unit current enters the network at \(s\) and leaves at \(t\), edges being resistors of conductance equal to their weight.

The current from a pair is computed from the pseudoinverse \(T\) of the Laplacian: node \(i\) gets \(I_i^{st} = \frac{1}{2} \sum_j A_{ij} |T_{is} - T_{it} - T_{js} + T_{jt}|\), and \(B(i) = \sum_{s < t} I_i^{st}\), over the pairs of other nodes (endpoints = False) or of all nodes, with \(I_s^{st} = I_t^{st} = 1\) (endpoints = True, Newman’s definition). With normalized = True the sum is divided by the number of pairs, \((N - 1)(N - 2) / 2\) or \(N (N - 1) / 2\), with \(N\) the number of nodes of the network considered (the first as NetworkX’s current_flow_betweenness_centrality).

The current along an edge \((i, j)\) is \(A_{ij} |x_s - x_t|\), with \(x = T_{i \cdot} - T_{j \cdot}\), so its sum over all pairs is found by sorting \(x\): \(\sum_{s < t} |x_s - x_t| = \sum_k (2k - n + 1) x_{(k)}\). The cost is a dense pseudoinverse per component (as laplacian_pinv(), \(n^2\) numbers in memory) and a sort of \(n\) numbers per edge, in blocks of edges (about batch_size numbers at once), all on the device of the network: \(O(n^3 + m n \log n)\), instead of \(O((m + n) n^2)\) for Newman’s algorithm.

Edges are taken as undirected (in directed networks each edge is a resistor whatever its direction), parallel edges add their conductances, self loops are ignored. Weights must be positive. Pairs of nodes in different components carry no current, so with component = None they add nothing. In multilayer networks the current flows on the supra-graph, couplings included.

Parameters:

  • net – A Network.

  • component – Index of the component (0 is the largest), or None for all components at once (see the module description).

  • weight – Name of the edge attribute used as edge conductance, or None for unit conductances.

  • normalized – Divide by the number of pairs.

  • endpoints – Count the pairs where the node is the source or the target, with current 1.

  • batch_size – Bound on the numbers held at once while sorting (about one per edge and node of a block).

Returns:

Vector over the nodes of the component, or a list of them if component is None.

Raises:

ValueError – If some weights are not positive.

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv", device = "cuda")
f = gsk.flow_centrality(net)
f = gsk.flow_centrality(net, weight = "weight", endpoints = True)   # Newman's normalization
net.set_node_attribute("flow", f)
graphoskop.harmonic_centrality(net, component=0, weight=None, inverse=False, direction='out', normalized=True, lengths=None, n_jobs=None)

Harmonic centrality (Marchiori and Latora, 2000; Boldi and Vigna, 2014): the reciprocal of the harmonic mean of the lengths from a node to all the other nodes.

\(H(i) = \frac{1}{N - 1} \sum_{j \ne i} \frac{1}{d(i, j)}\), with \(1 / \infty = 0\) for unreachable nodes, so nodes of different components (component = None) are compared directly, without corrections. \(N\) is the number of nodes of the network considered; normalized = False gives the plain sum (as NetworkX). Nodes at length 0 (along edges of length 0) are left out of the sum.

In directed networks, direction = "out" uses the lengths from the node to the others, "in" those from the others to the node (as NetworkX).

Parameters:

  • net – A Network.

  • component – Index of the component (0 is the largest), or None for all components at once (see the module description).

  • weight – Name of the edge attribute used as edge length, or None for unit lengths.

  • inverse – Use the reciprocal of the edge attribute as length.

  • direction – "out" or "in"; ignored in undirected networks.

  • normalized – Divide by \(N - 1\).

  • lengths – Precomputed lengths (see the module description), or None.

  • n_jobs – Number of processes for the searches, None for all CPUs.

Returns:

Vector over the nodes of the component, or a list of them if component is None.

Raises:

ValueError – If direction is not valid, lengths are negative or NaN, or lengths does not match.

Example:

h = gsk.harmonic_centrality(net, component = None)         # all components at once
graphoskop.hits(net, component=0, weight=None, tol=1e-10, max_iter=10000)

Hubs and authorities (HITS; Kleinberg, 1999): a good authority is pointed to by good hubs, a good hub points to good authorities, \(a \propto A^T h\) and \(h \propto A a\), so \(a\) is the leading eigenvector of \(A^T A\) and \(h\) that of \(A A^T\). Each sums to 1 over the nodes of a component (as NetworkX, which normalizes over the whole network); each component is computed on its own, since a single power iteration over several components keeps only the one with the largest eigenvalue. In undirected networks hubs and authorities are the same. Weights add up over parallel edges; in multilayer networks the scores are those of the supra-graph, couplings included.

Computed by power iteration on \(A^T A\) (positive semidefinite, so it does not oscillate), with two sparse products per step on the device of the network, starting from a constant vector, until the authorities change by less than tol per node (1-norm of the change below \(n \cdot\) tol). A component without edges gets 0. If the largest eigenvalue of \(A^T A\) is repeated (e.g. two disconnected parts once direction is taken into account), the scores are not unique; this iteration returns the ones reached from the constant vector.

Parameters:

  • net – A Network.

  • component – Index of the component (0 is the largest), or None for all components.

  • weight – Name of the edge attribute used as edge weight, or None for unit weights.

  • tol – Tolerance per node.

  • max_iter – Largest number of iterations; a warning is raised if it is reached.

Returns:

(hubs, authorities), two vectors over the nodes of the component, or two lists of them if component is None.

Raises:

ValueError – If some weights are negative.

Example:

import graphoskop as gsk

net = gsk.load_network("links.tsv", directed = True, device = "cuda")
hubs, authorities = gsk.hits(net)
net.set_node_attribute("authority", authorities)
graphoskop.k_core_centrality(net, component=0, mode='all')

k-core centrality, or core number (Seidman, 1983): the largest \(k\) such that the node belongs to the \(k\)-core, the largest subgraph in which every node has at least \(k\) neighbors (obtained by repeatedly removing the nodes with fewer than \(k\) neighbors). Nodes without neighbors have 0.

Edges count once whatever their weight and multiplicity, and self loops are ignored (as NetworkX’s core_number). In directed networks, mode chooses the degree used: "all" (in plus out, as NetworkX, where a pair of reciprocal edges counts twice), "in" or "out" (as igraph’s coreness). In multilayer networks cores are those of the supra-graph, where couplings are edges like the others.

Computed by peeling on the device of the network: at level \(k\) (starting at the smallest degree), all nodes with degree at most \(k\) are removed at once and the degrees of their neighbors updated, wave after wave, until none is left at that level; they get core number \(k\). Each wave only touches the edges of the nodes it removes, so the work is proportional to the number of edges, plus a small fixed cost per wave and a pass over the nodes per level. Waves are few on most networks; long chains of nodes (e.g. a path) are peeled one node from each end per wave.

Parameters:

  • net – A Network.

  • component – Index of the component (0 is the largest), or None for all components.

  • mode – "all", "in" or "out"; ignored in undirected networks.

Returns:

int64 vector over the nodes of the component, or a list of them if component is None.

Raises:

ValueError – If mode is not valid.

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv")
core = gsk.k_core_centrality(net)
net.set_node_attribute("core", core)
main_core = net.node_ids[0][(core == core.max()).cpu().numpy()]
graphoskop.katz_centrality(net, component=0, weight=None, alpha=0.1, beta=1.0, direction='in', normalized=True, tol=1e-10, max_iter=10000)

Katz centrality (Katz, 1953): the walks reaching a node, those of \(k\) edges discounted by \(\alpha^k\), plus a baseline \(\beta_i\) for every node, \(x_i = \alpha \sum_j A_{ji} x_j + \beta_i\), i.e. \(x = \beta + \alpha A^T \beta + \alpha^2 (A^T)^2 \beta + \ldots\). The series converges only if \(\alpha < 1 / \lambda_{max}\), the reciprocal of the largest eigenvalue of the adjacency matrix; as \(\alpha\) approaches it the ranking approaches that of eigenvector_centrality(). Unlike eigenvector centrality it is positive on every node, also in directed acyclic networks.

In directed networks, direction = "in" counts the walks reaching a node (as NetworkX), "out" those leaving it. Weights add up over parallel edges; a self loop counts once in undirected networks. In multilayer networks walks run on the supra-graph, couplings included.

Computed by iterating the equation from \(x = 0\), with one sparse product per step on the device of the network, until the vector changes by less than tol per node (1-norm of the change below \(n \cdot\) tol). With normalized = True the result has unit Euclidean norm over the network considered: with component = None all components are normalized together, so values are comparable across them. If \(\beta\) is 0 everywhere, so is the result.

Parameters:

  • net – A Network.

  • component – Index of the component (0 is the largest), or None for all components.

  • weight – Name of the edge attribute used as edge weight, or None for unit weights.

  • alpha – Attenuation factor \(\alpha\).

  • beta – Baseline \(\beta\): a number for all nodes, the name of a numeric node attribute, or a dictionary (or pandas.Series) from input node id to value (missing nodes get 0).

  • direction – "in" or "out"; ignored in undirected networks.

  • normalized – Scale to unit Euclidean norm.

  • tol – Tolerance per node.

  • max_iter – Largest number of iterations.

Returns:

Vector over the nodes of the component, or a list of them if component is None.

Raises:

ValueError – If direction is not valid, weights are negative, or the iteration does not converge (alpha too large).

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv", directed = True, device = "cuda")
x = gsk.katz_centrality(net, alpha = 0.05)
xs = gsk.katz_centrality(net, component = None, beta = "prior")   # node attribute as baseline
graphoskop.pagerank(net, component=0, weight=None, damping=0.85, personalization=None, tol=1e-12, max_iter=10000)

PageRank (Brin and Page, 1998): the stationary distribution of a random walker who, at each step, follows an out edge with probability damping (choosing it proportionally to its weight), and otherwise jumps to a random node. Nodes without out edges (dangling) always jump. Jumps go to a uniformly random node, or, with personalization, to a node drawn from those values (personalized PageRank, as NetworkX, where dangling nodes jump the same way).

The values sum to 1 over the network considered: with component = None the walker jumps between components, so values are comparable across them (one walk on the whole network); with a component index, the walk stays in that component (as stationary_distribution(), which this generalizes). Undirected edges are followed both ways; in multilayer networks the walker moves along couplings too. Computed by power iteration, one sparse product per step on the device of the network, until the 1-norm of the change is below tol.

Parameters:

  • net – A Network.

  • component – Index of the component (0 is the largest), or None for the whole network.

  • weight – Name of the edge attribute used as edge weight, or None for unit weights.

  • damping – Probability of following an edge (1 - alpha of stationary_distribution()).

  • personalization – Jump distribution: name of a numeric node attribute, or dictionary (or pandas.Series) from input node id to value (missing nodes get 0), or None for uniform. Values must be non negative, not all 0; they are normalized to sum 1.

  • tol – Convergence threshold (1-norm of the change between iterations).

  • max_iter – Largest number of iterations; a warning is raised if it is reached.

Returns:

Vector over the nodes of the component, or a list of them if component is None.

Raises:

ValueError – If weights or personalization values are negative, or the personalization is all 0.

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv", directed = True, device = "cuda")
pr = gsk.pagerank(net, component = None)                       # whole network
ppr = gsk.pagerank(net, component = None, personalization = {"alice": 1})
graphoskop.reach_centrality(net, component=0, direction='out', lengths=None, n_jobs=None)

Local reaching centrality (Mones, Vicsek and Vicsek, 2012): the fraction of the other nodes that a node reaches along edge directions, \(C_R(i) = r_i / (N - 1)\), with \(r_i\) the number of nodes reachable from \(i\) and \(N\) the number of nodes of the network considered (see the module description). With direction = "in", the fraction of nodes from which \(i\) is reached. Defined for directed networks only: in an undirected network every node reaches its whole component. Edge weights do not matter (reaching does not depend on them; the weighted variant of the paper averages weights along one shortest path, which is not unique, and is not provided).

All nodes of a strongly connected component reach the same nodes, so a single breadth first search per strongly connected component is needed (on the CPU, in parallel processes for large work, as closeness_centrality()), or none with precomputed lengths.

Parameters:

  • net – A directed Network.

  • component – Index of the component (0 is the largest), or None for all components at once (see the module description).

  • direction – "out" (nodes reached) or "in" (nodes reaching).

  • lengths – Precomputed lengths (see the module description), or None.

  • n_jobs – Number of processes for the searches, None for all CPUs.

Returns:

Vector over the nodes of the component, or a list of them if component is None.

Raises:

ValueError – If the network is undirected, direction is not valid, or lengths does not match.

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv", directed = True)
r = gsk.reach_centrality(net, component = None)
net.set_node_attribute("reach", r, component = None)

See global_reach_centrality() for the hierarchy measure built on it.
