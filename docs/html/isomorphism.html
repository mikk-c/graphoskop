Isomorphism

Isomorphism: whether two networks are the same up to a relabeling of their nodes, and whether a network contains another one.

Two networks are isomorphic when a one-to-one map of the nodes of one onto the nodes of the other maps edges onto edges and non edges onto non edges. A network contains another one, the pattern, when the pattern is isomorphic to a subgraph of it: to an induced subgraph (some nodes and all the edges among them), or, more loosely, to any subgraph (some nodes and some of the edges among them: a monomorphism).

Both questions have an exact and an approximate answer.

  • The approximate answer is one sided: False is always right, and True means that the networks passed a necessary condition. For isomorphism, the condition is color refinement, the 1-dimensional Weisfeiler-Leman test: every node gets a color from its attributes, then the color of every node is repeatedly combined with the multiset of the colors of its neighbors, on both networks at once, until no color class splits; isomorphic networks end with the same number of nodes of every color. Regular graphs of the same size and degree are the classic case that the test cannot tell apart. For subgraphs, the condition is a filter of the candidate images of every pattern node (same attributes, at least the same degree), keeping a candidate only while every neighbor of the pattern node has a candidate among the neighbors of the candidate (the refinement of Ullmann, 1976, as matrix products), followed by a matching that assigns distinct candidates to all pattern nodes. Both are vectorized tensor operations, on the device of the networks, except color refinement on the CPU, which runs in compiled code with Hopcroft’s rule, in \(O(m \log n)\) whatever the diameter of the networks (vectorized rounds are faster only on a GPU, where they run up to 32 rounds before the compiled code takes over).

  • The exact answer to isomorphism comes from individualization-refinement, the strategy of nauty, bliss and Traces (McKay and Piperno, 2014): after color refinement, a node of net2 in a color class with more than one node per network is given a color of its own together with each node of net1 of its class, in turn, and the colors are refined again, until every class holds one node of each network, a mapping that is then checked. A class whose individualization splits nothing else is a class of twins (nodes with the same neighbors) and is matched at once, without trying alternatives. The search is compiled (Numba) and the candidates of the first node are tried in parallel.

  • The exact answer to subgraph questions searches a mapping depth first, in the style of VF2++ and VF3 (Jüttner and Madarasi, 2018; Carletti et al., 2017): pattern nodes are matched in an order that keeps every new node connected to the matched ones (most matched neighbors, then fewest candidates, then highest degree), the candidates of a node are the neighbors of the image of a matched neighbor that passed the filter above, and every candidate is checked against the matched nodes. The search is compiled and runs in parallel over the candidate images of the first node (as the parallel VF3 of Carletti et al., 2019).

Node attributes and edge attributes listed by name must be equal on matched nodes and edges. Edge directions always count; self loops are attributes of their node; parallel edges are one edge whose attributes are the number of copies and the attribute values of each copy (pairs of parallel edges must match exactly, also in monomorphisms). In multilayer networks the layer of every node copy must match as well.

import pandas as pd
import graphoskop as gsk

ring = gsk.add_edges(gsk.chain_graph(6), (5, 0))              # a 6-cycle
path = gsk.chain_graph(4)
gsk.is_isomorphic(ring, ring)                                 # True
gsk.is_isomorphic(ring, path, subgraph = True)                # True: the cycle contains a 4-path
gsk.is_isomorphic(path, ring, subgraph = True)                # False
gsk.is_isomorphic(ring, path, subgraph = True, exact = False) # True: passes the filter

net = gsk.load_network("edges.tsv", "nodes.tsv")
other = gsk.load_network("edges2.tsv", "nodes2.tsv")
gsk.is_isomorphic(net, other, exact = False)                  # Weisfeiler-Leman test only
gsk.is_isomorphic(net, other, node_attributes = "city")       # cities must match too

triangle = gsk.load_network(pd.DataFrame({"source": ["a", "b", "c"], "target": ["b", "c", "a"]}))
m = gsk.isomorphisms(net, triangle, subgraph = True)          # every embedding of a triangle
m["match"].nunique() // 6                                     # number of triangles
graphoskop.is_isomorphic(net1, net2, subgraph=False, induced=True, exact=True, node_attributes=None, edge_attributes=None)

Whether two networks are isomorphic or, with subgraph = True, whether net1 contains net2: whether some subgraph of net1 is isomorphic to net2.

With exact = True (default), the answer comes from a compiled, parallel search of a mapping of the nodes of net2 onto nodes of net1: individualization-refinement for isomorphism, a depth first search in the style of VF2++ / VF3 for subgraphs, with the candidates pruned by the approximate tests first (see the module description). The worst case is exponential, as for every known algorithm, but common networks are matched quickly.

With exact = False, the approximate test only: False is always right, and True means that the networks passed a necessary condition, so that they are likely, not surely, isomorphic (net1 likely contains net2). For isomorphism, the condition is that color refinement (1-dimensional Weisfeiler-Leman) gives both networks the same number of nodes of every color; for subgraphs, that every pattern node keeps candidates under neighborhood filtering and that distinct candidates can be assigned to all pattern nodes. Both are tensor operations, on the GPU if the networks are there. For subgraphs, the filter needs a dense matrix of n1 * n2 booleans and is skipped above \(2^{28}\) pairs, leaving a comparison of node attributes only (and, with exact = True, a search without pruning).

The networks must be both directed or both undirected, and both multilayer or not. Node attributes listed in node_attributes (numeric or qualitative, multi-valued in long format) must be equal on matched nodes, NaN matching NaN; edge attributes listed in edge_attributes (numeric or qualitative) must be equal on matched edges. Self loops must match (with induced = False, a self loop of net1 may be left out of the subgraph). Parallel edges are matched as a whole: same number of copies with the same attribute values. In multilayer networks every node copy must match a copy in the same layer (compared by layer label). Bipartite networks are matched as plain networks: pass BIPARTITE in node_attributes to match the node types too.

Hypergraphs and simplicial complexes: not supported (see Higher-order networks).

Parameters:

  • net1 – A Network (the larger network, with subgraph = True).

  • net2 – A Network (the pattern, with subgraph = True).

  • subgraph – Whether to test whether net1 contains net2 instead of isomorphism.

  • induced – With subgraph = True, whether the subgraph of net1 must be induced (all the edges of net1 among the matched nodes are in net2); otherwise net1 may have more edges among them (monomorphism).

  • exact – Whether to search a mapping (exact answer) or to run the approximate test only.

  • node_attributes – Name or list of names of node attributes that must match.

  • edge_attributes – Name or list of names of edge attributes that must match.

Returns:

True or False.

Raises:

  • ValueError – If one network is directed (multilayer) and the other is not.

  • KeyError – If an attribute is missing.

Example:

import graphoskop as gsk

ring = gsk.chain_graph(6)
ring = gsk.add_edges(ring, (5, 0))                        # a 6-cycle
path = gsk.chain_graph(4)
gsk.is_isomorphic(ring, ring)                             # True
gsk.is_isomorphic(ring, path, subgraph = True)            # True: the 6-cycle contains P4
gsk.is_isomorphic(path, ring, subgraph = True)            # False
gsk.is_isomorphic(ring, path, exact = False)              # False (different sizes)
graphoskop.isomorphisms(net1, net2, subgraph=False, induced=True, node_attributes=None, edge_attributes=None, max_matches=None)

The mappings of the nodes of net2 onto nodes of net1 found by the exact test of is_isomorphic(): isomorphisms or, with subgraph = True, embeddings of net2 (the pattern) into net1. Every mapping is listed, so a subgraph of net1 appears once for every automorphism of the pattern (a triangle six times), and highly symmetric networks have a huge number of isomorphisms: max_matches stops the search.

All the mappings are found in parallel; with max_matches, the first ones are found by a single thread, in a fixed order.

Hypergraphs and simplicial complexes: not supported (see Higher-order networks).

Parameters:

  • net1 – A Network.

  • net2 – A Network.

  • subgraph – Whether to find embeddings of net2 into net1 instead of isomorphisms.

  • induced – With subgraph = True, whether the subgraphs must be induced.

  • node_attributes – Name or list of names of node attributes that must match.

  • edge_attributes – Name or list of names of edge attributes that must match.

  • max_matches – Most mappings to return (None: all).

Returns:

pandas.DataFrame with columns match (0, 1, …), net2 and net1: in mapping match, node net2 of net2 goes to node net1 of net1 (input ids); one row per node of net2 and mapping.

Raises:

ValueError – If one network is directed (multilayer) and the other is not.

Example:

import pandas as pd
import graphoskop as gsk

net = gsk.load_network("edges.tsv")
triangle = gsk.load_network(pd.DataFrame({"source": ["a", "b", "c"], "target": ["b", "c", "a"]}))
m = gsk.isomorphisms(net, triangle, subgraph = True)
m["match"].nunique() // 6                                 # number of triangles of net

Performance

Measured on two CPU threads (no GPU), testing a network against a copy with its nodes shuffled (isomorphic) and against a copy where one swap of edge endpoints keeps the degrees but breaks the isomorphism:

  • Barabási-Albert network, 100,000 nodes and 300,000 edges: exact test 0.3 s (isomorphic) and 0.2 s (not), approximate test 0.3 s; igraph’s BLISS takes 14.6 s. With 1,000,000 nodes: 7.9 s and 6.9 s exact, 4.5 s and 3.5 s approximate.

  • Random 3-regular network, 100,000 nodes: exact test 0.3 s (isomorphic) and 5.5 s (not: color refinement sees no difference, so every candidate image of the first node is tried); the approximate test cannot tell the two apart and answers True in 0.1 s. igraph’s BLISS takes 308 s on the isomorphic pair.

  • 2D lattice, 300 by 300: 0.3 s and 0.2 s exact (BLISS: 0.4 s and 0.2 s); 1000 by 1000: 5.9 s and 7.8 s exact, 3.8 s and 4.3 s approximate.

igraph’s VF2 did not finish within five minutes on the 100,000-node Barabási-Albert pair, on a 10,000-node 3-regular pair or on a 100 by 100 lattice.

Subgraphs of a Barabási-Albert network with 100,000 nodes and 500,000 edges: whether it contains a pattern of 3 to 7 nodes (triangle, 4-cycle, 6-path, 5-star, 6-wheel, 5- and 7-cliques) takes 0.15 to 0.45 s exactly and 0.1 to 0.3 s approximately, mostly spent building and filtering the candidates; igraph’s VF2 answers in milliseconds when the pattern is there, but takes 4.5 s and 2.4 s to rule out the cliques. The approximate test accepts both cliques, which are absent: neighborhood filtering does not see them. Listing every mapping with isomorphisms(): 3,960 for the triangle in 0.7 s (igraph’s VF2 counts them in 9.8 s), 60,184 for the 4-cycle in 8.6 s (igraph: 232 s).

On a GPU, the approximate tests and the first rounds of color refinement of the exact isomorphism test run there; the searches always run on the CPU.
