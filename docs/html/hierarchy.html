Hierarchy

Hierarchy in directed networks: how far the nodes are organized in levels, with some nodes reaching (or controlling) many others and being reached by few.

global_reach_centrality() measures it from the local reaching centrality of the nodes (see centrality); flow_hierarchy() from the edges (or nodes) in no directed cycle, through which flows only go one way; arborescence_hierarchy() from the edges that survive the reduction of the network to an arborescence; agony_hierarchy() from the agony of the best division of the nodes into levels.

import graphoskop as gsk

net = gsk.load_network("edges.tsv", directed = True)
gsk.global_reach_centrality(net)
gsk.flow_hierarchy(net)                    # fraction of edges in no cycle
gsk.flow_hierarchy(net, by = "nodes")      # fraction of nodes in no cycle
gsk.arborescence_hierarchy(net)            # fraction of edges left in the arborescence
score, forest = gsk.arborescence_hierarchy(net, arborescence = True)
h, levels = gsk.agony_hierarchy(net, ranks = True)   # 1 - agony / number of edges, levels
graphoskop.agony_hierarchy(net, component=0, weight=None, ranks=False)

Agony (Gupte et al., 2011; Tatti, 2015), a measure of hierarchy: the levels of the nodes, 0 at the top, are chosen so that edges point from higher to lower levels as much as possible. An edge from \(u\) to \(v\) costs nothing if \(v\) is at least one level below \(u\), and otherwise its agony \(r(u) - r(v) + 1\) (times its weight), so the agony of the network is

\[A(G) = \min_r \sum_{(u, v) \in E} w_{uv} \max\left(0, r(u) - r(v) + 1\right),\]

and its hierarchy \(h = 1 - A(G) / W\), with \(W\) the total weight of the edges (their number without weight): 1 for a directed acyclic graph, 0 when every edge is in a directed cycle that cannot be ordered (e.g. a directed cycle, whose agony is its length). Self loops always cost their weight; parallel edges add their weights.

The minimum is a linear program whose dual is a maximum circulation: \(A(G)\) is the largest total flow of a circulation in which each edge carries at most its weight (for unit weights, the largest Eulerian subgraph). It is solved exactly by HiGHS (scipy.optimize.linprog(): interior point with crossover, or dual simplex if needed; on the CPU), one component at a time, and the levels are the dual values of the flow conservation constraints, integers (the network matrix is totally unimodular), shifted so that the top level is 0. The levels found are one optimal ranking among possibly many. The time grows faster than the number of edges: about 4 s for 100,000 edges and 20 s for 300,000 on two CPU cores.

Hypergraphs and simplicial complexes: not supported (see Higher-order networks).

Parameters:

  • net – A directed Network.

  • component – Index of the component (0 is the largest), or None for all components (agonies and weights summed).

  • weight – Name of the edge attribute used as edge weight, or None for unit weights.

  • ranks – Whether to also return the levels.

Returns:

The hierarchy \(h\), a float (NaN without edges); with ranks, the pair (h, levels), the levels an int64 vector over the nodes of the component, on its device (a list of them, one per component, with component = None). The agony is \((1 - h) W\).

Raises:

  • ValueError – If the network is undirected or weights are negative.

  • RuntimeError – If the linear program solver fails.

Example:

h = gsk.agony_hierarchy(net)
h, levels = gsk.agony_hierarchy(net, weight = "weight", ranks = True)
net.set_node_attribute("level", levels)
graphoskop.arborescence_hierarchy(net, component=0, arborescence=False)

Arborescence hierarchicalness (Coscia, 2018): the fraction of the edges of a directed network that survive its reduction to an arborescence (a forest of trees with edges pointing away from their roots), \(A_G = |E^*| / |E|\). It is 1 for a network that already is an arborescence, and close to 0 for a network that is one big cycle.

The reduction has two steps. First, the condensation: every strongly connected component collapses into one node, its internal edges are lost, and the edges between two components become one (see network_condensation()). Then, every node with several parents keeps only the edge from the parent with the lowest closeness, \(1 / \sum_j d(i, j)\) over the nodes \(j\) it reaches (0 for nodes reaching none): the parent closest to the roots. As every node with a parent keeps exactly one edge, \(|E^*|\) is the number of nodes of the condensation with at least one parent, so the score needs only the strongly connected components (found on the CPU, \(O(n + m)\)); the closeness, a search from every node of the condensation (as in closeness_centrality()), is computed only to return the arborescence, and is the costly part. Edges point from higher to lower levels: to read them the other way, reverse them with flip_edge_direction(). \(|E|\) counts the distinct edges of the network (parallel edges once, self loops included).

Hypergraphs and simplicial complexes: not supported (see Higher-order networks).

Parameters:

  • net – A directed Network, not multilayer.

  • component – Index of the component (0 is the largest), or None for the whole network.

  • arborescence – Whether to also return the arborescence.

Returns:

The score, a float between 0 and 1 (NaN without edges); with arborescence, the pair (score, forest), the forest a directed Network whose node i collapses the i-th strongly connected component of the network considered (largest first), with the qualitative node attribute members holding its nodes.

Raises:

ValueError – If the network is undirected or multilayer.

Example:

gsk.arborescence_hierarchy(net)                        # largest component
score, forest = gsk.arborescence_hierarchy(net, component = None, arborescence = True)
forest.get_node_attribute("members", None)             # nodes of each condensed node
graphoskop.flow_hierarchy(net, component=0, weight=None, by='edges')

Flow hierarchy (Luo and Magee, 2011), a measure of hierarchy: the fraction of the edges that are in no directed cycle, i.e. that join two different strongly connected components (a self loop is a cycle). It is 1 for a directed acyclic graph, where flows only go down the levels, and 0 when every edge is in a cycle (e.g. a strongly connected network).

With weight, the fraction of the total weight; with by = "nodes", the fraction of the nodes in no cycle (alone in their strongly connected component, without self loop) instead of the edges. Strongly connected components are found on the CPU (scipy.sparse.csgraph.connected_components()); in multilayer networks on the supra-graph. With component = None all components count.

Hypergraphs and simplicial complexes: not supported (see Higher-order networks).

Parameters:

  • net – A directed Network.

  • component – Index of the component (0 is the largest), or None for all components.

  • weight – Name of the edge attribute used as edge weight, or None for unit weights (ignored with by = "nodes").

  • by – "edges" (as in the paper) or "nodes".

Returns:

The flow hierarchy, a float between 0 and 1 (NaN without edges, or without nodes).

Raises:

ValueError – If the network is undirected, by is not valid, or weights are negative.

Example:

gsk.flow_hierarchy(net)                            # fraction of edges in no cycle
gsk.flow_hierarchy(net, component = None, weight = "weight")
gsk.flow_hierarchy(net, by = "nodes")              # fraction of nodes in no cycle
graphoskop.global_reach_centrality(net, component=0, direction='out', lengths=None, n_jobs=None)

Global reaching centrality (Mones, Vicsek and Vicsek, 2012), a measure of hierarchy: how much the most reaching node exceeds the others, \(GRC = \sum_i (C_R^{max} - C_R(i)) / (N - 1)\), with \(C_R\) the local reaching centrality of reach_centrality() and \(C_R^{max}\) its largest value. It is 1 for a star with edges out of its center and 0 when every node reaches all the others (e.g. a directed cycle). With component = None the sum and the maximum run over all components.

Hypergraphs and simplicial complexes: not supported (see Higher-order networks).

Parameters:

  • net – A directed Network.

  • component – Index of the component (0 is the largest), or None for all components at once.

  • direction – "out" (nodes reached) or "in" (nodes reaching).

  • lengths – Precomputed lengths, as for reach_centrality(), or None.

  • n_jobs – Number of processes for the searches, None for all CPUs.

Returns:

The global reaching centrality, a float.

Raises:

ValueError – If the network is undirected, direction is not valid, or lengths does not match.

Example:

gsk.global_reach_centrality(net)                    # largest component
