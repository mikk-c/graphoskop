Graphoskop
==========

.. automodule:: graphoskop

The documentation follows `The Atlas for the Aspiring Network Scientist
<https://www.networkatlas.eu/>`_, the textbook graphoskop accompanies (version two, whose numbering
is used throughout). The first pages present the network object, file formats and transformations;
the others follow the parts and chapters of the Atlas, in its order, and the graphical interface
comes last. Lines starting with *Atlas* give the chapters and sections where the concepts of a page
or section are explained.
