Transformations

Transformations of a network into another network.

to_undirected() symmetrizes a directed network: all the edges between two nodes, in either direction, become one undirected edge, whose attributes combine theirs. remove_isolates() drops the nodes without edges, remove_self_loops() the edges from a node to itself, remove_parallel_edges() merges the edges between the same two nodes. subgraph() keeps a set of nodes and the edges between them, ego_network() the neighbors of a node and the edges between them, to_strongly_connected() the edges within strongly connected components. add_nodes(), add_edges(), remove_nodes() and remove_edges() add or remove nodes and edges, one or many at once. flip_edge_direction() reverses some or all of the edges of a directed network.

clique_promotion() makes a simplicial complex or a hypergraph from the cliques of a network, and clique_expansion() goes back: the network of the nodes sharing a hyperedge or a facet (see Higher-order networks).

network_union(), network_difference() and network_intersection() combine the edges of two networks with the same node ids. quotient_network() collapses sets of nodes into single nodes, and network_condensation() the strongly connected components of a directed network.

import graphoskop as gsk

net = gsk.load_network("trust.tsv", directed = True)          # columns weight, sign
und = gsk.to_undirected(net)                                    # weights summed: A + A^T
und = gsk.to_undirected(net, combine = "max", disagree = "positive")
core = gsk.remove_isolates(net)                                 # nodes without edges dropped
clean = gsk.remove_isolates(gsk.remove_self_loops(net))         # no self loops, then no isolates
simple = gsk.remove_parallel_edges(net)                         # one edge per pair (per direction)
sub = gsk.subgraph(net, ["alice", "bob", "carol"])              # induced subgraph
ego = gsk.ego_network(net, "alice")                             # alice, her neighbors, their edges
alters = gsk.ego_network(net, "alice", include_ego = False)     # without alice and her edges
scc = gsk.to_strongly_connected(net)                            # one component per strongly connected component
rev = gsk.flip_edge_direction(net)                              # all edges reversed: A^T
rev = gsk.flip_edge_direction(net, ("alice", "bob"))            # only alice -> bob, now bob -> alice

Nodes and edges are added or removed one at a time, from any iterable, or from a pandas.DataFrame table. Missing attributes are NaN, except edge weights, which default to 1.

import pandas as pd

net = gsk.add_nodes(net, "dave")                                # node attributes NaN
net = gsk.add_nodes(net, pd.DataFrame({"id": ["erin"], "age": [41]}))
net = gsk.add_edges(net, [("alice", "dave"), ("dave", "frank")])   # weight 1, frank added
net = gsk.add_edges(net, pd.DataFrame({"source": ["bob"], "target": ["erin"], "weight": [2.5]}))
net = gsk.remove_edges(net, ("alice", "bob"))                   # all edges between them
net = gsk.remove_nodes(net, ["carol", "dave"])                  # with their edges

See also layer_network() and aggregate_network() for multilayer networks, and signed_network().

graphoskop.ego_network(net, ego, include_ego=True, direction='out')

Ego network: the subgraph induced by a node (the ego) and its neighbors, with all the edges among them; with include_ego = False, only the neighbors and the edges among them, the ego and its edges being removed.

Attributes, node types, node table format, directedness and device are kept, and components are recomputed, as in subgraph() (without the ego, the neighbors can fall apart in several components). In multilayer networks the neighbors are those in the supra-graph (couplings included), and an entity given as ego stands for all its copies, which are all egos.

Hypergraphs and simplicial complexes: not supported (see Higher-order networks).

Parameters:

  • net – A Network.

  • ego – The ego (input id, internal id (component, index), or entity in multilayer networks).

  • include_ego – Whether to keep the ego and its edges.

  • direction – In directed networks, the neighbors: "out" (nodes the ego points to), "in" (nodes pointing to the ego) or "both"; ignored otherwise.

Returns:

The ego network, a new Network.

Raises:

  • KeyError – If there is no such node.

  • ValueError – If direction is not valid.

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv", "nodes.tsv")
ego = gsk.ego_network(net, "alice")                         # alice, her friends, their edges
alters = gsk.ego_network(net, "alice", include_ego = False) # how her friends know each other
graphoskop.flip_edge_direction(net, edges=None)

Directed network with some or all of its edges reversed: an edge from a to b becomes an edge from b to a, with the same attributes.

Without edges, all the edges are reversed (the transpose of the adjacency matrix). Otherwise edges is one edge (u, v), an iterable of them, or a pandas.DataFrame with the endpoints in the first two columns, as in remove_edges(): all the edges from u to v are reversed, parallel edges included, and the edges from v to u, if any, are not. In multilayer networks, an entity stands for all its copies, and a table with layer columns gives copies, as in remove_edges().

Reversing edges never changes the weakly connected components, so components, internal ids (component, index), node attributes, node types and device stay the same, and so does the order of the edges. Tensors are copied, so changing one network does not change the other.

Hypergraphs and simplicial complexes: not supported (see Higher-order networks).

Parameters:

  • net – A directed Network.

  • edges – None for all the edges, or an edge (u, v), an iterable of edges, or a pandas.DataFrame.

Returns:

The network with the edges reversed, a new Network.

Raises:

  • ValueError – If the network is undirected, or an edge is not a pair.

  • KeyError – If a node or an edge is not in the network.

Example:

import graphoskop as gsk

net = gsk.load_network("follows.tsv", directed = True)   # a -> b: a follows b
followed = gsk.flip_edge_direction(net)                 # b -> a: b is followed by a
net = gsk.flip_edge_direction(net, ("alice", "bob"))    # now bob -> alice
net = gsk.flip_edge_direction(net, [("bob", "carol"), ("carol", "dave")])
graphoskop.remove_isolates(net)

Network without its isolated nodes.

An isolated node has no edges at all; a node whose only edge is a self loop is not isolated. Since every isolated node is a component on its own, the other components are kept unchanged, in the same order, with the same node and edge attributes, node types and device; only their positions in the list of components can shift (isolated nodes are among the smallest components, so the largest ones keep their index). Their tensors are copied, so changing one network does not change the other.

In multilayer networks a copy is isolated if it has no edges, couplings and other interlayer edges included; a copy coupled to the other copies of its entity is not isolated.

Hypergraphs and simplicial complexes: not supported (see Higher-order networks).

Parameters:

net – A Network.

Returns:

The network without isolated nodes, a new Network (with the same nodes, copied, if there are none).

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv", "nodes.tsv")   # nodes.tsv lists nodes without edges too
core = gsk.remove_isolates(net)
core.number_of_nodes() <= net.number_of_nodes()     # True
graphoskop.remove_parallel_edges(net, combine='sum', sign='sign', disagree='zero')

Network without parallel edges: all the edges between the same two nodes become one edge, whose attributes combine theirs.

In directed networks, parallel edges have the same source and the same target: the edges \(u \to v\) and \(v \to u\) are not parallel and both stay (use to_undirected() to merge them). In undirected networks, \(u - v\) and \(v - u\) are the same edge. Self loops of a node are parallel to each other. In multilayer networks the endpoints are copies (entity, layer), so only edges within the same layer are merged (and interlayer edges between the same two copies), never edges of different layers.

Each numeric edge attribute of a merged edge combines the values of its edges, ignoring NaN, as in to_undirected(): "sum" (weights then give the same adjacency matrix and Laplacians), "mean" or "max"; each qualitative one keeps their distinct values (one value, or a tuple of them). The sign attribute (see Signed networks) keeps the common sign of the edges, and disagree decides when they have both signs: "positive", "negative" or "zero". A merged edge keeps the position and orientation of the first of its edges.

Merging parallel edges never changes which nodes are connected, so nodes, components, internal ids, node attributes, node types and device are kept, and all the work runs on the device of the network. Tensors are copied, so changing one network does not change the other.

Hypergraphs and simplicial complexes: not supported (see Higher-order networks).

Parameters:

  • net – A Network.

  • combine – "sum", "mean" or "max".

  • sign – Name of the sign edge attribute (ignored if the network has no such attribute).

  • disagree – "positive", "negative" or "zero".

Returns:

The network without parallel edges, a new Network.

Raises:

ValueError – If combine or disagree is not valid.

Example:

import graphoskop as gsk

net = gsk.load_network("emails.tsv", directed = True)    # one row per email
simple = gsk.remove_parallel_edges(net)                   # one edge per sender and receiver, weights summed
simple = gsk.remove_parallel_edges(net, combine = "max")
graphoskop.remove_self_loops(net)

Network without its self loops (edges from a node to itself).

All nodes are kept, so a node whose only edges were self loops becomes isolated (follow with remove_isolates() to drop it as well). Removing self loops never splits a component, so components, internal ids (component, index), node attributes, node types and device stay the same, and so do the attributes of the other edges. Tensors are copied, so changing one network does not change the other. In multilayer networks self loops are intra-layer edges from a copy to itself.

Hypergraphs and simplicial complexes: not supported (see Higher-order networks).

Parameters:

net – A Network.

Returns:

The network without self loops, a new Network.

Example:

import graphoskop as gsk

net = gsk.load_network("replies.tsv", directed = True)   # people replying to themselves
clean = gsk.remove_isolates(gsk.remove_self_loops(net))
graphoskop.subgraph(net, nodes)

Subgraph induced by a set of nodes: those nodes, with their attributes, and the edges between them, with theirs.

Components are recomputed, so they are those of the subgraph; node types (bipartite networks), node table format, directedness and device are kept. In multilayer networks nodes are copies (entity, layer), and an entity stands for all its copies; interlayer edges (couplings included) between kept copies are kept.

Hypergraphs and simplicial complexes: not supported (see Higher-order networks).

Parameters:

  • net – A Network.

  • nodes – Iterable of nodes (input ids, internal ids (component, index), or entities in multilayer networks), for example one of the arrays of connected_components_nodes().

Returns:

The subgraph, a new Network.

Raises:

KeyError – If a node does not exist.

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv", "nodes.tsv")
ego = gsk.subgraph(net, ["alice", "bob", "carol"])
graphoskop.to_strongly_connected(net)

Directed network split into its strongly connected components: the edges between different strongly connected components are dropped, so that each of them becomes a component of its own (see connected_components_count()).

All nodes and their attributes are kept (a node in no directed cycle becomes isolated), and so are the attributes of the remaining edges, node types, node table format and device. In multilayer networks the strongly connected components are those of the supra-graph.

Hypergraphs and simplicial complexes: not supported (see Higher-order networks).

Parameters:

net – A directed Network.

Returns:

The network split into strongly connected components, a new Network; its components are sorted by size as usual.

Raises:

ValueError – If net is undirected (its components are already strongly connected).

Example:

import graphoskop as gsk

net = gsk.load_network("follows.tsv", directed = True)
scc = gsk.to_strongly_connected(net)
scc.number_of_components() == gsk.connected_components_count(net, type = "strong")   # True
graphoskop.to_undirected(net, combine='sum', sign='sign', disagree='zero')

Undirected version of a directed network.

All the edges between the same two nodes, in either direction (parallel edges included), are merged into one undirected edge; self loops of a node are merged into one self loop. Each numeric edge attribute of the merged edge combines the values of its edges, ignoring NaN:

  • "sum": their sum, so that weights give \(A + A^T\);

  • "mean": their mean (an edge in one direction only keeps its value);

  • "max": their maximum.

Each qualitative edge attribute keeps the distinct values of the merged edges: the value if they all have the same (missing values aside), a tuple of the distinct values otherwise.

The sign attribute (if the network has one, see Signed networks) is not combined: if all the merged edges have the same sign, the edge keeps it; if some are positive and some negative, disagree decides: "positive" (+1), "negative" (-1) or "zero" (0, which signed analyses treat as no edge). Edges with sign 0 or NaN do not count as disagreeing.

Nodes and node attributes are kept, isolated nodes included, and so are node types (bipartite networks) and the device. In multilayer networks intra-layer edges are merged within each layer, and interlayer edges (couplings included) between the same two copies are merged too.

Hypergraphs and simplicial complexes: not supported (see Higher-order networks).

Parameters:

  • net – A directed Network.

  • combine – "sum", "mean" or "max".

  • sign – Name of the sign edge attribute (ignored if the network has no such attribute).

  • disagree – "positive", "negative" or "zero".

Returns:

The undirected network, a new Network.

Raises:

ValueError – If net is undirected, or combine or disagree is not valid.

Example:

import graphoskop as gsk

net = gsk.load_network("trust.tsv", directed = True)           # columns weight, sign
und = gsk.to_undirected(net, combine = "mean", disagree = "negative")
und.get_edge_attribute("weight", edge = ("alice", "bob"))       # mean of both directions

Adding and removing nodes and edges

graphoskop.add_edges(net, edges, weight='weight')

Network with new edges.

edges is one edge (u, v), an iterable of them (e.g. a list of pairs, or a two column array), or a pandas.DataFrame edge table: source and target in the first two columns, then one column per edge attribute (non-numeric columns are ignored, as in load_network()). A tuple is always one edge. New edges get NaN for every attribute they are not given, except weight, which defaults to 1: if the network or the new edges have an attribute named weight, new edges without a value get 1, and so do the existing edges if the attribute is new (they were unweighted). Columns that are not attributes of the network become new attributes, NaN for the existing edges.

Endpoints not in the network are added as new nodes, with NaN (missing) for every node attribute, as in add_nodes(). Adding an edge that already exists adds a parallel edge (see remove_parallel_edges()). In undirected networks (u, v) and (v, u) are the same edge.

In multilayer networks the endpoints are copies (entity, layer): an edge between copies in the same layer is an intra-layer edge, otherwise an interlayer edge (a coupling if they are copies of the same entity). A table is given as an edge table (source, target, a layer column, then attributes) or as an interlayer table (source, source_layer, target, target_layer, then attributes), as written by to_pandas_dataframes(). Layers not in layer_labels are appended to the layer order. In bipartite networks new edges must join nodes of different types, and new endpoints need a type, so they must be added first with add_nodes().

Components are recomputed, since new edges can join them; node and edge attributes, node types, node table format and device are kept.

Hypergraphs and simplicial complexes: not supported (see Higher-order networks).

Parameters:

  • net – A Network.

  • edges – An edge (u, v), an iterable of edges, or a pandas.DataFrame.

  • weight – Name of the edge attribute holding the weights, or None to give no default weight.

Returns:

The network with the new edges, a new Network.

Raises:

ValueError – If an edge is not a pair, if an endpoint of a multilayer network is not a copy (entity, layer), or, in bipartite networks, if an edge joins two nodes of the same type or a new endpoint has no node type.

Example:

import graphoskop as gsk
import pandas as pd

net = gsk.load_network("edges.tsv")                           # attribute weight
net = gsk.add_edges(net, ("alice", "dave"))                    # weight 1, dave is a new node
net = gsk.add_edges(net, [("bob", "carol"), ("carol", "dave")])
net = gsk.add_edges(net, pd.DataFrame({"source": ["alice"], "target": ["erin"], "weight": [2.5]}))
graphoskop.add_nodes(net, nodes)

Network with new nodes, without edges (use add_edges() to connect them).

nodes is one node id, an iterable of node ids, or a pandas.DataFrame node table in the format of the network’s (net.node_format), as taken by load_network(): wide (node id, then one column per attribute) or long (node id, attribute name, value). A string or a tuple is always one node. New nodes get NaN (missing) for every attribute they are not given; in long (sparse) node tables, a numeric attribute without a value reads as 0. Columns that are not attributes of the network become new attributes, NaN for the existing nodes.

In multilayer networks every new node is a copy (entity, layer): tuples, or a table with the entity in the first column and the layer in the second. Layers not in layer_labels are appended to the layer order. In bipartite networks new nodes must have a value of BIPARTITE, so they are given as a table.

Every new node is a component of its own; the existing components, node and edge attributes, node types, node table format and device are kept.

Hypergraphs and simplicial complexes: not supported (see Higher-order networks).

Parameters:

  • net – A Network.

  • nodes – A node id, an iterable of node ids, or a pandas.DataFrame.

Returns:

The network with the new nodes, a new Network.

Raises:

ValueError – If a node is already in the network, if a node of a multilayer network is not a copy (entity, layer), or if a new node of a bipartite network has no node type.

Example:

import graphoskop as gsk
import pandas as pd

net = gsk.load_network("edges.tsv", "nodes.tsv")            # attributes age, city
net = gsk.add_nodes(net, "dave")                              # age NaN, city NaN
net = gsk.add_nodes(net, ["erin", "frank"])
net = gsk.add_nodes(net, pd.DataFrame({"id": ["gina"], "age": [41]}))   # city NaN
graphoskop.remove_edges(net, edges)

Network without some edges.

edges is one edge (u, v), an iterable of them, or a pandas.DataFrame with the endpoints in the first two columns (e.g. an edge table; other columns are ignored). A tuple is always one edge. All the edges from u to v are removed, parallel edges included; in undirected networks, also those from v to u. Endpoints are given as in remove_nodes(). In multilayer networks, an entity stands for all its copies, so (u, v) between two entities removes the edges between their copies in every layer and across layers; a table with a layer column, or with source_layer and target_layer columns, gives copies, as written by to_pandas_dataframes().

All nodes are kept, so a node can become isolated (follow with remove_isolates() to drop it). Components are recomputed, since removing an edge can split one; the attributes of the nodes and of the other edges, node types, node table format and device are kept.

Hypergraphs and simplicial complexes: not supported (see Higher-order networks).

Parameters:

  • net – A Network.

  • edges – An edge (u, v), an iterable of edges, or a pandas.DataFrame.

Returns:

The network without the edges, a new Network.

Raises:

  • KeyError – If a node or an edge is not in the network.

  • ValueError – If an edge is not a pair.

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv")
net = gsk.remove_edges(net, ("alice", "bob"))
net = gsk.remove_edges(net, [("bob", "carol"), ("carol", "dave")])
graphoskop.remove_nodes(net, nodes)

Network without some nodes and their edges: the subgraph induced by all the other nodes (see subgraph()).

nodes is one node, an iterable of nodes, or a pandas.DataFrame whose first column gives the nodes (e.g. a node table); a string or a tuple is always one node. Nodes are input ids or internal ids (component, index); in multilayer networks, copies (entity, layer) or entities, which stand for all their copies (in a table, the entity is in the first column and the layer in the second, missing for all the copies).

Components are recomputed, since removing a node can split one; the attributes of the other nodes and edges, node types, node table format and device are kept.

Hypergraphs and simplicial complexes: not supported (see Higher-order networks).

Parameters:

  • net – A Network.

  • nodes – A node, an iterable of nodes, or a pandas.DataFrame.

Returns:

The network without the nodes, a new Network.

Raises:

KeyError – If a node is not in the network.

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv", "nodes.tsv")
net = gsk.remove_nodes(net, "alice")
net = gsk.remove_nodes(net, ["bob", "carol"])

Collapsing nodes

quotient_network() collapses sets of nodes into single nodes, merging the edges between them; network_condensation() collapses the strongly connected components of a directed network, giving a directed acyclic graph.

blocks = gsk.quotient_network(net, [{"alice", "bob"}, {"carol", "dave"}])   # nodes 0 and 1
blocks = gsk.quotient_network(net, [{"alice", "bob"}], self_loops = False)
dag = gsk.network_condensation(net)   # node i: i-th strongly connected component
graphoskop.network_condensation(net, combine='sum', node_combine='mean')

Condensation of a directed network: each strongly connected component collapses into a single node, giving a directed acyclic graph (see quotient_network()).

The node collapsing the strongly connected component at position i of connected_components_nodes() (type = "strong", largest first) has id i. The edges between two strongly connected components are merged into one, combining their attributes with combine; the edges within them are dropped. Numeric node attributes combine with node_combine and qualitative ones keep all their distinct values, as in quotient_network().

Hypergraphs and simplicial complexes: not supported (see Higher-order networks).

Parameters:

  • net – A directed Network, not multilayer.

  • combine – "sum", "mean" or "max", for the edge attributes.

  • node_combine – "sum", "mean" or "max", for the numeric node attributes.

Returns:

The condensation, a new directed Network.

Raises:

ValueError – If net is undirected or multilayer (strongly connected components of the supra-graph mix copies of different layers), if combine or node_combine is not valid, or if a strongly connected component of a bipartite network has nodes of both types.

Example:

import graphoskop as gsk

net = gsk.load_network("citations.tsv", directed = True)
dag = gsk.network_condensation(net)
sccs = gsk.connected_components_nodes(net, type = "strong")   # sccs[i] collapsed into node i
graphoskop.quotient_network(net, sets, combine='sum', node_combine='mean', self_loops=True)

Quotient network: the nodes of each set collapse into a single node.

sets is a list of sets (or lists, tuples, arrays) of nodes; nodes in no set stay as they are. The nodes collapsing the sets get integer ids, in the order of the list, counting from 0 and skipping the integers that are ids of nodes in no set: set i gets id i unless some of these integers are taken (with ids [0, 2] left out of the sets, three sets get 1, 3 and 4). Each edge joins the nodes its endpoints collapse into; the edges then joining the same two nodes are merged into one, combining their attributes with combine, as in remove_parallel_edges() (also merging the parallel edges of net). Edges within a set become self loops of its node, or are dropped with self_loops = False. With combine = "sum" and weights, the adjacency matrix of the quotient is \(P^T A P\), with \(P\) the node-to-set membership matrix.

The numeric node attributes of a collapsed node combine those of its nodes with node_combine, ignoring missing values (and, in long sparse node tables, nodes without a value); its qualitative attributes have all the distinct values of its nodes, several values being stored as for overlapping communities (see Several values per node: overlapping communities). In bipartite networks, a set must have nodes of a single type.

In multilayer networks the sets hold entities: the copies of the entities of a set collapse, layer by layer, into the copies of a new entity, and interlayer edges are merged like the others (the couplings of the entities of a set become the couplings of the new entity). Components are recomputed; node table format, node types and device are kept.

Hypergraphs and simplicial complexes: not supported (see Higher-order networks).

Parameters:

  • net – A Network.

  • sets – List of iterables of nodes (input ids; entities in multilayer networks), disjoint.

  • combine – "sum", "mean" or "max", for the edge attributes.

  • node_combine – "sum", "mean" or "max", for the numeric node attributes.

  • self_loops – Keep the edges within a set, as self loops of its node.

Returns:

The quotient network, a new Network.

Raises:

  • KeyError – If a node is not in the network.

  • ValueError – If a node is in two sets, if combine or node_combine is not valid, or if a set has nodes of both types of a bipartite network.

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv", "nodes.tsv")
teams = gsk.quotient_network(net, [{"alice", "bob"}, {"carol", "dave", "erin"}])   # nodes 0 and 1
blocks = gsk.quotient_network(net, communities, self_loops = False)

Combining networks

Set operations on the edges of two networks with the same node ids: two edges are the same if they join the same two nodes. Attributes come from the first network, completed by the second.

both = gsk.network_union(week1, week2)            # edges of either
gone = gsk.network_difference(week1, week2)       # edges of week1 not in week2
kept = gsk.network_intersection(week1, week2)     # edges of week1 also in week2
graphoskop.network_difference(net, other)

Difference of two networks: net without the edges of other.

The two networks are assumed to use the same node ids for the same nodes. An edge of net is removed, with its parallel edges, if other has an edge joining the same two nodes (in either direction, in undirected networks; in multilayer networks, the same two copies (entity, layer)). All the nodes of net are kept, with their attributes, and so are the attributes of the remaining edges; other only gives the edges to remove (its nodes not in net are ignored). Components are recomputed.

Hypergraphs and simplicial complexes: not supported (see Higher-order networks).

Parameters:

  • net – A Network.

  • other – A Network, directed if net is, multilayer if net is.

Returns:

The difference, a new Network.

Raises:

ValueError – If the networks differ in directedness, or one is multilayer and the other is not.

Example:

import graphoskop as gsk

week1 = gsk.load_network("calls_week1.tsv")

graphoskop.network_intersection(net, other)

Intersection of two networks: the nodes of both, and the edges of net joining two nodes that other also joins.

The two networks are assumed to use the same node ids for the same nodes. Two edges are the same if they join the same two nodes (in either direction, in undirected networks; in multilayer networks, the same two copies (entity, layer)). The edges kept are those of net, with their attributes (parallel edges included). Nodes keep their attributes in net; the values they do not have there come from other. Components are recomputed; node table format, node types and device are those of net.

Hypergraphs and simplicial complexes: not supported (see Higher-order networks).

Parameters:

  • net – A Network.

  • other – A Network, directed if net is, multilayer if net is, and bipartite if net is.

Returns:

The intersection, a new Network.

Raises:

ValueError – If the networks differ in directedness, or one is multilayer or bipartite and the other is not.

Example:

import graphoskop as gsk

week1 = gsk.load_network("calls_week1.tsv")
week2 = gsk.load_network("calls_week2.tsv")
stable = gsk.network_intersection(week1, week2)   # pairs calling in both weeks
graphoskop.network_union(net, other)

Union of two networks: the nodes and the edges of either.

The two networks are assumed to use the same node ids for the same nodes. Two edges are the same if they join the same two nodes (in either direction, in undirected networks; in multilayer networks, the same two copies (entity, layer)). The union has all the edges of net, as they are (parallel edges included), and the edges of other joining two nodes that net does not join. Each edge keeps the attributes of its network; attributes of the other network are NaN, except "weight", which is 1 for the edges of a network without it, as in add_edges(). To add up the weights of the edges in both, use add_edges() with the edge table of other, then remove_parallel_edges().

Nodes keep their attributes in net; the values they do not have there come from other, and nodes only in other keep theirs. In multilayer networks, layers only in other are appended to the layer order. Components are recomputed; node table format, node types and device are those of net.

Hypergraphs and simplicial complexes: not supported (see Higher-order networks).

Parameters:

  • net – A Network.

  • other – A Network, directed if net is, multilayer if net is, and bipartite if net is.

Returns:

The union, a new Network.

Raises:

ValueError – If the networks differ in directedness, or one is multilayer or bipartite and the other is not.

Example:

import graphoskop as gsk

week1 = gsk.load_network("calls_week1.tsv")
week2 = gsk.load_network("calls_week2.tsv")
both_weeks = gsk.network_union(week1, week2)

Higher-order networks

clique_promotion() turns the maximal cliques of a network into the facets of a simplicial complex (its clique complex) or into hyperedges; clique_expansion() goes back, from a hypergraph or a simplicial complex to the network of the nodes sharing a hyperedge or a facet (for a simplicial complex, its 1-skeleton). See Higher-order networks.

sc = gsk.clique_promotion(net)                          # simplicial complex
hg = gsk.clique_promotion(net, kind = "hypergraph")
back = gsk.clique_expansion(sc)                         # the edges of net, weighted by facets
graphoskop.clique_expansion(net, weight=None, batch_size=16777216)

Clique expansion of a hypergraph or simplicial complex: the plain network of its nodes, two nodes connected if they share a hyperedge (facet), with edge attribute "weight" the number of hyperedges they share (with weight, the sum over them of the products of the weights of their two memberships). In a simplicial complex this is the 1-skeleton: its edges are the edges of the complex, with the number of facets containing them as weight. In a directed hypergraph, the edges go from the tail nodes to the head nodes of every hyperedge, and the expansion is directed.

This is simple_count_projection() of incidence_network() on the nodes; the other bipartite projections apply the same way, e.g. hyperbolic_projection( incidence_network(net), "node") weighs every hyperedge by one over its size, as the hypergraph Laplacian of Zhou et al. (2006). Node attributes are kept; those of hyperedges and facets are dropped. Nodes sharing no hyperedge stay isolated. The number of edges grows with the squares of the hyperedge sizes: a hyperedge of 10,000 nodes gives 50 million edges.

Hypergraphs and simplicial complexes: supported (see Higher-order networks).

Parameters:

  • net – A Network, hypergraph or simplicial complex.

  • weight – Membership attribute used as weight, or None for unit weights.

  • batch_size – As in simple_count_projection().

Returns:

New Network, with edge attribute "weight".

Raises:

ValueError – If net is not a hypergraph or a simplicial complex.

Example:

import graphoskop as gsk

net = gsk.load_hypergraph([["a", "b", "c"], ["b", "c", "d"]])
g = gsk.clique_expansion(net)
g.get_edge_attribute("weight", edge = ("b", "c"))     # 2: they share two hyperedges
graphoskop.clique_promotion(net, kind='simplicial', batch_size=4194304)

Higher-order network from the cliques of a network: every maximal clique (a set of nodes all joined to each other, not contained in a larger one) becomes a facet of a simplicial complex (kind = "simplicial", the clique complex, or flag complex, of the network) or a hyperedge of a hypergraph (kind = "hypergraph"). Edges in no triangle are cliques of two nodes, and nodes without edges stay isolated nodes, so clique_expansion() gives back the edges of the network. Only maximal cliques are promoted: in a simplicial complex the smaller cliques are their faces; in a hypergraph they would repeat the same interactions.

Cliques are those of maximal_cliques(): edges are taken as undirected and unweighted, self loops and parallel edges are ignored. Node attributes are kept; edge attributes are not (a clique has many edges). Hyperedges are labeled by their positions, from 0, largest cliques first; the result is on the device of net. The number of maximal cliques can grow exponentially with the size of dense networks.

Hypergraphs and simplicial complexes: not supported (see Higher-order networks).

Parameters:

  • net – A Network, neither multilayer nor bipartite (a bipartite network has no triangles: load it as a hypergraph instead, with load_hypergraph()).

  • kind – "simplicial" or "hypergraph".

  • batch_size – Number of 2-paths expanded at once in the triangle enumeration.

Returns:

New Network, a simplicial complex or a hypergraph.

Raises:

ValueError – If kind is not valid, or net is multilayer or bipartite.

Example:

import graphoskop as gsk
import pandas as pd

# a square with one diagonal, and a pendant edge
edges = pd.DataFrame({"s": ["a", "b", "c", "d", "a", "d"], "t": ["b", "c", "d", "a", "c", "e"]})
net = gsk.load_network(edges)
sc = gsk.clique_promotion(net)                      # facets {a, b, c}, {a, c, d}, {d, e}
sc.number_of_facets()                                # 3
gsk.generalized_degree(sc, 2, 1, ["a", "c"])         # 2: the diagonal is in both triangles
hg = gsk.clique_promotion(net, kind = "hypergraph")
gsk.hyperedge_size(hg)                               # sizes 2 (once) and 3 (twice)
