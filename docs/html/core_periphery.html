Core-periphery structure

Core-periphery structure: a densely connected core of nodes, and a periphery of nodes connected to the core but hardly to each other.

The models of Borgatti and Everett (2000) compare the adjacency matrix \(A\) with an ideal pattern matrix \(\Delta\), built from how much each node belongs to the core, by their Pearson correlation \(\rho\) over all pairs of distinct nodes (ordered pairs in directed networks; self loops are ignored). The best core is the one maximizing \(\rho\).

  • Discrete model: each node is in the core (\(c_i = 1\)) or in the periphery (\(c_i = 0\)). Two core nodes should be connected (\(\delta_{ij} = 1\)), two peripheral nodes should not (\(\delta_{ij} = 0\)). Pairs of a core and a peripheral node should be connected ("present", \(\delta_{ij} = \max(c_i, c_j)\)), should not ("absent", \(\delta_{ij} = c_i c_j\)), or are left out of the correlation ("missing"), as chosen by core_periphery_ties.

  • Continuous model: each node has a coreness \(c_i \ge 0\), and the pattern is \(\delta_{ij} = c_i c_j\), so that pairs of more central nodes should be more connected.

The model of Rombach, Porter, Fowler and Mucha (2014), rombach_core_periphery(), generalizes the continuous one: core values follow a transition function with two parameters, the size of the core and the sharpness of its boundary, the edges of more central pairs are rewarded (by the product of the core values of their nodes, or by their \(p\)-norm), and the core scores aggregate the best assignments over a range of the two parameters.

The correlation is computed from sums over the edges and over the nodes, never from \(n^2\) pairs: for instance \(\sum_{i \ne j} c_i c_j = (\sum_i c_i)^2 - \sum_i c_i^2\). Without weight, \(a_{ij}\) is 1 for connected pairs (parallel edges count once); with it, the sum of the weights of the edges from \(i\) to \(j\). All the work runs on the device of the network, in double precision.

The discrete model is fit by local search: starting from a partition, nodes are moved between core and periphery while \(\rho\) increases. In each round the change of \(\rho\) for moving every node alone is computed at once, from how strongly each node is connected to the core; the nodes whose move improves \(\rho\) are sorted, and the number of them moved together is the best, computed exactly (accounting for the edges among them) in one pass, so that a round can move many nodes, and at least the best one. The search stops when no single move improves \(\rho\). Starting partitions are the best prefixes (the \(k\) first nodes in the core, the best \(k\) found in one pass over the edges) of the nodes sorted by strength, and of restarts orders by strength times a random log-normal factor (of standard deviation 1 on the log scale); the best result is kept. The paper used a genetic algorithm instead: both find local optima, not certainly the global one.

The continuous model is fit by L-BFGS, on \(c_i = x_i^2\) (so that coreness stays non negative), starting from the strengths, until ten iterations improve \(\rho\) by less than a fraction tol. Coreness is scaled to a largest value of 1, since \(\rho\) does not depend on the scale.

Nestedness, the core-periphery structure of bipartite networks, is measured by nestedness() (NODF, with a comparison with null models), and its isocline is found by nestedness_isocline() (see Nestedness).

In multilayer networks the supra-graph is used (couplings are edges like the others). Sparse tensors are built with invariant checks explicitly turned off (they are coalesced by construction), which also silences the warning some versions of PyTorch give. With component = None the whole network is one matrix: nodes of different components are pairs without edges.

import graphoskop as gsk

net = gsk.load_network("edges.tsv")
core, rho = gsk.discrete_core_periphery(net)                  # boolean vector, correlation
net.set_node_attribute("core", core)
core, rho = gsk.discrete_core_periphery(net, core_periphery_ties = "missing")
coreness, rho = gsk.continuous_core_periphery(net, weight = "weight")   # largest value 1
score, quality = gsk.rombach_core_periphery(net)               # core scores, R per (alpha, beta)
score, quality = gsk.rombach_core_periphery(net, alpha = 1, beta = 0.8, p = 2)

References:

  • S. P. Borgatti and M. G. Everett (2000), Models of core/periphery structures, Social Networks 21(4), 375-395, https://doi.org/10.1016/S0378-8733(99)00019-2.

  • M. P. Rombach, M. A. Porter, J. H. Fowler and P. J. Mucha (2014), Core-periphery structure in networks, SIAM Journal on Applied Mathematics 74(1), 167-190, https://doi.org/10.1137/120881683.

graphoskop.continuous_core_periphery(net, component=0, weight=None, tol=1e-05, max_iter=1000)

Continuous core-periphery model (Borgatti and Everett, 2000): the coreness of every node, non negative, such that the products \(c_i c_j\) best correlate with the network (see the module description).

Hypergraphs and simplicial complexes: not supported (see Higher-order networks).

Parameters:

  • net – A Network.

  • component – Index of the component (0 is the largest), or None for the whole network.

  • weight – Name of the edge attribute used as edge weight, or None for unit weights.

  • tol – The search stops when ten iterations improve \(\rho\) by less than this fraction.

  • max_iter – Largest number of L-BFGS iterations.

Returns:

(coreness, rho): a float64 vector over the nodes of the component, on its device, ordered by internal index (as node attributes), with largest value 1; or a list of them, one per component, with component = None. rho is the correlation reached (NaN without edges).

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv")
coreness, rho = gsk.continuous_core_periphery(net)
net.set_node_attribute("coreness", coreness)
graphoskop.discrete_core_periphery(net, component=0, core_periphery_ties='present', weight=None, restarts=10, seed=None)

Discrete core-periphery model (Borgatti and Everett, 2000): the division of the nodes into a core and a periphery that best correlates with the network (see the module description).

Hypergraphs and simplicial complexes: not supported (see Higher-order networks).

Parameters:

  • net – A Network.

  • component – Index of the component (0 is the largest), or None for the whole network.

  • core_periphery_ties – Ideal for the pairs of a core and a peripheral node: "present" (connected), "absent" (not connected) or "missing" (left out of the correlation).

  • weight – Name of the edge attribute used as edge weight, or None for unit weights.

  • restarts – Number of randomized starting partitions, besides the one from the strengths.

  • seed – Seed of the randomized starts, or None for a random seed.

Returns:

(core, rho): a boolean vector over the nodes of the component, on its device, ordered by internal index (as node attributes), True for the core; or a list of them, one per component, with component = None. rho is the correlation reached (NaN if no division has a correlation, e.g. without edges).

Raises:

ValueError – If core_periphery_ties is not valid.

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv")
core, rho = gsk.discrete_core_periphery(net)
net.set_node_attribute("core", core)
core, rho = gsk.discrete_core_periphery(net, core_periphery_ties = "missing", weight = "weight")
graphoskop.rombach_core_periphery(net, component=0, alpha=None, beta=None, p=None, weight=None, restarts=0, seed=None, max_iter=1000)

Core-periphery structure of Rombach, Porter, Fowler and Mucha (2014): a core score for every node, aggregated over a range of core shapes, from sharp to smooth and from large to small cores.

For a pair of parameters \((\alpha, \beta)\), the core values are those of the transition function, on the \(k\)-th node from the most peripheral

\[\begin{split}C^*_k = \begin{cases} \frac{k (1 - \alpha)}{2 \lfloor \beta n \rfloor} & k \le \lfloor \beta n \rfloor \\ \frac{(k - \lfloor \beta n \rfloor) (1 - \alpha)}{2 (n - \lfloor \beta n \rfloor)} + \frac{1 + \alpha}{2} & k > \lfloor \beta n \rfloor \end{cases}\end{split}\]

(normalized to sum 1): \(\beta\) is the fraction of nodes in the periphery, and \(\alpha\) the jump of the core values between periphery and core, 1 for a sharp boundary (core values 0 or 1), 0 for a smooth one. The values are assigned to the nodes so as to maximize the core quality \(R = \sum_{i, j} A_{ij} C_{ij}\), with \(C_{ij} = C_i C_j\), or, with p, the \(p\)-norm \(C_{ij} = (C_i^p + C_j^p)^{1 / p}\), under which a pair is as central as its most central node (as p grows). The core score of node \(i\) is \(CS(i) = Z \sum_{(\alpha, \beta)} C_i(\alpha, \beta) R(\alpha, \beta)\), with \(Z\) such that the largest score is 1.

The paper assigns values by simulated annealing on a grid of 100 by 100 pairs. Here, for all pairs at once on the device of the network, nodes start ranked by strength; then each node gets the value of its rank by the gradient of \(R\) (how much \(R\) grows with its core value), as long as this improves \(R\); then pairs of nodes swap values, in rounds, until a round improves \(R\) by less than one part in a million. Every node tries the nodes 1, 2, 4, 8, … ranks above and below it (all ranks in networks of at most 64 nodes) and the node whose value it would get by its gradient; the pairs that are each other’s best swap are swapped together. This finds local optima: restarts from random orders of the nodes may find better ones. Self loops are ignored; without weight, \(A_{ij}\) is 1 for connected pairs, with it, the sum of the weights; directed edges count in both directions, as the paper is for undirected networks. In multilayer networks the supra-graph is used. With the \(p\)-norm, the exact gain of a swap needs a pass over the edges of its two nodes, so every node tries only the partner with the best first order gain, and the search is slower than with the product.

Hypergraphs and simplicial complexes: not supported (see Higher-order networks).

Parameters:

  • net – A Network.

  • component – Index of the component (0 is the largest), or None for the whole network (nodes of different components are pairs without edges).

  • alpha – Value or iterable of values of \(\alpha\) in [0, 1]; None for 0.05, 0.1, …, 1.

  • beta – Value or iterable of values of \(\beta\) in [0, 1]; None for 0.05, 0.1, …, 1.

  • p – Exponent of the \(p\)-norm of core values (at least 1), or None for their product.

  • weight – Name of the edge attribute used as edge weight, or None for unit weights.

  • restarts – Number of random starting orders of the nodes, besides the one by strength; for each pair of parameters, the best assignment is kept.

  • seed – Seed of the random starts, or None for a random seed.

  • max_iter – Largest number of rounds of each phase of the search.

Returns:

(score, quality): the core scores, a float64 vector over the nodes of the component, on its device, ordered by internal index (as node attributes), with largest value 1 (or a list of them, one per component, with component = None); and a pandas.DataFrame with columns alpha, beta and R, the core quality reached for each pair.

Raises:

ValueError – If \(\alpha\) or \(\beta\) are not in [0, 1], or p is below 1.

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv")
score, quality = gsk.rombach_core_periphery(net)
net.set_node_attribute("core_score", score)
score, quality = gsk.rombach_core_periphery(net, alpha = 1, beta = 0.8)   # sharp core of 20%
score, quality = gsk.rombach_core_periphery(net, p = 2)

Nestedness

Nestedness of bipartite networks: the core-periphery structure of a biadjacency matrix in which the neighbors of each node are a subset of the neighbors of every node of the same type with more neighbors. Sorting rows and columns by decreasing degree, the ones of a perfectly nested matrix fill its top-left corner, up to a line, the isocline, beyond which there are only zeros.

Rows are the nodes of type 0 and columns the nodes of type 1 (see bipartite_labels), of all components, isolated nodes included; edges are unweighted (parallel edges count once) and their direction, if any, is ignored.

nestedness() measures NODF (Almeida-Neto et al., 2008): for every pair of rows with different degrees, the percentage of the neighbors of the row with fewer neighbors that are also neighbors of the other (0 for pairs with equal degrees), averaged over all pairs of rows and of columns. It is 100 for a perfectly nested matrix. Its significance is the comparison with the values of random matrices from a null model:

  • "equiprobable": the same number of ones, placed uniformly at random;

  • "proportional" (Bascompte et al., 2003): each cell is one, independently, with the mean of the densities of its row and of its column, \((k_i / C + k_j / R) / 2\);

  • "fixed": the same degrees for all nodes, by edge swaps (see edge_swap()).

The sum over pairs is computed without forming pairs: for every edge from row \(j\) to a column, the rows of that column with more neighbors than \(j\) each add \(1 / k_j\), and they are counted by sorting the edges, in \(O(m \log m)\) on the device of the network; the random matrices are all scored together.

nestedness_isocline() gives the isocline as the fill line of the nestedness temperature (Atmar and Patterson, 1993, as made explicit by Rodríguez-Gironés and Santamaría, 2006): with \(x\) the position of a column and \(y\) that of a row, both from 0 to 1 from the top-left corner, the ones are expected where \(y < f(x)\),

\[f(x) = 1 - \left(1 - (1 - x)^p\right)^{1 / p}, \quad \text{i.e.} \quad (1 - x)^p + (1 - y)^p = 1,\]

a quarter of a superellipse, symmetric between rows and columns. The area below it is \(1 - \Gamma(1 + 1 / p)^2 / \Gamma(1 + 2 / p)\): \(p = 1\) is the anti-diagonal (half of the matrix filled), larger \(p\) a smaller corner.

net = gsk.load_network("pollination.tsv", "species.tsv", bipartite = True)
gsk.nestedness(net)                                      # nodf, nodf_rows, nodf_columns
res = gsk.nestedness(net, null_model = "fixed", samples = 1000, seed = 1)
res["z"], res["p_value"]
iso = gsk.nestedness_isocline(net)                       # p, fill, rows, columns, line
iso = gsk.nestedness_isocline(net, method = "fit")

References:

  • M. Almeida-Neto, P. Guimarães, P. R. Guimarães Jr, R. D. Loyola and W. Ulrich (2008), A consistent metric for nestedness analysis in ecological systems: reconciling concept and measurement, Oikos 117(8), 1227-1239, https://doi.org/10.1111/j.0030-1299.2008.16644.x.

  • J. Bascompte, P. Jordano, C. J. Melián and J. M. Olesen (2003), The nested assembly of plant-animal mutualistic networks, PNAS 100(16), 9383-9387, https://doi.org/10.1073/pnas.1633576100.

  • W. Atmar and B. D. Patterson (1993), The measure of order and disorder in the distribution of species in fragmented habitat, Oecologia 96(3), 373-382, https://doi.org/10.1007/BF00317508.

  • M. A. Rodríguez-Gironés and L. Santamaría (2006), A new algorithm to calculate the nestedness temperature of presence-absence matrices, Journal of Biogeography 33(5), 924-935, https://doi.org/10.1111/j.1365-2699.2006.01444.x.

graphoskop.nestedness(net, null_model=None, samples=100, seed=None, progress=None)

NODF nestedness of a bipartite network, optionally compared with a null model (see the module description).

Hypergraphs and simplicial complexes: not supported (see Higher-order networks).

Parameters:

  • net – A bipartite Network.

  • null_model – "equiprobable", "proportional", "fixed", or None for no comparison.

  • samples – Number of random matrices of the null model.

  • seed – Seed of the random matrices, or None for a random seed.

  • progress – Whether to show a progress bar over the random matrices (None: as set by set_progress(); see Progress bars).

Returns:

A dictionary with nodf (between 0 and 100), nodf_rows and nodf_columns (the averages over pairs of rows, nodes of type 0, and over pairs of columns, nodes of type 1; NaN with fewer than two of them); with a null model also null_mean, null_std, z (the z-score of nodf; NaN if all random matrices have the same value, e.g. when the degrees allow only one matrix), p_value (the fraction of random matrices at least as nested, counting the network itself among them: \((1 + b) / (1 + \text{samples})\)) and null (the NODF of every random matrix, a NumPy array).

Raises:

ValueError – If the network is not bipartite or is multilayer, or null_model is not valid.

Example:

import graphoskop as gsk

net = gsk.load_network("pollination.tsv", "species.tsv", bipartite = True)
gsk.nestedness(net)["nodf"]
res = gsk.nestedness(net, null_model = "fixed", samples = 1000, seed = 1)
res["z"], res["p_value"]
graphoskop.nestedness_isocline(net, method='fill', points=101)

Isocline of the nested biadjacency matrix (see the module description): the line \((1 - x)^p + (1 - y)^p = 1\) separating the expected ones, in the top-left corner of the matrix with rows and columns sorted by decreasing degree, from the expected zeros.

With method = "fill", \(p\) makes the area below the line equal to the fill of the matrix (the fraction of ones), as in the nestedness temperature. With method = "fit", \(p\) makes the line closest (least squares) to the boundary of the ones of the sorted matrix if it were perfectly nested: column \(j\) (at \(x = (j - 0.5) / C\)) filled down to \(y = k_j / R\), row \(i\) (at \(y = (i - 0.5) / R\)) filled up to \(x = k_i / C\); its distance from the fill line shows how the ones are spread.

Hypergraphs and simplicial complexes: not supported (see Higher-order networks).

Parameters:

  • net – A bipartite Network.

  • method – "fill" or "fit".

  • points – Number of points of the line returned.

Returns:

A dictionary with p; fill; rows and columns, the input ids of the nodes of type 0 and of type 1 by decreasing degree (ties in network order), the order of the matrix; and line, a pandas.DataFrame of points points x, y of the line, for plotting. p is NaN for an empty or full matrix.

Raises:

ValueError – If the network is not bipartite or is multilayer, or method is not valid.

Example:

iso = gsk.nestedness_isocline(net)
iso["p"]
f = lambda x: 1 - (1 - (1 - x) ** iso["p"]) ** (1 / iso["p"])   # the line, as a function
iso["line"].plot(x = "x", y = "y")
