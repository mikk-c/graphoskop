Network error correction

Network error correction: inferring the true network behind noisy observations.

Observed networks have errors: spurious edges that are not there and missing edges that are. Network data can be cleaned in two separate steps, filtering out the weakest edges with a backbone (see Backboning) and adding the most likely missing ones with link prediction (see Link prediction). The methods of this chapter do both at once, in a single and consistent framework (Peixoto, 2018): a generative model of the network, by default the nested degree-corrected stochastic blockmodel, is fitted jointly with a model of the measurement errors, and the posterior probability of every node pair being an edge is estimated by sampling. Edges with a low probability are likely spurious, non-edges with a high probability likely missing. Simpler generative models can be used instead, given as the generators of their families (degree_corrected_block_model(), stochastic_block_model(), planted_partition_graph(), configuration_model(), gnm_random_graph()): the more structure a model captures, the better it tells errors apart.

fit_nested_block_model() finds the hierarchy of groups that best compresses a network (the minimum description length of the nested blockmodel). measured_network_correction() reconstructs a network from repeated measurements of its node pairs (or from a single observation), with error rates known or unknown, the same for every pair or heterogeneous. uncertain_network_correction() reconstructs a network whose node pairs come with probabilities of being edges, estimated by some other measurement. The generator nested_block_model() samples networks from the model, or from its fit to a network.

All the inference runs in compiled kernels (Numba) on the CPU, as in graph-tool: Markov chain moves are sequential and branchy, which suits a CPU core better than a GPU. The candidate merges of the fit are evaluated in parallel, and the posterior is sampled by several independent chains in parallel threads. The kernels are compiled the first time they run (about two minutes, once: they are cached). For scale, on two CPU cores: the fit takes 0.3 seconds for 800 nodes and 4,400 edges, 4.5 seconds for 9,600 nodes and 56,000 edges, and 40 seconds for 50,000 nodes and 350,000 edges; a sweep of the sampler, about one microsecond per move, takes 11 milliseconds for 960 nodes and 5,800 edges, so reconstructing it with the default 1,200 sweeps per chain takes about 14 seconds with two chains (one per core).

import graphoskop as gsk

net = gsk.load_network("edges.tsv")
fit = gsk.fit_nested_block_model(net, seed = 0)              # node attributes community, community_1, ...
fit["groups"], fit["description_length"]

corrected, summary = gsk.measured_network_correction(net, false_negative_rate = 0.1, false_positive_rate = 0.001, seed = 0)
clean = gsk.extract_backbone(corrected, 0.5, score = "probability", keep_isolates = True)   # maximum marginal posterior network

screens = gsk.load_network("screens.tsv")                    # columns trials, hits: repeated measurements
corrected, summary = gsk.measured_network_correction(screens, "trials", "hits", default_measurements = 3)
summary["false_negative_rate"], summary["false_positive_rate"]   # estimated

for model in (gsk.gnm_random_graph, gsk.configuration_model, gsk.nested_block_model):   # Fig. 3 of Peixoto (2018)
   corrected, summary = gsk.measured_network_correction(screens, "trials", "hits", default_measurements = 3, model = model)
corrected, summary = gsk.measured_network_correction(screens, "trials", "hits", default_measurements = 3,
                                                     model = "stochastic_block_model", groups = "lab")   # fixed groups

scored = gsk.load_network("predictions.tsv")                 # column probability, from another method
corrected, summary = gsk.uncertain_network_correction(scored, "probability")

Fit the nested degree-corrected stochastic blockmodel (Peixoto, 2014, 2017): the hierarchy of groups that minimizes the description length of the network. The same fit, and those of the other blockmodels, are also available for community discovery as block_model_communities().

The model generates a network in levels. At the bottom, nodes are in groups, and edges are placed between groups according to the numbers of edges between every pair of groups, at random among their nodes in proportion to the node degrees (degree correction). These numbers are themselves a network between the groups, generated in the same way by a coarser grouping of the groups, and so on up to a single group. The description length is minus the logarithm of the probability of the network and of all its parameters (groups, numbers of edges between groups, degrees), the microcanonical formulation without free parameters:

\[\Sigma = -\ln P(A \mid k, e, b) - \ln P(k \mid e, b) - \sum_l \ln P(e_l \mid e_{l + 1}, b_{l + 1}) - \sum_l \ln P(b_l)\]

with the degree-corrected likelihood \(P(A \mid k, e, b) = \prod_{r < s} e_{rs}! \prod_r e_{rr}!! \prod_i k_i! / \prod_r e_r!\), the degree prior \(P(k \mid e, b) = \prod_r \prod_k \eta^r_k! / (n_r!\, q(e_r, n_r))\) (degree histograms \(\eta^r_k\) uniform given the number of partitions \(q(e_r, n_r)\) of \(e_r\) into at most \(n_r\) parts), the edge counts of each level uniform among the multigraphs between the groups of the level above, \(P(e_l \mid e_{l + 1}, b_{l + 1}) = \prod_{r < s} \left(\!\binom{n_r n_s}{e_{rs}}\!\right)^{-1} \prod_r \left(\!\binom{n_r (n_r + 1) / 2}{e_{rr} / 2}\!\right)^{-1}\), and each partition of \(N\) elements into \(B\) groups uniform given its group sizes, \(P(b) = \prod_r n_r! / N! \binom{N - 1}{B - 1}^{-1} N^{-1}\). More groups, or more levels, are only used if they compress the network more than they cost, so the model selects its own numbers of groups and levels. \(q(m, n)\) is exact for \(m \leq 1000\) and given by Szekeres’ asymptotic formula otherwise (within 0.1 of its logarithm).

The minimization follows Peixoto’s agglomerative heuristic: starting from one group per node, groups are merged in rounds that halve their number, each group merging into the best of 10 proposed groups (proposals through its edges, all groups evaluated in parallel), each round followed by up to sweeps greedy sweeps of node moves. The upper levels are built in the same way on the network between groups. The number of groups of the bottom level is chosen by the nested description length, first along the halving rounds and then by golden section search; the result is refined by greedy sweeps at all levels. It is a heuristic: different seeds can give slightly different results.

The groups are written as numeric node attributes: attribute for the bottom level, attribute + "_1", attribute + "_2", … for the levels above (the group of every node). Parallel edges count once and self loops are ignored. The bottom level has at most max_blocks groups (the levels above are dense tables of that size).

Hypergraphs and simplicial complexes: not supported (see Higher-order networks).

Parameters:

  • net – An undirected Network, not multilayer, modified in place.

  • attribute – Name of the node attribute of the bottom level.

  • max_blocks – Maximum number of groups of the bottom level.

  • sweeps – Maximum number of greedy sweeps after each merge round.

  • seed – Seed of the random numbers, or None.

Returns:

Dict with the description_length and the number of groups of every level, bottom first (without the single group on top).

Raises:

ValueError – If net is directed or multilayer.

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv")
fit = gsk.fit_nested_block_model(net, seed = 0)
fit["groups"]                             # e.g. [64, 8, 2]
net.get_node_attribute("community_1")      # groups of the second level, component 0

Reconstruct a network from noisy measurements of its node pairs, with known or unknown error rates (Peixoto, 2018), using a generative model of the true network: by default the nested degree-corrected stochastic blockmodel (see fit_nested_block_model()), or a simpler one.

Every node pair \((i, j)\) was measured \(n_{ij}\) times, and an edge was observed in \(x_{ij}\) of them. The pairs listed as edges of net carry their numbers in the edge attributes measurements and positives (by default 1 and 1: each edge of net was observed once); all other pairs were measured default_measurements times with default_positives positive outcomes (by default, once, without seeing an edge). A single observed network is thus the default case. Measured non-edges are listed as edges of net with positives 0.

An existing edge is missed in a measurement with probability \(p\) (false negative), a non-edge is seen as an edge with probability \(q\) (false positive), so that

\[P(x \mid n, A, p, q) = \prod_{i < j} \binom{n_{ij}}{x_{ij}} \left[(1 - p)^{x_{ij}} p^{n_{ij} - x_{ij}}\right]^{A_{ij}} \left[q^{x_{ij}} (1 - q)^{n_{ij} - x_{ij}}\right]^{1 - A_{ij}}\]

  • Homogeneous errors (heterogeneous = False): \(p\) and \(q\) are the same for all pairs, unknown, with priors \(p \sim \mathrm{Beta}(\alpha, \beta)\), \(q \sim \mathrm{Beta}(\mu, \nu)\) (priors = (alpha, beta, mu, nu), default (1, 1, 1, 1), uniform), integrated out (Eq. 19 of the paper). Either rate can instead be given as known (false_negative_rate, false_positive_rate), and its prior is then ignored.

  • Heterogeneous errors (heterogeneous = True): every pair has its own error rates, drawn from these Beta distributions, whose hyperparameters are themselves unknown, with a flat prior on \([0.01, 1000]\) and sampled (priors are their initial values, default (1, 10, 1, 10)); the rates are integrated out pair by pair (Eq. 58).

The posterior distribution of the true network \(A\) and of the groups is sampled by Markov chain Monte Carlo, and the posterior probability \(\pi_{ij}\) of every pair being an edge is the fraction of samples in which it is one. The structure inferred from the network (pairs of groups densely or sparsely connected) is what tells real edges from errors: an edge between two groups that are otherwise unconnected is likely spurious, a missing edge within a dense group likely missing. Edges with \(\pi_{ij} > 1/2\) form the maximum marginal posterior estimate of the network:

corrected, summary = gsk.measured_network_correction(net)
clean = gsk.extract_backbone(corrected, 0.5, score = "probability", keep_isolates = True)

Models of the true network. model is one of the generators below (the function itself, e.g. gsk.configuration_model, or its name); the reconstruction uses Peixoto’s nonparametric microcanonical version of its family, with all its parameters integrated out under noninformative priors (not the parametrization of the generator):

  • nested_block_model() (default): the nested degree-corrected stochastic blockmodel, a hierarchy of groups (see fit_nested_block_model());

  • degree_corrected_block_model(): degree-corrected blockmodel, one level of groups;

  • stochastic_block_model(): blockmodel without degree correction (all nodes of a group alike);

  • planted_partition_graph(): one density of edges within groups, one between;

  • configuration_model(): the degrees only (degree-corrected, one group);

  • gnm_random_graph() or gnp_random_graph(): Erdős-Rényi, no structure (one group without degree correction).

The more structure a model captures, the better it tells errors apart: Erdős-Rényi gives every unobserved pair the same chance, the configuration model favors pairs of high degree nodes, blockmodels pairs of densely connected groups (as in Fig. 3 of the paper). The groups of the flat blockmodels are fitted by minimizing their description length, as fit_nested_block_model() does for the nested one (the number of groups chosen along the same merges, refined by greedy sweeps under each model), then sampled; or fixed, read from the node attribute groups (numeric or qualitative).

Latent multigraph. These models generate multigraphs, with parallel edges and self loops, while measurements see simple networks: as in Appendix D of the paper, the chain samples a multigraph \(G\), and the true network is its collapse, \(A_{ij} = 1\) if \(G_{ij} > 0\), \(i \neq j\). Its number of edges has the negative binomial prior of Eq. C9 (geometric edge counts per pair of groups, their mean set by the observed edges), so that the posterior is proper.

Single observations. With one measurement per pair, a missing edge looks like every other unobserved pair between the same groups, so it cannot be singled out: the posterior spreads its probability evenly over all of them (low, unless the groups are dense), and only spurious edges, observed between sparsely connected groups, are told apart. With both rates unknown, the data cannot tell a structure with errors from the same structure without them either, and the estimated rates go to their minimum; known rates (false_negative_rate, false_positive_rate), even approximate, make the probabilities and the expected number of edges calibrated. Repeated measurements (measurements, default_measurements above 1) are what makes individual missing edges recoverable.

Sampling. The chain starts from the edges observed in most of their measurements, with the groups fitted to them. Each sweep tries a move of every node between the groups of the bottom level, of every group between the groups of the level above (for all levels; no group moves if the groups are fixed, or for the configuration model and Erdős-Rényi), and \(\max(E, N)\) moves of the multigraph: a pair is chosen at random among the edges of the multigraph, among all pairs, among the listed pairs, or through the blockmodel (a node, a group connected to its group, a member of it), each with probability 1/4; an edge is added to it or, if it has some, one is added or removed with probability 1/2 each (Eq. D8), and the move is accepted with the Metropolis-Hastings criterion.

The numbers of groups are sampled too, as in graph-tool: a node or group moves to a new group with probability 0.01 (Eq. B4), the new group joining the group of the level above of the one it left, and groups that lose their last member disappear (into a group under the same group above, so that every move can be undone). Since single moves change the number of groups slowly, each sweep also tries 3 split-merge moves of the bottom groups (Jain and Neal, 2004; Peixoto, 2020): a group is split in two, its nodes assigned at random and then by 4 restricted Gibbs sweeps between the two halves, or two groups are merged, the probability of the reverse split computed in the same way. The numbers of groups are thus averaged over in the posterior, which matters when many partitions with more groups, each less likely than the best one, together outweigh it. Every level has room for twice the groups of the fit, at least 10 more (at most its number of elements); the hierarchy keeps the depth of the fit. On Zachary’s karate club measured twice, with one inconsistent pair (Fig. 3 of the paper), Erdős-Rényi gives that pair a probability of 0.50, the configuration model 0.87 and the nested blockmodel 0.93 (0.5, 0.87 and 0.93 in the paper; 0.92 to 0.96 with the default number of sweeps), averaging over about 3 groups, although a single group describes the club best. The number of groups changes slowly (over hundreds of sweeps): its posterior mean (mean_groups) needs longer chains than the probabilities of the edges.

chains independent chains run in parallel threads, each discarding burnin sweeps and then taking samples samples every interval sweeps. The chains run in a compiled kernel (Numba) on the CPU.

Hypergraphs and simplicial complexes: not supported (see Higher-order networks).

Parameters:

  • net – An undirected Network, not multilayer.

  • measurements – Edge attribute with the number of measurements of each listed pair, or None for 1.

  • positives – Edge attribute with the number of positive measurements, or None for all of them.

  • default_measurements – Number of measurements of the pairs not in net.

  • default_positives – Number of positive measurements of the pairs not in net.

  • heterogeneous – Pair by pair error rates instead of one rate for all pairs.

  • priors – (alpha, beta, mu, nu), see above.

  • false_negative_rate – Known \(p\), or None (unknown); homogeneous errors only.

  • false_positive_rate – Known \(q\), or None (unknown); homogeneous errors only.

  • model – Model of the true network: a generator, or its name (see above).

  • groups – Node attribute with fixed groups (flat blockmodels only), or None to fit and sample them.

  • samples – Samples per chain.

  • burnin – Sweeps discarded at the start of every chain.

  • interval – Sweeps between samples.

  • chains – Number of chains (threads).

  • max_blocks – Maximum number of groups of the bottom level of the fit.

  • seed – Seed of the random numbers, or None.

Returns:

(corrected, summary): the corrected network, a new Network with the nodes of net and an edge for every pair observed or ever sampled as an edge, with the edge attribute "probability" (\(\pi_{ij}\)) and the numeric edge attributes of net (NaN for new pairs); and a dict with the model, the numbers of groups per level of its fit, the posterior means of the number of groups of the bottom level (mean_groups), of the number of edges, of the description_length, of the false_negative_rate \(p\) and the false_positive_rate \(q\) (with heterogeneous errors, the means of their Beta distributions, and the hyperparameters), and the number of samples.

Raises:

ValueError – If net is directed or multilayer, if measurements are negative or fewer than the positive outcomes, if known rates are not in \((0, 1)\) or are given with heterogeneous errors, if model is not one of the generators above, or if groups is given to another model or names a missing attribute.

Example:

import graphoskop as gsk

net = gsk.load_network("interactions.tsv")      # one observation of the network
corrected, summary = gsk.measured_network_correction(net, false_negative_rate = 0.1, false_positive_rate = 0.001, seed = 0)
spurious = gsk.extract_backbone(corrected, 0.5, score = "probability")   # edges kept

net = gsk.load_network("screens.tsv")           # columns trials, hits: repeated measurements
corrected, summary = gsk.measured_network_correction(net, "trials", "hits", default_measurements = 3, heterogeneous = True)
cm, _ = gsk.measured_network_correction(net, "trials", "hits", default_measurements = 3, model = gsk.configuration_model)
sbm, _ = gsk.measured_network_correction(net, "trials", "hits", default_measurements = 3, model = "stochastic_block_model", groups = "lab")
graphoskop.uncertain_network_correction(net, probability='probability', default_probability=0.0, model='nested_block_model', groups=None, samples=200, burnin=200, interval=5, chains=4, max_blocks=4096, seed=None)

Reconstruct a network whose node pairs come with probabilities of being edges, estimated by some other measurement (extrinsic uncertainty, Section III of Peixoto, 2018), using a generative model of the true network: by default the nested degree-corrected stochastic blockmodel, or a simpler one (see measured_network_correction()).

Every pair listed as an edge of net has the probability \(Q_{ij}\) in the edge attribute probability; the other pairs have default_probability (by default 0: they cannot be edges, so only the listed pairs are uncertain). \(Q_{ij}\) is read as the probability of the edge given its measurement alone, as if with a uniform prior, so it enters the posterior as the likelihood ratio \(Q_{ij} / (1 - Q_{ij})\):

\[P(A \mid Q) \propto P(A) \prod_{i < j} Q_{ij}^{A_{ij}} (1 - Q_{ij})^{1 - A_{ij}}\]

with \(P(A)\) the model, which pulls the probabilities of the pairs towards what the structure of the rest of the network makes likely. Models, sampling, outputs and parameters are as in measured_network_correction(); the chain starts from the pairs with \(Q_{ij} > 1/2\). Pairs with probability 0 never become edges, pairs with probability 1 are always edges.

Hypergraphs and simplicial complexes: not supported (see Higher-order networks).

Parameters:

  • net – An undirected Network, not multilayer.

  • probability – Edge attribute with the probability of each listed pair.

  • default_probability – Probability of the pairs not in net.

  • model – Model of the true network: a generator, or its name (see measured_network_correction()).

  • groups – Node attribute with fixed groups (flat blockmodels only), or None to fit and sample them.

  • samples – Samples per chain.

  • burnin – Sweeps discarded at the start of every chain.

  • interval – Sweeps between samples.

  • chains – Number of chains (threads).

  • max_blocks – Maximum number of groups of the bottom level of the fit.

  • seed – Seed of the random numbers, or None.

Returns:

(corrected, summary), as measured_network_correction() (the summary has model, groups, mean_groups, edges, description_length and samples). The edge attribute "probability" of the corrected network replaces the input one.

Raises:

ValueError – If net is directed or multilayer, if a probability is outside \([0, 1]\), if a pair is listed twice, or for model and groups as in measured_network_correction().

Example:

import graphoskop as gsk

net = gsk.load_network("predicted_interactions.tsv")   # column probability
corrected, summary = gsk.uncertain_network_correction(net, seed = 0)
likely = gsk.extract_backbone(corrected, 0.5, score = "probability")
cm, _ = gsk.uncertain_network_correction(net, model = gsk.configuration_model, seed = 0)
