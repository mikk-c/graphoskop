Bipartite projections

Projections of bipartite networks onto one of their node types.

A projection keeps the nodes of one type and connects two of them according to the nodes of the other type they share. The result is a new, unipartite Network, with the edge weights in the edge attribute "weight", the node attributes that have values on the kept nodes (attributes only defined on the other type are dropped), and components recomputed.

Let \(B\) be the biadjacency matrix, rows for the kept nodes and columns for the other ones, with parallel edges summed. In an undirected network, kept nodes \(a\) and \(b\) are connected through every other node \(c\) with \(B_{ac} > 0\) and \(B_{bc} > 0\). In a directed network, through every directed path \(a \to c \to b\) of length two, with \(B_{ac}\) the weight of \(a \to c\) and \(B_{bc}\) the weight of \(c \to b\); the projection is then directed, and its components can split even if the bipartite ones do not. Each function combines the two weights of every path differently.

The similarity projections (cosine_similarity_projection(), pearson_correlation_projection(), inverse_euclidean_projection()) compare instead the whole rows of \(B\) of two kept nodes, as vectors over all the nodes of the other type. They take the dot products from the paths and the rest from the sums and sums of squares of each row, so they too only connect (and only compute) the pairs of kept nodes sharing a neighbor.

All functions generate the paths of length two explicitly, \(\sum_c d_c (d_c - 1) / 2\) of them (\(\sum_c d^{in}_c d^{out}_c\) if directed), in batches of about batch_size paths, each reduced to the sums of its distinct node pairs on the device of the network. Batches cover disjoint sets of kept nodes, so no pair is split between two batches and nothing needs merging: peak memory is about 60 bytes per path of a batch (1 GB with the default batch_size = 2 ** 24) plus the result. Smaller batches use less memory and take a little longer. This is faster and leaner than a sparse matrix product, even for projections that are one.

All functions take a weight parameter, defaulting to the edge attribute "weight"; if the network has none, a warning is issued and all weights are 1. Any other missing name raises KeyError. Degrees become strengths (sums of edge weights) with weights.

Multilayer bipartite networks are projected layer by layer: paths of length two only use intra-layer edges, which stay within a layer, and couplings are ignored, so strengths and totals are those of each layer. The projection is a multilayer network with the copies of the kept type, re-coupled with the interlayer edges of the input between them (couplings and the other interlayer edges, which join nodes of the same type), whose "weight" is their value of the weight attribute (1 with unit weights).

graphoskop.cosine_similarity_projection(net, node_type, weight='weight', batch_size=16777216)

Cosine similarity projection: two kept nodes \(a\) and \(b\) sharing at least one neighbor are connected with the cosine of the angle between their rows \(B_a\) and \(B_b\) of the biadjacency matrix:

\[w_{ab} = \frac{\sum_c B_{ac} B_{bc}}{\sqrt{\sum_c B_{ac}^2} \sqrt{\sum_c B_{bc}^2}}\]

The numerator is simple_count_projection(). With unit weights (weight = None) this is the number of shared neighbors over \(\sqrt{k_a k_b}\) (Salton index). Weights are between 0 and 1 for non-negative edge weights. Kept nodes sharing no neighbor (similarity 0) stay as isolated nodes.

Vectors use the edge weights with parallel edges summed. In directed networks the weight of \(a \to b\) compares the out-vector of \(a\) (weights of \(a \to c\)) with the in-vector of \(b\) (weights of \(c \to b\)), and the projection is directed. The dot products are sums over the paths of length two (see the module description), accumulated in float64.

Parameters:

  • net – A bipartite Network.

  • node_type – Value of BIPARTITE of the nodes to keep, one of net.bipartite_labels.

  • weight – Name of the edge attribute used as edge weight, or None for unit weights. The default "weight" falls back to unit weights, with a warning, if there is no such attribute.

  • batch_size – Target number of paths of length two per batch (see the module description).

Returns:

The projection, a new unipartite Network, directed if net is, with the edge attribute "weight".

Raises:

  • ValueError – If net is not bipartite, or has no node of type node_type.

  • KeyError – If weight is another name and there is no edge attribute with it.

Example:

import graphoskop as gsk

net = gsk.load_network("purchases.tsv", "nodes.tsv", bipartite = True)
users = gsk.cosine_similarity_projection(net, "user", weight = "quantity")
graphoskop.hist_intersection_projection(net, node_type, weight='weight', batch_size=16777216)

Histogram intersection projection: two kept nodes \(a\) and \(b\) are connected with weight \(\sum_c \min(B_{ac}, B_{bc})\), summing over the nodes \(c\) of the other type they share (over the paths \(a \to c \to b\) in directed networks, see the module description). Parallel edges are first summed. With unit weights (weight = None) this is the number of shared neighbors, as in simple_count_projection(). Kept nodes sharing no neighbor stay as isolated nodes.

A sum of minima is not a matrix product, so the paths of length two are generated explicitly, \(\sum_c d_c (d_c - 1) / 2\) of them (\(\sum_c d^{in}_c d^{out}_c\) if directed), in batches of about batch_size paths, each reduced to the sums of its distinct node pairs on the device of the network. Batches cover disjoint sets of kept nodes, so no pair is split between two batches and nothing needs merging: peak memory is about 60 bytes per path of a batch (1 GB with the default) plus the result. Smaller batches use less memory and take a little longer.

Parameters:

  • net – A bipartite Network.

  • node_type – Value of BIPARTITE of the nodes to keep, one of net.bipartite_labels.

  • weight – Name of the edge attribute used as edge weight, or None for unit weights.

  • batch_size – Target number of paths of length two per batch.

Returns:

The projection, a new unipartite Network, directed if net is, with the edge attribute "weight".

Raises:

  • ValueError – If net is not bipartite, or has no node of type node_type.

  • KeyError – If there is no edge attribute named weight.

Example:

import graphoskop as gsk

net = gsk.load_network("purchases.tsv", "nodes.tsv", bipartite = True, device = "cuda")
users = gsk.hist_intersection_projection(net, "user")                          # edge attribute "weight"
users = gsk.hist_intersection_projection(net, "user", weight = "quantity")
users = gsk.hist_intersection_projection(net, "user", batch_size = 2 ** 22)    # less memory
graphoskop.hyperbolic_projection(net, node_type, weight='weight', batch_size=16777216)

Newman’s hyperbolic projection: every node \(c\) of the other type shared by two kept nodes \(a\) and \(b\) counts \(1 / k_c\), with \(k_c\) the degree of \(c\), so that shared neighbors with many connections count less. With weights, \(k_c\) is the strength \(s_c = \sum_x B_{xc}\) (sum of the weights of the edges of \(c\)) and each path counts its two weights, so the weight is \(\sum_c B_{ac} B_{bc} / s_c\), i.e. \(B S^{-1} B^T\) with \(S\) the diagonal matrix of the strengths of the other nodes; with unit weights, \(\sum_c 1 / k_c\). Parallel edges are summed, so with unit weights they count as many times as they appear. In directed networks the sum runs over the paths \(a \to c \to b\) (see the module description), and \(s_c\) sums the edges of \(c\) in both directions. Kept nodes sharing no neighbor stay as isolated nodes.

Parameters:

  • net – A bipartite Network.

  • node_type – Value of BIPARTITE of the nodes to keep, one of net.bipartite_labels.

  • weight – Name of the edge attribute used as edge weight, or None for unit weights. The default "weight" falls back to unit weights, with a warning, if there is no such attribute.

  • batch_size – Target number of paths of length two per batch (see the module description).

Returns:

The projection, a new unipartite Network, directed if net is, with the edge attribute "weight".

Raises:

  • ValueError – If net is not bipartite, or has no node of type node_type.

  • KeyError – If weight is another name and there is no edge attribute with it.

Example:

import graphoskop as gsk

net = gsk.load_network("papers.tsv", "nodes.tsv", bipartite = True)
authors = gsk.hyperbolic_projection(net, "author", weight = None)   # co-authorship, large papers count less
graphoskop.inverse_euclidean_projection(net, node_type, weight='weight', batch_size=16777216)

Inverse Euclidean distance projection: two kept nodes \(a\) and \(b\) sharing at least one neighbor are connected with

\[w_{ab} = \frac{1}{1 + d_{ab}}, \qquad d_{ab} = \sqrt{\sum_c (B_{ac} - B_{bc})^2} = \sqrt{\sum_c B_{ac}^2 + \sum_c B_{bc}^2 - 2 \sum_c B_{ac} B_{bc}}\]

the Euclidean distance between their rows of the biadjacency matrix. Adding 1 keeps the weight finite, between 0 and 1, with 1 for identical vectors. With unit weights (weight = None), \(d_{ab}^2\) is the number of neighbors of exactly one of the two nodes. Kept nodes sharing no neighbor stay as isolated nodes, even though their similarity is not 0: only pairs joined by a path of length two are computed.

Vectors use the edge weights with parallel edges summed. In directed networks the weight of \(a \to b\) compares the out-vector of \(a\) with the in-vector of \(b\), and the projection is directed. The dot products are sums over the paths of length two (see the module description), accumulated in float64 to limit cancellation.

Parameters:

  • net – A bipartite Network.

  • node_type – Value of BIPARTITE of the nodes to keep, one of net.bipartite_labels.

  • weight – Name of the edge attribute used as edge weight, or None for unit weights. The default "weight" falls back to unit weights, with a warning, if there is no such attribute.

  • batch_size – Target number of paths of length two per batch (see the module description).

Returns:

The projection, a new unipartite Network, directed if net is, with the edge attribute "weight".

Raises:

  • ValueError – If net is not bipartite, or has no node of type node_type.

  • KeyError – If weight is another name and there is no edge attribute with it.

Example:

import graphoskop as gsk

net = gsk.load_network("purchases.tsv", "nodes.tsv", bipartite = True)
users = gsk.inverse_euclidean_projection(net, "user", weight = "quantity")
graphoskop.pearson_correlation_projection(net, node_type, weight='weight', batch_size=16777216)

Pearson correlation projection: two kept nodes \(a\) and \(b\) sharing at least one neighbor are connected with the Pearson correlation of their rows \(B_a\) and \(B_b\) of the biadjacency matrix, over all the \(m\) nodes of the other type (zeros included):

\[w_{ab} = \frac{\sum_c B_{ac} B_{bc} - m \bar{B}_a \bar{B}_b} {\sqrt{\sum_c B_{ac}^2 - m \bar{B}_a^2} \sqrt{\sum_c B_{bc}^2 - m \bar{B}_b^2}}\]

with \(\bar{B}_a = \sum_c B_{ac} / m\). Weights are between -1 and 1: two nodes sharing a neighbor can still be negatively correlated, e.g. if each has many neighbors the other lacks. A node whose vector is constant (connected to every other node with the same weight) has zero variance, and its correlations are 0. Kept nodes sharing no neighbor stay as isolated nodes, even though their correlation is not 0 (it is negative): only pairs joined by a path of length two are computed.

Vectors use the edge weights with parallel edges summed. \(m\) counts all the nodes of the other type in the network, isolated ones and other components included; in multilayer networks, those of the layer. In directed networks the weight of \(a \to b\) compares the out-vector of \(a\) with the in-vector of \(b\), and the projection is directed. The dot products are sums over the paths of length two (see the module description), accumulated in float64 to limit cancellation.

Parameters:

  • net – A bipartite Network.

  • node_type – Value of BIPARTITE of the nodes to keep, one of net.bipartite_labels.

  • weight – Name of the edge attribute used as edge weight, or None for unit weights. The default "weight" falls back to unit weights, with a warning, if there is no such attribute.

  • batch_size – Target number of paths of length two per batch (see the module description).

Returns:

The projection, a new unipartite Network, directed if net is, with the edge attribute "weight".

Raises:

  • ValueError – If net is not bipartite, or has no node of type node_type.

  • KeyError – If weight is another name and there is no edge attribute with it.

Example:

import graphoskop as gsk

net = gsk.load_network("purchases.tsv", "nodes.tsv", bipartite = True)
users = gsk.pearson_correlation_projection(net, "user", weight = None)
graphoskop.random_walk_projection(net, node_type, directed=False, weight='weight', batch_size=16777216)

Random walk projection (YCN, Yildirim and Coscia, 2014): the weight from \(a\) to \(b\) is the probability that a random walker on the bipartite network moves from \(a\) to \(b\) in two steps (through a node of the other type), times the probability of finding it on \(b\) after infinitely many steps:

\[U_{a \to b} = T_{ab} \pi_b, \qquad T_{ab} = \sum_c \frac{B_{ac}}{s_a} \frac{B_{bc}}{s_c}\]

with \(B\) the biadjacency matrix, \(s\) the strengths (sums of edge weights; degrees with unit weights), \(T\) the two-step transition matrix (ProbS, see resource_allocation_projection()) and \(\pi\) its stationary distribution. The walk is reversible, so \(\pi_b = s_b / S\), with \(S\) the total edge weight, and no eigenvector is computed: \(U_{a \to b} = H_{ab} s_b / (s_a S)\), with \(H\) the hyperbolic sum of hyperbolic_projection(). With directed = False the two directions are averaged, \((U_{a \to b} + U_{b \to a}) / 2\). Parallel edges are summed. Kept nodes sharing no neighbor stay as isolated nodes.

This is the stationary distribution of the whole network, so on networks with several components, weights are comparable across components (the reference implementation takes an arbitrary eigenvector of eigenvalue 1 instead, which is unique only on connected networks). In multilayer networks, \(S\) is the total edge weight of the layer.

Parameters:

  • net – An undirected bipartite Network.

  • node_type – Value of BIPARTITE of the nodes to keep, one of net.bipartite_labels.

  • directed – Return the directed projection \(U\), with both directions of every pair, instead of the average of the two directions.

  • weight – Name of the edge attribute used as edge weight, or None for unit weights. The default "weight" falls back to unit weights, with a warning, if there is no such attribute.

  • batch_size – Target number of paths of length two per batch (see the module description).

Returns:

The projection, a new unipartite Network with the edge attribute "weight".

Raises:

  • ValueError – If net is directed (the walk is then not reversible), is not bipartite, or has no node of type node_type.

  • KeyError – If weight is another name and there is no edge attribute with it.

Example:

import graphoskop as gsk

net = gsk.load_network("occupations.tsv", "nodes.tsv", bipartite = True)
occupations = gsk.random_walk_projection(net, "occupation")
flows = gsk.random_walk_projection(net, "occupation", directed = True)
graphoskop.resource_allocation_projection(net, node_type, lambd=1, weight='weight', batch_size=16777216)

Resource allocation projections (Zhou et al.): ProbS (mass diffusion), HeatS (heat conduction) and their hybrid. They start from the hyperbolic sum \(H_{ab} = \sum_c B_{ac} B_{bc} / s_c\) of hyperbolic_projection(), and normalize it by the strengths \(s_a\) and \(s_b\) of the kept nodes (sums of the weights of their edges; their degrees with unit weights). Each projected edge \(a \to b\) carries what flows from \(a\) to \(b\):

\[w_{a \to b} = \frac{H_{ab}}{s_a^{\lambda} s_b^{1 - \lambda}}\]

  • lambd = 1, ProbS: normalized by the sender. In undirected networks the weights leaving a node, its self loop included (which is dropped), sum to 1: the fraction of its resource reaching each other node.

  • lambd = 0, HeatS: normalized by the receiver. In undirected networks the weights entering a node, its self loop included, sum to 1: the share of its value averaged from each other node.

  • 0 < lambd < 1: the hybrid. With lambd = 0.5, \(H_{ab} / \sqrt{s_a s_b}\) is symmetric.

The projection is undirected only if lambd = 0.5 and net is undirected; otherwise it is directed, with both directions of every pair if net is undirected. Parallel edges are summed. In directed networks \(H\) sums over the paths \(a \to c \to b\) (see the module description), and strengths sum the edges in both directions. Kept nodes sharing no neighbor stay as isolated nodes.

Parameters:

  • net – A bipartite Network.

  • node_type – Value of BIPARTITE of the nodes to keep, one of net.bipartite_labels.

  • lambd – Hybrid parameter \(\lambda\), from 0 (HeatS) to 1 (ProbS).

  • weight – Name of the edge attribute used as edge weight, or None for unit weights. The default "weight" falls back to unit weights, with a warning, if there is no such attribute.

  • batch_size – Target number of paths of length two per batch (see the module description).

Returns:

The projection, a new unipartite Network with the edge attribute "weight".

Raises:

  • ValueError – If lambd is not between 0 and 1, if net is not bipartite, or if it has no node of type node_type.

  • KeyError – If weight is another name and there is no edge attribute with it.

Example:

import graphoskop as gsk

net = gsk.load_network("purchases.tsv", "nodes.tsv", bipartite = True)
items = gsk.resource_allocation_projection(net, "item")                 # ProbS, directed
items = gsk.resource_allocation_projection(net, "item", lambd = 0)      # HeatS, directed
items = gsk.resource_allocation_projection(net, "item", lambd = 0.5)    # hybrid, undirected
graphoskop.simple_count_projection(net, node_type, weight='weight', batch_size=16777216)

Projection counting the shared neighbors, weighted: two kept nodes \(a\) and \(b\) are connected with weight \(\sum_c B_{ac} B_{bc}\), i.e. \(B B^T\) (\(B_{out} B_{in}\) in directed networks), summing over the nodes \(c\) of the other type they share (paths of length two in directed networks, see the module description). With unit weights (weight = None) this is the number of shared neighbors, parallel edges counting as many times as they appear. Kept nodes sharing no neighbor stay as isolated nodes.

Parameters:

  • net – A bipartite Network.

  • node_type – Value of BIPARTITE of the nodes to keep, one of net.bipartite_labels.

  • weight – Name of the edge attribute used as edge weight, or None for unit weights. The default "weight" falls back to unit weights, with a warning, if there is no such attribute.

  • batch_size – Target number of paths of length two per batch (see the module description).

Returns:

The projection, a new unipartite Network, directed if net is, with the edge attribute "weight".

Raises:

  • ValueError – If net is not bipartite, or has no node of type node_type.

  • KeyError – If weight is another name and there is no edge attribute with it.

Example:

import graphoskop as gsk

net = gsk.load_network("purchases.tsv", "nodes.tsv", bipartite = True)
users = gsk.simple_count_projection(net, "user", weight = None)   # items bought in common
items = gsk.simple_count_projection(net, "item", weight = "quantity")
users.get_edge_attribute("weight")
