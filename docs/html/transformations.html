Transformations

Transformations of a network into another network.

to_undirected() symmetrizes a directed network: all the edges between two nodes, in either direction, become one undirected edge, whose attributes combine theirs. remove_isolates() drops the nodes without edges, remove_self_loops() the edges from a node to itself, remove_parallel_edges() merges the edges between the same two nodes. subgraph() keeps a set of nodes and the edges between them, to_strongly_connected() the edges within strongly connected components. add_nodes(), add_edges(), remove_nodes() and remove_edges() add or remove nodes and edges, one or many at once.

import graphoskop as gsk

net = gsk.load_network("trust.tsv", directed = True)          # columns weight, sign
und = gsk.to_undirected(net)                                    # weights summed: A + A^T
und = gsk.to_undirected(net, combine = "max", disagree = "positive")
core = gsk.remove_isolates(net)                                 # nodes without edges dropped
clean = gsk.remove_isolates(gsk.remove_self_loops(net))         # no self loops, then no isolates
simple = gsk.remove_parallel_edges(net)                         # one edge per pair (per direction)
ego = gsk.subgraph(net, ["alice", "bob", "carol"])              # induced subgraph
scc = gsk.to_strongly_connected(net)                            # one component per strongly connected component

Nodes and edges are added or removed one at a time, from any iterable, or from a pandas.DataFrame table. Missing attributes are NaN, except edge weights, which default to 1.

import pandas as pd

net = gsk.add_nodes(net, "dave")                                # node attributes NaN
net = gsk.add_nodes(net, pd.DataFrame({"id": ["erin"], "age": [41]}))
net = gsk.add_edges(net, [("alice", "dave"), ("dave", "frank")])   # weight 1, frank added
net = gsk.add_edges(net, pd.DataFrame({"source": ["bob"], "target": ["erin"], "weight": [2.5]}))
net = gsk.remove_edges(net, ("alice", "bob"))                   # all edges between them
net = gsk.remove_nodes(net, ["carol", "dave"])                  # with their edges

See also layer_network() and aggregate_network() for multilayer networks, and signed_network().

graphoskop.to_undirected(net, combine='sum', sign='sign', disagree='zero')

Undirected version of a directed network.

All the edges between the same two nodes, in either direction (parallel edges included), are merged into one undirected edge; self loops of a node are merged into one self loop. Each numeric edge attribute of the merged edge combines the values of its edges, ignoring NaN:

  • "sum": their sum, so that weights give \(A + A^T\);

  • "mean": their mean (an edge in one direction only keeps its value);

  • "max": their maximum.

The sign attribute (if the network has one, see Signed networks) is not combined: if all the merged edges have the same sign, the edge keeps it; if some are positive and some negative, disagree decides: "positive" (+1), "negative" (-1) or "zero" (0, which signed analyses treat as no edge). Edges with sign 0 or NaN do not count as disagreeing.

Nodes and node attributes are kept, isolated nodes included, and so are node types (bipartite networks) and the device. In multilayer networks intra-layer edges are merged within each layer, and interlayer edges (couplings included) between the same two copies are merged too.

Parameters:

  • net – A directed Network.

  • combine – "sum", "mean" or "max".

  • sign – Name of the sign edge attribute (ignored if the network has no such attribute).

  • disagree – "positive", "negative" or "zero".

Returns:

The undirected network, a new Network.

Raises:

ValueError – If net is undirected, or combine or disagree is not valid.

Example:

import graphoskop as gsk

net = gsk.load_network("trust.tsv", directed = True)           # columns weight, sign
und = gsk.to_undirected(net, combine = "mean", disagree = "negative")
und.get_edge_attribute("weight", edge = ("alice", "bob"))       # mean of both directions
graphoskop.remove_isolates(net)

Network without its isolated nodes.

An isolated node has no edges at all; a node whose only edge is a self loop is not isolated. Since every isolated node is a component on its own, the other components are kept unchanged, in the same order, with the same node and edge attributes, node types and device; only their positions in the list of components can shift (isolated nodes are among the smallest components, so the largest ones keep their index). Their tensors are copied, so changing one network does not change the other.

In multilayer networks a copy is isolated if it has no edges, couplings and other interlayer edges included; a copy coupled to the other copies of its entity is not isolated.

Parameters:

net – A Network.

Returns:

The network without isolated nodes, a new Network (with the same nodes, copied, if there are none).

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv", "nodes.tsv")   # nodes.tsv lists nodes without edges too
core = gsk.remove_isolates(net)
core.number_of_nodes() <= net.number_of_nodes()     # True
graphoskop.remove_self_loops(net)

Network without its self loops (edges from a node to itself).

All nodes are kept, so a node whose only edges were self loops becomes isolated (follow with remove_isolates() to drop it as well). Removing self loops never splits a component, so components, internal ids (component, index), node attributes, node types and device stay the same, and so do the attributes of the other edges. Tensors are copied, so changing one network does not change the other. In multilayer networks self loops are intra-layer edges from a copy to itself.

Parameters:

net – A Network.

Returns:

The network without self loops, a new Network.

Example:

import graphoskop as gsk

net = gsk.load_network("replies.tsv", directed = True)   # people replying to themselves
clean = gsk.remove_isolates(gsk.remove_self_loops(net))
graphoskop.remove_parallel_edges(net, combine='sum', sign='sign', disagree='zero')

Network without parallel edges: all the edges between the same two nodes become one edge, whose attributes combine theirs.

In directed networks, parallel edges have the same source and the same target: the edges \(u \to v\) and \(v \to u\) are not parallel and both stay (use to_undirected() to merge them). In undirected networks, \(u - v\) and \(v - u\) are the same edge. Self loops of a node are parallel to each other. In multilayer networks the endpoints are copies (entity, layer), so only edges within the same layer are merged (and interlayer edges between the same two copies), never edges of different layers.

Each numeric edge attribute of a merged edge combines the values of its edges, ignoring NaN, as in to_undirected(): "sum" (weights then give the same adjacency matrix and Laplacians), "mean" or "max". The sign attribute (see Signed networks) keeps the common sign of the edges, and disagree decides when they have both signs: "positive", "negative" or "zero". A merged edge keeps the position and orientation of the first of its edges.

Merging parallel edges never changes which nodes are connected, so nodes, components, internal ids, node attributes, node types and device are kept, and all the work runs on the device of the network. Tensors are copied, so changing one network does not change the other.

Parameters:

  • net – A Network.

  • combine – "sum", "mean" or "max".

  • sign – Name of the sign edge attribute (ignored if the network has no such attribute).

  • disagree – "positive", "negative" or "zero".

Returns:

The network without parallel edges, a new Network.

Raises:

ValueError – If combine or disagree is not valid.

Example:

import graphoskop as gsk

net = gsk.load_network("emails.tsv", directed = True)    # one row per email
simple = gsk.remove_parallel_edges(net)                   # one edge per sender and receiver, weights summed
simple = gsk.remove_parallel_edges(net, combine = "max")
graphoskop.subgraph(net, nodes)

Subgraph induced by a set of nodes: those nodes, with their attributes, and the edges between them, with theirs.

Components are recomputed, so they are those of the subgraph; node types (bipartite networks), node table format, directedness and device are kept. In multilayer networks nodes are copies (entity, layer), and an entity stands for all its copies; interlayer edges (couplings included) between kept copies are kept.

Parameters:

  • net – A Network.

  • nodes – Iterable of nodes (input ids, internal ids (component, index), or entities in multilayer networks), for example one of the arrays of connected_components_nodes().

Returns:

The subgraph, a new Network.

Raises:

KeyError – If a node does not exist.

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv", "nodes.tsv")
ego = gsk.subgraph(net, ["alice", "bob", "carol"])
graphoskop.to_strongly_connected(net)

Directed network split into its strongly connected components: the edges between different strongly connected components are dropped, so that each of them becomes a component of its own (see connected_components_count()).

All nodes and their attributes are kept (a node in no directed cycle becomes isolated), and so are the attributes of the remaining edges, node types, node table format and device. In multilayer networks the strongly connected components are those of the supra-graph.

Parameters:

net – A directed Network.

Returns:

The network split into strongly connected components, a new Network; its components are sorted by size as usual.

Raises:

ValueError – If net is undirected (its components are already strongly connected).

Example:

import graphoskop as gsk

net = gsk.load_network("follows.tsv", directed = True)
scc = gsk.to_strongly_connected(net)
scc.number_of_components() == gsk.connected_components_count(net, type = "strong")   # True

Adding and removing nodes and edges

graphoskop.add_nodes(net, nodes)

Network with new nodes, without edges (use add_edges() to connect them).

nodes is one node id, an iterable of node ids, or a pandas.DataFrame node table in the format of the network’s (net.node_format), as taken by load_network(): wide (node id, then one column per attribute) or long (node id, attribute name, value). A string or a tuple is always one node. New nodes get NaN (missing) for every attribute they are not given; in long (sparse) node tables, a numeric attribute without a value reads as 0. Columns that are not attributes of the network become new attributes, NaN for the existing nodes.

In multilayer networks every new node is a copy (entity, layer): tuples, or a table with the entity in the first column and the layer in the second. Layers not in layer_labels are appended to the layer order. In bipartite networks new nodes must have a value of BIPARTITE, so they are given as a table.

Every new node is a component of its own; the existing components, node and edge attributes, node types, node table format and device are kept.

Parameters:

  • net – A Network.

  • nodes – A node id, an iterable of node ids, or a pandas.DataFrame.

Returns:

The network with the new nodes, a new Network.

Raises:

ValueError – If a node is already in the network, if a node of a multilayer network is not a copy (entity, layer), or if a new node of a bipartite network has no node type.

Example:

import graphoskop as gsk
import pandas as pd

net = gsk.load_network("edges.tsv", "nodes.tsv")            # attributes age, city
net = gsk.add_nodes(net, "dave")                              # age NaN, city NaN
net = gsk.add_nodes(net, ["erin", "frank"])
net = gsk.add_nodes(net, pd.DataFrame({"id": ["gina"], "age": [41]}))   # city NaN
graphoskop.add_edges(net, edges, weight='weight')

Network with new edges.

edges is one edge (u, v), an iterable of them (e.g. a list of pairs, or a two column array), or a pandas.DataFrame edge table: source and target in the first two columns, then one column per edge attribute (non-numeric columns are ignored, as in load_network()). A tuple is always one edge. New edges get NaN for every attribute they are not given, except weight, which defaults to 1: if the network or the new edges have an attribute named weight, new edges without a value get 1, and so do the existing edges if the attribute is new (they were unweighted). Columns that are not attributes of the network become new attributes, NaN for the existing edges.

Endpoints not in the network are added as new nodes, with NaN (missing) for every node attribute, as in add_nodes(). Adding an edge that already exists adds a parallel edge (see remove_parallel_edges()). In undirected networks (u, v) and (v, u) are the same edge.

In multilayer networks the endpoints are copies (entity, layer): an edge between copies in the same layer is an intra-layer edge, otherwise an interlayer edge (a coupling if they are copies of the same entity). A table is given as an edge table (source, target, a layer column, then attributes) or as an interlayer table (source, source_layer, target, target_layer, then attributes), as written by to_pandas_dataframes(). Layers not in layer_labels are appended to the layer order. In bipartite networks new edges must join nodes of different types, and new endpoints need a type, so they must be added first with add_nodes().

Components are recomputed, since new edges can join them; node and edge attributes, node types, node table format and device are kept.

Parameters:

  • net – A Network.

  • edges – An edge (u, v), an iterable of edges, or a pandas.DataFrame.

  • weight – Name of the edge attribute holding the weights, or None to give no default weight.

Returns:

The network with the new edges, a new Network.

Raises:

ValueError – If an edge is not a pair, if an endpoint of a multilayer network is not a copy (entity, layer), or, in bipartite networks, if an edge joins two nodes of the same type or a new endpoint has no node type.

Example:

import graphoskop as gsk
import pandas as pd

net = gsk.load_network("edges.tsv")                           # attribute weight
net = gsk.add_edges(net, ("alice", "dave"))                    # weight 1, dave is a new node
net = gsk.add_edges(net, [("bob", "carol"), ("carol", "dave")])
net = gsk.add_edges(net, pd.DataFrame({"source": ["alice"], "target": ["erin"], "weight": [2.5]}))
graphoskop.remove_nodes(net, nodes)

Network without some nodes and their edges: the subgraph induced by all the other nodes (see subgraph()).

nodes is one node, an iterable of nodes, or a pandas.DataFrame whose first column gives the nodes (e.g. a node table); a string or a tuple is always one node. Nodes are input ids or internal ids (component, index); in multilayer networks, copies (entity, layer) or entities, which stand for all their copies (in a table, the entity is in the first column and the layer in the second, missing for all the copies).

Components are recomputed, since removing a node can split one; the attributes of the other nodes and edges, node types, node table format and device are kept.

Parameters:

  • net – A Network.

  • nodes – A node, an iterable of nodes, or a pandas.DataFrame.

Returns:

The network without the nodes, a new Network.

Raises:

KeyError – If a node is not in the network.

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv", "nodes.tsv")
net = gsk.remove_nodes(net, "alice")
net = gsk.remove_nodes(net, ["bob", "carol"])
graphoskop.remove_edges(net, edges)

Network without some edges.

edges is one edge (u, v), an iterable of them, or a pandas.DataFrame with the endpoints in the first two columns (e.g. an edge table; other columns are ignored). A tuple is always one edge. All the edges from u to v are removed, parallel edges included; in undirected networks, also those from v to u. Endpoints are given as in remove_nodes(). In multilayer networks, an entity stands for all its copies, so (u, v) between two entities removes the edges between their copies in every layer and across layers; a table with a layer column, or with source_layer and target_layer columns, gives copies, as written by to_pandas_dataframes().

All nodes are kept, so a node can become isolated (follow with remove_isolates() to drop it). Components are recomputed, since removing an edge can split one; the attributes of the nodes and of the other edges, node types, node table format and device are kept.

Parameters:

  • net – A Network.

  • edges – An edge (u, v), an iterable of edges, or a pandas.DataFrame.

Returns:

The network without the edges, a new Network.

Raises:

  • KeyError – If a node or an edge is not in the network.

  • ValueError – If an edge is not a pair.

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv")
net = gsk.remove_edges(net, ("alice", "bob"))
net = gsk.remove_edges(net, [("bob", "carol"), ("carol", "dave")])
