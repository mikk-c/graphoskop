Robustness

Robustness: how much a network breaks down when its nodes or edges fail, one after the other. Like epidemics, failures are a percolation process: removing nodes (site percolation) or edges (bond percolation) eventually breaks the network into small pieces.

node_removal() and edge_removal() remove the nodes or the edges of a network one by one, in an order given by a strategy, and record a quality of the network after each removal:

  • "lcc": the fraction of all the nodes in the largest connected component (weakly connected, in directed networks), the size of the giant component in percolation theory;

  • "apl": the average shortest path length between the remaining nodes, as average_shortest_path_length() (unit lengths, ordered pairs connected by a path, directions followed in directed networks; NaN when no pair is connected).

Strategies:

  • "random": random failures, a uniformly random order, anew in every run;

  • "friend_of_random" (nodes only): an acquaintance attack, the order of the friends named by random nodes (as in the immunization of simple_contagion): a random node names a random neighbor (out-neighbor in directed networks), which is removed, drawn again if already removed. This is the same as drawing the nodes without replacement with probability proportional to \(w_v = \sum_{u \to v} 1 / k_u\), the chance that a random node names \(v\), which is how the order is drawn; nodes nobody names come last, in random order;

  • node or edge ids: removed in the given order, and only those;

  • a measure, i.e. values of the nodes (vector, dictionary or pandas.Series by node id, or the name of a numeric node attribute, e.g. a centrality or degree() with distribution = None) or of the edges (vector aligned with the edges, e.g. edge_betweenness_centrality(), or the name of a numeric edge attribute): a targeted attack, from the largest value down (selection = "top", NaN last), or drawn without replacement with probability proportional to the values (selection = "weighted").

A measure can also be a function of the network returning such values (e.g. lambda g: gsk.degree(g, distribution = None)). By default the measure is computed once, on the intact network. With recompute = True and a function, it is computed again on the remaining network after every removal (an adaptive attack: e.g. the node with the largest current degree, then the largest degree among the nodes left, and so on), or after every recompute removals if it is a number, which is much faster on large networks: each computation rebuilds the remaining network and calls the function. Random strategies are repeated runs times, and the table gives the mean and its 95% Student’s t confidence interval; the other strategies give the same order every time, and are run once.

The largest component is found for every number of removals at once, by adding the removed nodes or edges back in reverse order with a union-find (Newman and Ziff, 2000), so a whole curve costs about as much as finding the components once; runs go in parallel on the CPU threads. The average path length needs a breadth-first search from every remaining node (or from samples random ones) at every recorded point, in parallel over the sources: much slower, so record few points.

cascade_failures() simulates cascades of failures instead: nodes or edges carry a load and have a capacity, a failed item passes its load to its neighbors, and overloaded items fail in turn.

import graphoskop as gsk

net = gsk.load_network("edges.tsv")
failures = gsk.node_removal(net, runs = 10, seed = 1)                 # random failures
k = gsk.degree(net, distribution = None)
attack = gsk.node_removal(net, strategy = k)                           # hubs first
soft = gsk.node_removal(net, strategy = k, selection = "weighted")     # hubs more likely first
friends = gsk.node_removal(net, strategy = "friend_of_random")         # acquaintance attack
chosen = gsk.node_removal(net, strategy = ["alice", "bob"])            # these nodes, in order
apl = gsk.node_removal(net, strategy = k, quality = "apl", points = 20, samples = 500)
degree = lambda g: gsk.degree(g, distribution = None)
adaptive = gsk.node_removal(net, strategy = degree, recompute = True)  # largest current degree first

cuts = gsk.edge_removal(net)                                           # random edge failures
eb = gsk.edge_betweenness_centrality(net)
cuts = gsk.edge_removal(net, strategy = eb, component = 0)            # highest betweenness first

ax = failures.plot(x = "fraction", y = "lcc", label = "random")
attack.plot(x = "fraction", y = "lcc", label = "hubs", ax = ax)

# cascades: a failed node passes its load to its neighbors, overloaded neighbors fail next
c = gsk.cascade_failures(net, failures = 5, margin = 0.2, runs = 10)   # random loads and capacities
c = gsk.cascade_failures(net, k, failures = 1, strategy = k, margin = 0.5)   # load = degree, the hub fails
c[["failed", "lcc"]].plot()                                            # by step
ml = gsk.load_network("layers.tsv", multilayer = True, coupling = "all")
c = gsk.cascade_failures(ml, failures = 5)                             # all copies of an entity fail together

Cascade failures

graphoskop.cascade_failures(net, load='random', capacity='random', failures=1, strategy='random', selection='top', elements='nodes', distribution='equal', margin=0.5, quality='lcc', runs=10, max_steps=1000, component=None, samples=None, seed=None, interdependent=True)

Cascading failures with load redistribution, as in the overload models of power grids and fiber bundles (Motter and Lai, 2002): every node (or edge) carries a load and has a capacity; when it fails it is removed from the network and its load goes to its neighbors, which fail in turn at the next step if their load exceeds their capacity, and so on until no item is overloaded.

Loads and capacities are node (or edge) attributes given by name, values (as for a measure, see the module description), or "random": random loads are uniform in [0, 1), and random capacities are the load plus a spare capacity uniform in [0, margin), so that nothing is overloaded at the start; random values are drawn anew in every run.

At step 0, the initial failures happen: failures items (a fraction of them if below 1) chosen by strategy, as in node_removal() ("random", "friend_of_random" for nodes, a measure with selection, or ids, which give the failing items themselves and make failures unused), or "overload": all the items whose load already exceeds their capacity. At every step, the failing items are removed together, and each one splits its current load among its remaining neighbors (distribution):

  • "equal": in equal parts;

  • "random": in random parts (weights uniform in [0, 1), normalized);

  • "load": proportionally to the current load of the receivers;

  • "capacity": proportionally to the capacity of the receivers.

The neighbors of a node are its neighbors (out-neighbors in directed networks, where load flows along the edges); the neighbors of an edge are the edges that share an endpoint with it (in directed networks, the edges leaving its target). Parallel edges count as several neighbors. When "load" or "capacity" weights are all zero the split is equal, and the load of an item without remaining neighbors is lost. The items whose load exceeds their capacity after all the transfers of a step fail at the next step (only the items that received load are checked: given loads above capacity at the start fail only through "overload").

In multilayer networks the items are the copies of the entities (nodes) or the edges of the supra-graph, and couplings are edges like the others. With interdependent = True (and node items), the layers depend on each other as in interdependent networks (Buldyrev et al., 2010): when a copy fails, all the copies of its entity fail at the same step, and pass their own loads to their own neighbors, so failures percolate from layer to layer (the failing copies do not pass load to each other through their couplings). With interdependent = False the copies fail independently, and load flows through the couplings as through any edge.

Parameters:

  • net – A Network.

  • load – Load of every item: "random", the name of a numeric attribute, or values.

  • capacity – Capacity of every item: "random", the name of a numeric attribute, or values.

  • failures – Number of initial failures, or a fraction of the items if below 1.

  • strategy – How the initial failures are chosen: "random", "friend_of_random" (nodes), "overload", a measure, or ids (the failing items).

  • selection – With a measure: "top" or "weighted".

  • elements – "nodes" or "edges", the items that carry load and fail.

  • distribution – "equal", "random", "load" or "capacity".

  • margin – Largest spare capacity of random capacities.

  • quality – "lcc" (fraction of all the nodes in the largest connected component) or "apl" (average shortest path length), after the failures of each step.

  • runs – Number of runs (a single run if nothing is random).

  • max_steps – Largest number of steps.

  • component – Index of the component (0 is the largest), or None for the whole network.

  • samples – With "apl", the number of random source nodes of the searches, or None.

  • seed – Seed of the random numbers, or None for a random seed.

  • interdependent – In multilayer networks with node items, whether all the copies of an entity fail together.

Returns:

pandas.DataFrame indexed by step (0: the initial failures), with columns failed (mean fraction of the items failed so far), the mean quality (lcc or apl) and their confidence intervals (failed_low, failed_high, lcc_low, …; NaN with a single run). Runs that stop earlier keep their final values.

Raises:

ValueError – If a parameter is not valid, or loads or capacities are not finite and non negative.

Example:

import graphoskop as gsk

net = gsk.load_network("grid.tsv", "stations.tsv")                     # node attributes load, capacity
c = gsk.cascade_failures(net, "load", "capacity", strategy = "overload", runs = 1)
c = gsk.cascade_failures(net, failures = 5, margin = 0.2)              # random loads and capacities
k = gsk.degree(net, distribution = None)
c = gsk.cascade_failures(net, k, failures = 1, strategy = k, distribution = "capacity")   # the hub fails
c = gsk.cascade_failures(net, elements = "edges", failures = 0.01)
c["failed"].iloc[-1]                                                     # final size of the cascade
ml = gsk.load_network("grid_layers.tsv", multilayer = True, coupling = "all")
c = gsk.cascade_failures(ml, failures = 5)                             # interdependent layers
c = gsk.cascade_failures(ml, failures = 5, interdependent = False)     # copies fail independently

Edge removal

graphoskop.edge_removal(net, strategy='random', selection='top', quality='lcc', runs=10, points=100, component=None, samples=None, seed=None, recompute=False)

Robustness of a network to edge failures or attacks: remove its edges one by one (all nodes stay), and record the quality of the network after each removal (see the module description). Every edge counts once (in undirected networks, both stored directions go together); parallel edges are removed one at a time.

Parameters:

  • net – A Network.

  • strategy – "random" (failures), edges (u, v) (removed in order; all the edges between u and v, in either direction if undirected), or edge values (a measure: a vector with one value per edge or per stored edge, e.g. edge_betweenness_centrality(), a list of them, one per component, or the name of a numeric edge attribute), or a function of the network returning edge values.

  • selection – With a measure: "top" (largest values first) or "weighted" (drawn with probability proportional to the values).

  • quality – "lcc" (fraction of the nodes in the largest connected component) or "apl" (average shortest path length).

  • runs – Number of runs of the random strategies; the others are run once.

  • points – Number of numbers of removals recorded, evenly spaced from none to all, or None for every removal.

  • component – Index of the component (0 is the largest), or None for the whole network.

  • samples – With "apl", the number of random source nodes of the searches at each point, or None for all the nodes (exact).

  • seed – Seed of the random numbers, or None for a random seed.

  • recompute – With a measure given as a function of the network, True to compute it again on the remaining network after every removal (adaptive attack), a number of removals between computations, or False to compute it once.

Returns:

pandas.DataFrame indexed by the number of removed edges (removed), with columns fraction (of the edges removed), the mean quality (lcc or apl) and its confidence interval (NaN with a single run).

Raises:

  • ValueError – If a parameter is not valid, or a vector does not have one value per edge.

  • KeyError – If a node or an edge does not exist.

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv")
failures = gsk.edge_removal(net)                                      # random, 10 runs
eb = gsk.edge_betweenness_centrality(net)                             # largest component
attack = gsk.edge_removal(net, strategy = eb, component = 0)          # highest betweenness first
cut = gsk.edge_removal(net, strategy = [("alice", "bob"), ("bob", "carol")])

Node removal

graphoskop.node_removal(net, strategy='random', selection='top', quality='lcc', runs=10, points=100, component=None, samples=None, seed=None, recompute=False)

Robustness of a network to node failures or attacks: remove its nodes one by one, with their edges, and record the quality of the network after each removal (see the module description).

Parameters:

  • net – A Network.

  • strategy – "random" (failures), "friend_of_random" (acquaintance attack), node ids (the nodes to remove, in order), or node values (a measure: vector, list of vectors, dictionary or pandas.Series by node id, or the name of a numeric node attribute), or a function of the network returning node values.

  • selection – With a measure: "top" (largest values first) or "weighted" (drawn with probability proportional to the values).

  • quality – "lcc" (fraction of the nodes in the largest connected component) or "apl" (average shortest path length).

  • runs – Number of runs of the random strategies ("random", "friend_of_random", "weighted"); the others are run once.

  • points – Number of numbers of removals recorded, evenly spaced from none to all, or None for every removal.

  • component – Index of the component (0 is the largest), or None for the whole network.

  • samples – With "apl", the number of random source nodes of the searches at each point, or None for all the remaining nodes (exact).

  • seed – Seed of the random numbers, or None for a random seed.

  • recompute – With a measure given as a function of the network, True to compute it again on the remaining network after every removal (adaptive attack), a number of removals between computations, or False to compute it once.

Returns:

pandas.DataFrame indexed by the number of removed nodes (removed), with columns fraction (of the nodes removed), the mean quality (lcc or apl) and its confidence interval (lcc_low, lcc_high, …; NaN with a single run).

Raises:

  • ValueError – If a parameter is not valid, a vector does not have one value per node, or a node is outside the nodes considered.

  • KeyError – If a node does not exist.

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv")
failures = gsk.node_removal(net)                                      # random, 10 runs
k = gsk.degree(net, distribution = None)                              # one vector per component
attack = gsk.node_removal(net, strategy = k)                          # hubs first
soft = gsk.node_removal(net, strategy = k, selection = "weighted")    # hubs more likely first
friends = gsk.node_removal(net, strategy = "friend_of_random")
apl = gsk.node_removal(net, strategy = k, quality = "apl", points = 20)
failures.plot(x = "fraction", y = "lcc")
degree = lambda g: gsk.degree(g, distribution = None)
adaptive = gsk.node_removal(net, strategy = degree, recompute = True)   # largest current degree first
faster = gsk.node_removal(net, strategy = degree, recompute = 100)      # recomputed every 100 removals

Performance

On two CPU threads, 10 runs of random node failures with the largest component as quality take 0.7 s on a random network with 100,000 nodes and 500,000 edges, and 10 s with 1,000,000 nodes and 5,000,000 edges (every removal recorded internally). The average path length needs a full search at every recorded point: 20 points on 5,000 nodes and 25,000 edges take 8 s exactly, 0.5 s with samples = 200 (3.956 instead of 3.950 before any removal).

With recompute, the measure is computed again on a rebuilt copy of the remaining network, so the cost grows with the number of computations: an adaptive degree attack on 10,000 nodes and 50,000 edges takes 13 s with recompute = 100 and 1.4 s with recompute = 1000.

cascade_failures() runs the runs in parallel and only touches the items that receive load: 10 runs from 5 random failures take 0.9 s on 100,000 nodes and 500,000 edges, and 14 s on 1,000,000 nodes and 5,000,000 edges.
