Multilayer networks

Multilayer networks: single layers and the aggregate network.

A multilayer network (loaded with multilayer = True, see load_network()) is stored as its supra-graph. Each node is a copy of an entity in a layer, with input id (entity, layer); entities absent from a layer have no copy there. Intra-layer edges join copies in the same layer; interlayer edges join copies in different layers: couplings when both are copies of the same entity, otherwise interdependencies between different entities. All of them are ordinary edges of the components, so the Laplacian of a component is the supra-Laplacian of the multilayer network (e.g. as in the multilayer generalized Euclidean distance, Coscia 2022), and every function working on Laplacians, node vectors or paths works on the supra-graph unchanged. Couplings are explicit edges, with their weight in the edge attributes: the Laplacians read it as an affinity (the larger, the stronger the coupling); with unit weights (weight = None) every coupling weighs 1.

The functions here turn a multilayer network into ordinary networks: one of its layers, or all the layers flattened into one network of entities.

Representation

A multilayer network is stored as its supra-graph. A node is a copy of an entity in one layer, with input id (entity, layer), and internal id (component, index) like any other node. Entities absent from a layer have no copy there. Edges come in three kinds, all stored as ordinary edges:

  • intra-layer edges, between copies in the same layer;

  • couplings, between copies of the same entity in different layers;

  • other interlayer edges, between copies of different entities in different layers.

Components are the weakly connected components of the supra-graph, so a component can hold copies of many layers, connected through couplings. Within a component, nodes are sorted by layer (by type first, then by layer, in bipartite networks). Every component has two int64 tensors on its device: layer (position of the layer of each node in layer_labels) and entity (position of its entity in entity_ids). An edge (s, t) is interlayer if layer[s] != layer[t] (see interlayer_mask()) and a coupling if moreover entity[s] == entity[t]. entity_map maps every entity to its copies.

graphoskop.LAYER = "layer"

Otherwise, returns the result of object.__str__() (if defined) or repr(object). encoding defaults to ‘utf-8’. errors defaults to ‘strict’.

Loading

load_network() with multilayer = True reads an edge table with a layer column, an optional table of interlayer edges and an optional node table with the entity and the layer in its first two columns. Couplings are generated with coupling:

  • "all": every pair of copies of each entity (a multiplex); a warning is issued if there are more couplings than intra-layer edges, which happens with many layers;

  • "ordinal": copies in adjacent layers only, undirected (stored in both directions in directed networks). A copy is not coupled across a layer where its entity has no copy. Adjacency follows the layer order, so a layer without any node (e.g. a time step without contacts) must be declared in layers to separate its neighbors;

  • "temporal": from each copy to the copy in the next layer, forward only, so the network must be directed (give undirected contacts in both directions). Paths then respect time;

  • None: no generated couplings (interlayer edges are then only those given explicitly).

Layers are ordered by their values, or by layers. coupling_weight is a positive number or an L by L matrix (one value per pair of layers, in layer order), stored in every edge attribute of the generated couplings.

import graphoskop as gsk

# edges.tsv:   source   target   layer     weight
#              alice    bob      work      2
#              alice    carol    friends   1
net = gsk.load_network("edges.tsv", "nodes.tsv", multilayer = True, coupling = "all", coupling_weight = 0.5)
net.layer_labels                     # ("friends", "work")
net.node_map[("alice", "work")]      # (component, index)
net.entity_map["alice"]              # internal ids of both copies
net.number_of_edges(kind = "inter")  # couplings

# snapshots of a contact network, couplings forward in time
net = gsk.load_network("contacts.tsv", multilayer = True, layer = "day", coupling = "temporal", directed = True)

In the node table, a row with a missing layer applies to all the copies of its entity, and the rows of a copy override it: entity-wide attributes are given once, layer-specific ones per copy.

Analyses

  • Laplacians and node vectors (Laplacians, Node vector analysis): the Laplacian of a component is the supra-Laplacian, so generalized_euclidean() is the multilayer generalized Euclidean distance (Coscia, 2022), and resistances, solvers, correlations, variances and entropies are their multilayer versions. Couplings weigh as affinities. Dense matrices have one row per copy.

  • Degree (degree()): intra-layer edges only. A copy has its degree in its layer, an entity the sum over its copies; distributions are given per layer, or per entity with by = "entity".

  • Shortest paths (Shortest paths): on the supra-graph, changing layer along a coupling is a step. Entities can be given as origins or destinations (shortest over their copies). Use inverse = True for lengths consistent with coupling affinities.

  • Backboning (Backboning): layer by layer, as on layer_network(); interlayer edges are never scored and are kept between kept copies.

  • Bipartite projections (Bipartite projections): a bipartite multilayer network is bipartite in every layer (an entity has the same type in all its copies, and interlayer edges join nodes of the same type); projections are layer by layer, and keep the interlayer edges between the copies of the kept type.

Saving

save_network() writes prefix + "_edges.tsv" (intra-layer edges, with a layer column), prefix + "_interlayer.tsv" (all interlayer edges, couplings included) and prefix + "_nodes.tsv" (one row per copy). Load them back with multilayer = True and interlayer_edges; generated couplings already in the interlayer table are not added twice.

Single layers and aggregation

graphoskop.layer_network(net, layer)

One layer of a multilayer network, as an ordinary network of entities.

The nodes are the copies in that layer, with the entity as id, and the edges are the intra-layer edges of the layer; couplings and other interlayer edges are left out. All node and edge attributes are kept (an attribute classified as qualitative is read back as numeric if all its values in the layer look like numbers, as when saving and loading), and so are node types in bipartite networks. Components are recomputed, so they are the components of the layer.

Parameters:

  • net – A multilayer Network.

  • layer – Layer, one of net.layer_labels.

Returns:

The layer, a new Network.

Raises:

  • ValueError – If net is not multilayer, or the layer has no node.

  • KeyError – If there is no such layer.

Example:

import graphoskop as gsk

net = gsk.load_network("multiplex.tsv", multilayer = True, coupling = "all")
work = gsk.layer_network(net, "work")
gsk.degree(work, "alice") == gsk.degree(net, ("alice", "work"))   # True
graphoskop.aggregate_network(net, merge=True)

Aggregate (flattened) network of a multilayer network: one node per entity, with the edges of all layers.

This is the limit of infinitely strong couplings: the copies of each entity collapse into one node, couplings disappear and the other interlayer edges become ordinary edges between their entities (except in bipartite networks, where they would join two nodes of the same type, and are left out). With merge = True the edges between the same two entities (in the same direction, if directed), from any layer, are merged into one edge whose numeric attributes are the sums of theirs (NaN only if all are NaN): the weight of an edge is then its total weight over the layers, and the degree of an entity its number of distinct neighbors. With merge = False they stay as parallel edges, which give the same Laplacians.

Node attributes take, for each entity, the first value found in layer order (attributes given for the whole entity have the same value in every copy); node types are kept in bipartite networks.

Parameters:

  • net – A multilayer Network.

  • merge – Merge the edges between the same two entities.

Returns:

The aggregate network, a new Network.

Raises:

ValueError – If net is not multilayer.

Example:

import graphoskop as gsk

net = gsk.load_network("multiplex.tsv", multilayer = True, coupling = "all")
flat = gsk.aggregate_network(net)                    # edge weights summed over the layers
gsk.degree(flat, "alice")                            # distinct neighbors of alice

Signed networks

A signed network is a two-layer network, positive and negative, flattened into one network of entities whose edges carry a sign: build it from two layers with gsk.signed_network(net, positive = ..., negative = ...) (see Signed networks).
