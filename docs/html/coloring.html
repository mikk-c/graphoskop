Coloring and independent sets

Graph coloring and independent sets.

A coloring assigns a color to every node so that joined nodes have different colors: the nodes of each color form an independent set (no two of them joined). Both the fewest colors needed (the chromatic number) and the largest independent set (the independence number) are NP-hard to find, so the functions here combine bounds, which often settle the answer at once on real networks, with exact searches that stop after time_limit seconds; if a search is stopped, the best solution found is returned with a warning saying it is not proven optimal.

Edges are taken as undirected and unweighted (in directed networks, two nodes are joined if there is an edge in either direction); self loops are ignored (a node joined to itself could not be colored, nor be in an independent set). In multilayer networks only intra-layer edges count, so each layer is colored on its own (couplings would force the copies of an entity to have different colors). Components are solved independently. The searches run on the CPU.

import graphoskop as gsk

net = gsk.load_network("edges.tsv")
colors = gsk.graph_coloring(net)              # one array of node ids per color, fewest colors
mis = gsk.maximum_independent_set(net)        # node ids of a largest independent set
graphoskop.graph_coloring(net, component=None, time_limit=60)

Coloring of the nodes with as few colors as possible, as a division of the nodes into independent sets (see the module description for which edges count).

For each component, the number of colors is bracketed between a lower bound, the size of the largest clique (its nodes need different colors; found as in maximal_cliques()), and the coloring found by DSATUR (Brelaz, 1979). If they differ, an exact DSATUR backtracking search tries each smaller number of colors \(k\), after setting aside the nodes with fewer than \(k\) neighbors (repeatedly; they can always be colored afterwards). The coloring returned is then optimal, unless time_limit is reached: the best coloring found is returned, with a warning giving the bounds. Components are colored independently (smallest first, so that the time limit is spent on the hardest), with the same colors, so the number of colors is the largest over components.

Parameters:

  • net – A Network.

  • component – Index of the component (0 is the largest), or None for the whole network.

  • time_limit – Seconds after which the exact search stops (for the whole call).

Returns:

List of arrays of input node ids, one per color (independent sets), largest first.

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv")
colors = gsk.graph_coloring(net)
len(colors)                       # number of colors used (the chromatic number if no warning)
graphoskop.maximum_independent_set(net, component=None, time_limit=60)

Largest independent set: the largest set of nodes no two of which are joined (see the module description for which edges count).

Exact branch and reduce on each component: nodes that can always be taken (no neighbors, or neighbors all joined to each other) are taken, dominated nodes are removed, the remaining graph is split into connected pieces, and the search branches on a node of largest degree, pruned by a clique cover bound. Sparse real networks are often reduced to nothing without branching. If time_limit is reached, a greedy set (smallest degree first) is returned for the components not finished, with a warning that it is not proven maximum.

Parameters:

  • net – A Network.

  • component – Index of the component (0 is the largest), or None for the whole network.

  • time_limit – Seconds after which the search stops (for the whole call).

Returns:

Array of input node ids.

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv")
mis = gsk.maximum_independent_set(net)
len(mis)                          # independence number if no warning
