Exploration

Graph exploration: breadth first and depth first search, random walks and Metropolis-Hastings random walks from a node.

Searches return the nodes reached from the source, each once, in the order they are visited, with the node they were reached from (their parent in the search tree) and their depth in that tree; in breadth first search the depth is the number of edges of a shortest path from the source. Searches run on the CPU with scipy.sparse.csgraph (compiled code, \(O(n + m)\)), whatever the device of the network, as in shortest_paths. Neighbors are visited in order of internal index; parallel edges and self loops do not matter.

Random walks instead move for a given number of steps, each to a random neighbor of the current node: they need not reach every node, and can visit a node many times. A vanilla random walk visits nodes in proportion to their degree, in the long run (undirected networks); a Metropolis-Hastings random walk corrects this bias by refusing some moves: from \(u\) it proposes a random neighbor \(v\) and moves there with probability \(\min(1, k_u / k_v)\), otherwise it stays at \(u\) for that step, so that in the long run the walk spends the same number of steps on every node (as used in network sampling). Refused moves add nothing to the output, so a node is listed once for each time the walk arrives on it, with the number of steps it stayed there (its duration): weighting visits by duration gives the uniform distribution, counting visits alone still favors hubs, though less than a vanilla walk. With weight, neighbors are chosen with probability proportional to the weight of the edge, and \(k\) is the strength (sum of the weights) instead of the degree. Parallel edges count as many times as they appear and self loops are edges like the others (the walk can stay on its node). In directed networks a walk stops at a node without edges to follow; there, the correction of the Metropolis-Hastings walk is exact only with direction = "both". All the walks of a component advance together, one step at a time, on the device of the network.

Only the component of the source is explored. A source can be given as an iterable of nodes (a list, set, range, NumPy array or pandas Series or Index; a tuple is always one node): each is then explored on its own, and the result gains a first column source, with the node as given.

In hypergraphs (see Higher-order networks), a step of a random walk follows Zhou et al. (2006): a hyperedge of the current node, drawn in proportion to its weight \(w(e)\) (the hyperedge attribute weight, or uniformly), then a node of that hyperedge, uniformly, the current one included. In a directed hypergraph the step goes from a tail to a head (direction = "out"). Walks run as walks of twice the length on the incidence graph, and also report the hyperedge of every step. Metropolis-Hastings walks run on hypergraph_walk_network(), and explorations of simplicial complexes on their 1-skeleton (their nodes and edges); other walk models are walks on hypergraph_walk_network(). Searches do not support them.

In directed networks direction chooses the edges followed: "out" (along their direction), "in" (against it) or "both". In multilayer networks the exploration runs on the supra-graph (couplings are edges like the others). An entity given as source stands for all its copies: a search starts from all of them at once (as one source linked to each of them), and each random walk starts from one of them, drawn uniformly at random.

import graphoskop as gsk

net = gsk.load_network("edges.tsv")
gsk.bfs(net, "alice")                                   # node, depth, parent, in visit order
gsk.bfs(net, "alice", max_depth = 2)                    # neighborhood up to two edges away
gsk.bfs(net, ["alice", "bob"])                          # one search per source
gsk.dfs(net, "alice")
gsk.random_walk(net, "alice", 20, walks = 5)            # walk, step, node
gsk.metropolis_hastings_random_walk(net, "alice", 20)   # not biased towards hubs
graphoskop.bfs(net, source, direction='out', max_depth=None)

Breadth first search: the nodes reachable from source, by increasing number of edges from it (see the module description).

Hypergraphs and simplicial complexes: not supported (see Higher-order networks).

Parameters:

  • net – A Network.

  • source – Starting node (input id, internal id (component, index), or entity in multilayer networks), or an iterable of them, searched one by one.

  • direction – In directed networks, "out", "in" or "both"; ignored otherwise.

  • max_depth – Only nodes at most this many edges away, or None for all.

Returns:

pandas.DataFrame in visit order, with columns node (input id), depth (number of edges from the source, 0 for the source) and parent (input id of the node it was reached from, missing for the source); first source with an iterable.

Raises:

  • ValueError – If direction is not valid.

  • KeyError – If there is no such node.

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv")
tree = gsk.bfs(net, "alice")
friends_of_friends = tree.node[tree.depth == 2]
gsk.bfs(net, "alice", max_depth = 1)          # alice and her neighbors
gsk.bfs(net, ["alice", "bob"], max_depth = 1) # both, with a column source
graphoskop.dfs(net, source, direction='out')

Depth first search: the nodes reachable from source, each followed by all the nodes reached through it before backtracking (preorder; see the module description).

Hypergraphs and simplicial complexes: not supported (see Higher-order networks).

Parameters:

  • net – A Network.

  • source – Starting node (input id, internal id (component, index), or entity in multilayer networks), or an iterable of them, searched one by one.

  • direction – In directed networks, "out", "in" or "both"; ignored otherwise.

Returns:

pandas.DataFrame in visit order, with columns node (input id), depth (depth in the search tree, 0 for the source) and parent (input id of the node it was reached from, missing for the source); first source with an iterable.

Raises:

  • ValueError – If direction is not valid.

  • KeyError – If there is no such node.

Example:

tree = gsk.dfs(net, "alice")
tree.node.tolist()                            # visit order
graphoskop.metropolis_hastings_random_walk(net, source, length, walks=1, weight=None, direction='out', seed=None)

Metropolis-Hastings random walks: as random_walk(), but a move from \(u\) to the drawn neighbor \(v\) happens only with probability \(\min(1, k_u / k_v)\) (degrees, or strengths with weight); otherwise the walk stays at \(u\) for that step, and nothing is added to the output. Moves towards hubs are refused more often, which corrects the bias of random walks towards them: in the long run the walk spends the same number of steps on every node (undirected networks, or direction = "both"; see the module description). The duration of each visit (1 plus the moves refused there) keeps that count.

Hypergraphs and simplicial complexes: supported (see Higher-order networks).

Parameters:

  • net – A Network.

  • source – Starting node (input id, internal id (component, index), or entity in multilayer networks), or an iterable of them, each with its own walks.

  • length – Number of steps of each walk, refused moves included (the walk lists at most length + 1 nodes).

  • walks – Number of walks from each source.

  • weight – Name of the edge attribute used as edge weight, or None for unit weights.

  • direction – In directed networks, "out", "in" or "both"; ignored otherwise.

  • seed – Seed of the random numbers, or None for a random seed.

Returns:

pandas.DataFrame with one row per arrival on a node, by walk: columns walk, step (0 for the source, then 1, 2, … over accepted moves only), node (input id) and duration (number of steps spent on the node: 1 plus the moves refused there; durations of a walk add up to length + 1, unless it stopped early); first source with an iterable.

Raises:

  • ValueError – If direction is not valid, length is negative, walks is below 1, or some weights are negative or NaN.

  • KeyError – If there is no such node or edge attribute.

Example:

w = gsk.metropolis_hastings_random_walk(net, "alice", 1000, walks = 10, seed = 0)
share = w.groupby("node").duration.sum() / w.duration.sum()   # about uniform
graphoskop.random_walk(net, source, length, walks=1, weight=None, direction='out', seed=None)

Random walks: from source, length steps, each to a neighbor of the current node drawn uniformly at random (or in proportion to the edge weights), possibly repeated (see the module description). Nodes can be visited many times, and not every node is reached.

Hypergraphs and simplicial complexes: supported (see Higher-order networks).

Parameters:

  • net – A Network.

  • source – Starting node (input id, internal id (component, index), or entity in multilayer networks), or an iterable of them, each with its own walks.

  • length – Number of steps of each walk.

  • walks – Number of walks from each source.

  • weight – Name of the edge attribute used as edge weight (neighbors are drawn in proportion to it), or None for uniform choices; in hypergraphs, a hyperedge attribute \(w(e)\).

  • direction – In directed networks, "out", "in" or "both"; ignored otherwise.

  • seed – Seed of the random numbers, or None for a random seed.

Returns:

pandas.DataFrame with one row per visit, by walk and step: columns walk (0 to walks - 1), step (0 for the source) and node (input id); first source with an iterable; for hypergraphs, last hyperedge (the Hyperedge taken to reach the node, None at step 0). In directed networks a walk ends early at a node without edges to follow.

Raises:

  • ValueError – If direction is not valid, length is negative, walks is below 1, or some weights are negative or NaN.

  • KeyError – If there is no such node or edge attribute.

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv")
w = gsk.random_walk(net, "alice", 10)                 # walk, step, node
w = gsk.random_walk(net, "alice", 10, walks = 100)    # 100 walks from alice
visits = w.node.value_counts()
gsk.random_walk(net, ["alice", "bob"], 10, weight = "weight", seed = 1)

net = gsk.load_hypergraph({"m1": ["a", "b", "c"], "m2": ["b", "d"]})
w = gsk.random_walk(net, "a", 10, seed = 1)           # walk, step, node, hyperedge
