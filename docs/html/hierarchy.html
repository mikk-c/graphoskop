Hierarchy

Hierarchy in directed networks: how far the nodes are organized in levels, with some nodes reaching (or controlling) many others and being reached by few.

global_reach_centrality() measures it from the local reaching centrality of the nodes (see centrality).

graphoskop.global_reach_centrality(net, component=0, direction='out', lengths=None, n_jobs=None)

Global reaching centrality (Mones, Vicsek and Vicsek, 2012), a measure of hierarchy: how much the most reaching node exceeds the others, \(GRC = \sum_i (C_R^{max} - C_R(i)) / (N - 1)\), with \(C_R\) the local reaching centrality of reach_centrality() and \(C_R^{max}\) its largest value. It is 1 for a star with edges out of its center and 0 when every node reaches all the others (e.g. a directed cycle). With component = None the sum and the maximum run over all components.

Parameters:

  • net – A directed Network.

  • component – Index of the component (0 is the largest), or None for all components at once.

  • direction – "out" (nodes reached) or "in" (nodes reaching).

  • lengths – Precomputed lengths, as for reach_centrality(), or None.

  • n_jobs – Number of processes for the searches, None for all CPUs.

Returns:

The global reaching centrality, a float.

Raises:

ValueError – If the network is undirected, direction is not valid, or lengths does not match.

Example:

gsk.global_reach_centrality(net)                    # largest component
