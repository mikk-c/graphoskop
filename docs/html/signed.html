Signed networks

Signed networks: construction, signed adjacency matrix and structural balance.

A signed network is an ordinary Network whose edges carry a sign, +1 (a positive relationship: friendship, trust, alliance) or -1 (a negative one: enmity, distrust, conflict), in a numeric edge attribute, by default SIGN. It can be seen as a multilayer network with two layers, positive and negative, flattened into one network of entities: an edge is in exactly one of the two layers. signed_network() builds one in either of two ways:

  • from a multilayer network, naming its positive and its negative layer. Two entities cannot be joined by an edge in both layers (in the same direction, if directed);

  • from an ordinary network, thresholding an edge attribute: edges at or above the threshold are positive, edges below it negative.

The signed adjacency matrix \(A\) (signed_adjacency()) has \(A_{ij}\) equal to the sign of the edge from \(i\) to \(j\), and 0 without an edge; parallel edges count once (they must have the same sign). Edges with sign 0 or NaN in the sign attribute are treated as absent.

graphoskop.SIGN = "sign"

Otherwise, returns the result of object.__str__() (if defined) or repr(object). encoding defaults to ‘utf-8’. errors defaults to ‘strict’.

Building a signed network

import graphoskop as gsk

# (i) two layers of a multilayer network
# relations.tsv:   source   target   layer
#                  alice    bob      ally
#                  bob      carol    enemy
net = gsk.load_network("relations.tsv", multilayer = True)
signed = gsk.signed_network(net, positive = "ally", negative = "enemy")

# (ii) thresholding an edge attribute of an ordinary network
net = gsk.load_network("ratings.tsv")                  # column "score"
signed = gsk.signed_network(net, weight = "score", threshold = 3)   # score >= 3 positive

signed.get_edge_attribute("sign")                       # +1 / -1, one entry per stored edge

The result is an ordinary network, so every other function works on it; the sign is one more edge attribute, kept when saving and loading.

graphoskop.signed_adjacency(net, component=0, sign='sign')

Signed adjacency matrix of a component of a signed network.

\(A_{ij}\) is the sign (+1 or -1) of the edge from \(i\) to \(j\), 0 without an edge; the matrix is symmetric in undirected networks. Parallel edges count once, self loops are kept on the diagonal. Rows and columns are ordered by internal node index.

Parameters:

  • net – A signed Network (see signed_network()).

  • component – Index of the component (0 is the largest), or None for a list with one matrix per component.

  • sign – Edge attribute (name or position) holding the sign.

Returns:

Sparse COO tensor (coalesced), n by n, in the dtype of the edge attributes and on the device of the component.

Raises:

  • ValueError – If the network is multilayer, or parallel edges have opposite signs.

  • KeyError – If there is no such edge attribute.

Example:

A = gsk.signed_adjacency(signed)
A.to_dense()
graphoskop.signed_network(net, positive=None, negative=None, weight=None, threshold=0, sign='sign')

Signed network, from two layers of a multilayer network or by thresholding an edge attribute.

  • positive and negative given: net must be multilayer. The result is a network of entities with the intra-layer edges of the two layers, signed +1 and -1. Couplings, other interlayer edges and the other layers are left out. An edge present in both layers (between the same two entities, in the same direction if directed) raises ValueError: an edge cannot be positive and negative at the same time. Nodes are the entities with a copy in either layer; node attributes take the first value found in layer order, as in aggregate_network().

  • weight given: net must not be multilayer. Edges whose weight is greater than or equal to threshold are signed +1, the others -1; edges with a NaN weight are dropped. Parallel edges with opposite signs raise ValueError. All nodes are kept, also those left without edges.

All edge attributes are kept, and the sign is stored as the edge attribute sign (replaced if it exists). Components are recomputed, so they are the components of the signed network; node attributes and node types (bipartite networks) are kept, and so are the device and directedness.

Parameters:

  • net – A Network.

  • positive – Positive layer, one of net.layer_labels.

  • negative – Negative layer, one of net.layer_labels.

  • weight – Edge attribute (name or position in edge_attributes) to threshold.

  • threshold – Threshold on weight.

  • sign – Name of the edge attribute storing the sign.

Returns:

The signed network, a new Network.

Raises:

  • ValueError – If both or neither of the two ways are given, if net is not multilayer (layers) or is multilayer (weight), if the two layers are the same, or if an edge is both positive and negative.

  • KeyError – If there is no such layer or edge attribute.

Example:

import graphoskop as gsk

net = gsk.load_network("relations.tsv", multilayer = True)       # layers "ally", "enemy"
signed = gsk.signed_network(net, positive = "ally", negative = "enemy")

net = gsk.load_network("votes.tsv")                               # column "score"
signed = gsk.signed_network(net, weight = "score", threshold = 0.5)
gsk.structural_balance(signed)

Structural balance and signed triangles

gsk.structural_balance(signed)        # Tr(A^3) / Tr(|A|^3), a float
gsk.structural_balance(signed, beta = 0.5)   # Tr(exp(beta A)) / Tr(exp(beta |A|)), all closed walks
gsk.signed_triangle_counts(signed)    # count of each type, expected under shuffled signs, ratio, z
graphoskop.signed_triangle_counts(net, component=None, sign='sign', batch_size=4194304)

Number of triangles of each sign pattern, compared with randomly shuffled signs.

In undirected networks there are four types, by the signs of their edges: "+++", "++-", "+--" and "---". In directed networks a triangle is three directed edges joining three nodes, one per pair (a pair joined in both directions is in two triangles). It is either a cycle \(i \to j \to k \to i\), with types "cycle +++" to "cycle ---" as above, or a feedforward loop \(i \to j \to k\), \(i \to k\), with eight types such as "feedforward +-+", the signs given in the order source to middle, middle to sink, source to sink. Which types are balanced is left to the user; structural_balance() takes "+++" and "+--" (cycles, in directed networks).

Each count is compared with its expected value when the signs are shuffled at random among the edges, keeping the number of positive and negative edges (self loops are left out). The mean and the variance under this null model are computed exactly, without sampling: the variance accounts for triangles sharing edges, from how many triangles use each edge in each position. ratio is the count over its expected value (above 1: overrepresented), z the count minus its expected value, over the standard deviation. Self loops are ignored and parallel edges count once. The triangles are found as in structural_balance(); the null model adds memory for 4 integers per edge.

Parameters:

  • net – A signed Network (see signed_network()).

  • component – Index of the component (0 is the largest), or None for the whole network (signs are then shuffled over all its edges).

  • sign – Edge attribute (name or position) holding the sign.

  • batch_size – Number of 2-paths expanded at once; larger is faster, especially on GPU, and uses more memory.

Returns:

pandas.DataFrame with columns triangle (the type), count, expected, ratio and z; NaN where the expected value or the variance is 0.

Raises:

  • ValueError – If the network is multilayer, or parallel edges have opposite signs.

  • KeyError – If there is no such edge attribute.

Example:

import graphoskop as gsk

signed = gsk.signed_network(gsk.load_network("ratings.tsv"), weight = "score", threshold = 3)
gsk.signed_triangle_counts(signed)
#   triangle  count  expected  ratio      z
# 0      +++   8120    7311.4   1.11   12.0
# ...
graphoskop.structural_balance(net, component=None, sign='sign', beta=None, exact=None, samples=60, steps=40, seed=0, batch_size=4194304)

Structural balance of a signed network, over its triangles or over all its closed walks.

With beta = None, over triangles:

\[\frac{\mathrm{Tr}(A^3)}{\mathrm{Tr}(|A|^3)} = \frac{B - U}{B + U},\]

with \(A\) the signed adjacency matrix (signed_adjacency()), \(B\) the number of balanced triangles (the product of the signs of their edges is positive: "+++" and "+--") and \(U\) the number of unbalanced ones ("++-" and "---"): 1 if all triangles are balanced, -1 if none is, NaN if there are no triangles. In directed networks the triangles are the directed 3-cycles \(i \to j \to k \to i\). For the counts of each type, and their comparison with shuffled signs, see signed_triangle_counts(). The traces are computed without forming \(A^3\): the pairs of adjacent nodes are oriented from lower to higher degree, and each triangle is found once by expanding the 2-paths along the orientation (the work grows with \(m^{3/2}\) at most, even with hubs). Paths are expanded in batches of batch_size (about 50 bytes per path). Counts are exact (integers).

With beta given, over all closed walks (walk-based balance, Estrada and Benzi, 2014):

\[\frac{\mathrm{Tr}(e^{\beta A})}{\mathrm{Tr}(e^{\beta |A|})} = \frac{\sum_k \frac{\beta^k}{k!} \mathrm{Tr}(A^k)}{\sum_k \frac{\beta^k}{k!} \mathrm{Tr}(|A|^k)},\]

in \((0, 1]\) for undirected networks. Closed walks of length \(k\) weigh \(\beta^k / k!\), so longer cycles count less, and more so the smaller \(\beta\) (even with \(\beta = 1\) a walk of length \(k\) weighs \(1 / k!\)). The traces include the walks of length 0 (one per node, isolated nodes included) and 2 (always positive), so the ratio tends to 1 as \(\beta \to 0\); as \(\beta\) grows it is dominated by the largest eigenvalues. Traces are computed per component and summed:

  • exactly, from the eigenvalues of the dense matrix (\(O(n^3)\)), for components with at most 2048 nodes (exact = None), or for all components (exact = True);

  • otherwise by stochastic estimation (Hutch++, Meyer et al., 2021), without forming \(e^{\beta A}\): \(e^{\beta A}\) is applied to samples random vectors with steps Arnoldi iterations each (sparse matrix products, on the device of the network). The walks of length up to 3 are counted exactly (length 3 from the triangles); for the longer ones, the dominant directions found with the first half of the vectors are traced exactly, and only the remainder is estimated with the second half. \(A\) and \(|A|\) use the same random vectors, so that their errors partly cancel in the ratio. Memory is about 8 * steps * n bytes per vector, with vectors processed in groups of at most batch_size / (steps * n). More samples reduce the random error, more steps the truncation error (needed for large \(\beta \lambda_{max}\)). Results depend on seed.

Self loops are ignored and parallel edges count once.

Parameters:

  • net – A signed Network (see signed_network()).

  • component – Index of the component (0 is the largest), or None for the whole network.

  • sign – Edge attribute (name or position) holding the sign.

  • beta – None for triangles, or a positive number for closed walks.

  • exact – With beta: None (exact for small components only), True or False.

  • samples – With beta: number of random vectors of the stochastic estimate.

  • steps – With beta: Arnoldi iterations per vector.

  • seed – With beta: seed of the random vectors.

  • batch_size – Number of 2-paths expanded at once (triangles), or bound on the number of entries of the Krylov bases held at once (walks); larger is faster, especially on GPU, and uses more memory.

Returns:

The balance, a float.

Raises:

  • ValueError – If the network is multilayer, parallel edges have opposite signs, or beta is not positive.

  • KeyError – If there is no such edge attribute.

Example:

import graphoskop as gsk

net = gsk.load_network("relations.tsv", multilayer = True)
signed = gsk.signed_network(net, positive = "ally", negative = "enemy")
gsk.structural_balance(signed)                  # triangles: 0.62
gsk.structural_balance(signed, beta = 0.5)      # all closed walks
