Laplacians

Laplacians of network components, their pseudoinverses, and Laplacian solvers; random walks (stationary distribution, fundamental matrix).

All functions take a Network and a component index (default 0, the largest component; None applies the function to every component and returns a list).

For undirected networks the Laplacian is \(D - A\). For directed networks kind selects:

  • "out": out-degree Laplacian \(D_{out} - A\).

  • "magnetic": magnetic Laplacian \(D_s - A_s \odot e^{i \Theta}\), with \(A_s = (A + A^T) / 2\), \(D_s\) its degree matrix and \(\Theta = 2 \pi q (A - A^T)\). Hermitian and complex valued.

  • "chung": Chung’s combinatorial Laplacian \(\Phi - (\Phi P + P^T \Phi) / 2\), with \(P\) the random walk transition matrix with teleportation probability alpha (dangling nodes teleport uniformly) and \(\Phi\) the diagonal matrix of its stationary distribution. Symmetric and real valued; dense if alpha > 0 or there are dangling nodes. The stationary distribution is available on its own as stationary_distribution().

\(A\) is the (weighted) adjacency matrix; parallel edges are summed and self loops do not affect the Laplacian. Rows and columns are ordered by internal node index.

In multilayer networks \(A\) is the supra-adjacency matrix: rows and columns are the copies (entity, layer) of the component, and couplings and other interlayer edges are entries like intra-layer edges, so \(L\) is the supra-Laplacian (as in Coscia, 2022, “Generalized Euclidean measure to estimate distances on multilayer networks”). Coupling weights must be positive, so that a component is connected through them; infinitely strong couplings give the Laplacian of aggregate_network(). Dense matrices have one row per copy, so they take about \(L^2\) times the memory of a single layer with \(L\) layers: on large networks, prefer laplacian_solver(). The random walks of stationary_distribution() and of the Chung Laplacian move along couplings like along any edge, with probability proportional to their weight.

Hypergraphs (see Higher-order networks) use the random walk of Zhou, Huang and Schölkopf (2006): from a node, a hyperedge containing it with probability proportional to its weight \(w(e)\) (weight names a hyperedge attribute; 1 without it), then a node of that hyperedge uniformly, itself included. Every function here works on the network of that walk (hypergraph_walk_network()), with weights \(A_{uv} = \sum_{e \ni u, v} w(e) / |e|\): the Laplacian \(D - A\) is the hypergraph Laplacian of Zhou et al., effective resistances are those of the incidence graph between nodes, and the stationary distribution (without teleportation) is proportional to \(\sum_{e \ni u} w(e)\). Building that network takes memory and time growing with the squares of the hyperedge sizes. Other walk models (Carletti et al., 2020; edge-dependent vertex weights, Chitra and Raphael, 2019) are networks of hypergraph_walk_network() to pass to these functions. Directed hypergraphs are not supported yet. Simplicial complexes use their 1-skeleton, unweighted: its Laplacian is the Hodge Laplacian \(L_0 = B_1 B_1^T\) (see hodge_laplacian() for the Laplacians of edges and higher simplices).

graphoskop.effective_resistance(net, component=0, lpinv=None, weight=None, kind='out', q=0.25, alpha=0.15)

Effective resistance between all pairs of nodes, \(R_{uv} = (e_u - e_v)^H L^+ (e_u - e_v) = L^+_{uu} + L^+_{vv} - L^+_{uv} - L^+_{vu}\), with \(L^+\) the pseudoinverse of the Laplacian (see laplacian()). For complex Laplacians the real part is taken.

\(L^+\) is used as given in lpinv (a dense tensor from laplacian_pinv(), left unchanged), or computed if None. A computed real symmetric \(L^+\) is turned into \(R\) in place, so no further n by n matrix is allocated.

Hypergraphs and simplicial complexes: supported (see Higher-order networks).

Parameters:

  • net – A Network.

  • component – Index of the component (0 is the largest), or None for all components. With None, lpinv is given as a list with one entry per component.

  • lpinv – Cached dense pseudoinverse, or None.

  • weight – Name of the edge attribute used as edge weight, or None for unit weights.

  • kind – Laplacian of directed networks: "out", "magnetic" or "chung".

  • q – Charge of the magnetic Laplacian.

  • alpha – Teleportation probability of the Chung Laplacian.

Returns:

Real n by n tensor, rows and columns ordered by internal node index, or a list of them if component is None.

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv")
R = gsk.effective_resistance(net, weight = "weight")
c, i = net.node_map["alice"]
c, j = net.node_map["bob"]
r = R[i, j]                                     # if both are in component 0
graphoskop.fundamental_matrix(net, component=0, weight=None, alpha=0.0)

Fundamental matrix of the random walk on network components (Kemeny and Snell, 1960):

\[F = (I - W + W^\infty)^{-1} = \sum_{k \geq 0} (W - W^\infty)^k,\]

with \(W\) the column stochastic transition matrix (\(W_{ji}\) the probability of a step from \(i\) to \(j\), so that \(W^k a\) is where the mass \(a\) is after \(k\) steps) and \(W^\infty = \pi 1^T\) its limit, every column being the stationary distribution \(\pi\). For a vector \(\delta\) summing to zero, \(F \delta = \sum_k W^k \delta\). Used by annihilation_distance().

At each step the walker follows an out edge with probability proportional to its weight (self loops make it stay), or, with probability alpha, jumps to a uniformly random node; dangling nodes always jump. The walk must have a unique stationary distribution: always on undirected components and with alpha > 0; on directed components without teleportation, there must be a single group of nodes that the walk cannot leave (nodes outside it are left forever, and get no stationary mass). On periodic walks (e.g. bipartite networks without teleportation) \(F\) exists, and the series converges in the Cesaro sense (averages of its partial sums).

Dense: \(O(n^3)\) time and a few \(n^2\) matrices, on the device of the component.

Hypergraphs and simplicial complexes: supported (see Higher-order networks).

Parameters:

  • net – A Network.

  • component – Index of the component (0 is the largest), or None for all components.

  • weight – Name of the edge attribute used as edge weight, or None for unit weights.

  • alpha – Teleportation probability.

Returns:

Float64 n by n tensor, or a list of them if component is None.

Raises:

ValueError – If the walk has no unique stationary distribution, or some weights are negative.

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv", "nodes.tsv")
F = gsk.fundamental_matrix(net)
d = gsk.annihilation_distance(net, "y2000", "y2010", F = F)
graphoskop.hitting_time(net, component=0, lpinv=None, weight=None, alpha=0)

Hitting times between all pairs of nodes: \(H_{ij}\) is the expected number of steps a random walk starting at \(i\) takes to reach \(j\) for the first time (\(H_{ii} = 0\)). The walk is the one of stationary_distribution(): it follows an out edge with probability proportional to its weight (self loops included: the walk may stay), or, with probability alpha, jumps to a uniformly random node; dangling nodes always jump. Hitting times are not symmetric, even in undirected networks; \(H_{ij} + H_{ji}\) is the commute time, \(\mathrm{vol} \cdot R_{ij}\) in undirected networks (effective_resistance()).

  • Undirected networks with alpha = 0: from the Laplacian pseudoinverse, \(H_{ij} = \sum_k d_k (L^+_{ik} - L^+_{ij} - L^+_{jk} + L^+_{jj})\), with \(d\) the (weighted) degrees. \(L^+\) is used as given in lpinv (from laplacian_pinv() with the same weight) or computed.

  • Otherwise (directed networks, or alpha > 0), from the fundamental matrix of the walk (Kemeny and Snell): \(H_{ij} = (Z_{jj} - Z_{ij}) / \pi_j\), with \(Z = (I - P + \mathbf{1} \pi^T)^{-1}\), \(P\) the transition matrix and \(\pi\) its stationary distribution, found exactly (not by power iteration), so periodic walks are fine. lpinv is ignored. With alpha = 0 the walk must be able to reach every node from every node (dangling nodes jump anywhere, so this fails when a set of nodes has edges only among themselves; restrict to a strongly connected component, see to_strongly_connected(), or use alpha > 0), otherwise some hitting times are infinite.

Both are dense \(O(n^3)\) computations in float64 on the device of the component, with a few n by n matrices. In multilayer networks the walk moves along couplings like along any edge.

Hypergraphs and simplicial complexes: supported (see Higher-order networks).

Parameters:

  • net – A Network.

  • component – Index of the component (0 is the largest), or None for all components. With None, lpinv is given as a list with one entry per component.

  • lpinv – Cached dense pseudoinverse (undirected networks, alpha = 0), or None.

  • weight – Name of the edge attribute used as edge weight, or None for unit weights.

  • alpha – Teleportation probability.

Returns:

Float64 n by n tensor, rows (origins) and columns (targets) ordered by internal node index, or a list of them if component is None.

Raises:

ValueError – If alpha = 0 and some node cannot reach some other.

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv")
H = gsk.hitting_time(net)
c, i = net.node_map["alice"]
c, j = net.node_map["bob"]
H[i, j], H[j, i]                         # alice to bob, bob to alice (if in component 0)

net = gsk.load_network("follows.tsv", directed = True)
H = gsk.hitting_time(net, alpha = 0.15)  # PageRank walk
graphoskop.laplacian(net, component=0, weight=None, kind='out', q=0.25, alpha=0.15, sparse=False)

Laplacian of network components (see the module description for the available kinds).

Hypergraphs and simplicial complexes: supported (see Higher-order networks).

Parameters:

  • net – A Network.

  • component – Index of the component (0 is the largest), or None for all components.

  • weight – Name of the edge attribute used as edge weight, or None for unit weights.

  • kind – Laplacian of directed networks: "out", "magnetic" or "chung".

  • q – Charge of the magnetic Laplacian.

  • alpha – Teleportation probability of the Chung Laplacian.

  • sparse – Return a sparse CSR tensor instead of a dense one. Not possible for a Chung Laplacian with teleportation or dangling nodes, which is dense.

Returns:

n by n tensor on the device of the component, or a list of them if component is None.

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv", directed = True)
L = gsk.laplacian(net)                                   # largest component, out-degree
L = gsk.laplacian(net, kind = "magnetic", sparse = True)
graphoskop.laplacian_pinv(net, component=0, weight=None, kind='out', q=0.25, alpha=0.15)

Moore-Penrose pseudoinverse of the Laplacian of network components.

Undirected, "magnetic" and "chung" Laplacians are Hermitian positive semidefinite with a known null space (constant vector, gauge vector of balanced magnetic phases, or none), so the pseudoinverse is computed exactly and in place with a Cholesky factorization: the only n by n matrix allocated is the result. "out" has no known null space and uses torch.linalg.pinv() (singular value decomposition, several n by n matrices, small singular values below its default threshold are treated as zero). For components too large for a dense n by n matrix, use laplacian_solver().

Hypergraphs and simplicial complexes: supported (see Higher-order networks).

Parameters:

  • net – A Network.

  • component – Index of the component (0 is the largest), or None for all components.

  • weight – Name of the edge attribute used as edge weight, or None for unit weights.

  • kind – Laplacian of directed networks: "out", "magnetic" or "chung".

  • q – Charge of the magnetic Laplacian.

  • alpha – Teleportation probability of the Chung Laplacian; use alpha > 0 unless the component is strongly connected and aperiodic.

Returns:

Dense n by n tensor on the device of the component, or a list of them if component is None.

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv")
lp = gsk.laplacian_pinv(net)                            # largest component, unweighted
lps = gsk.laplacian_pinv(net, None, weight = "weight")  # all components, weighted

net = gsk.load_network("edges.tsv", directed = True)
lp = gsk.laplacian_pinv(net, kind = "magnetic", q = 0.1)
lp = gsk.laplacian_pinv(net, kind = "chung", alpha = 0.1)
graphoskop.laplacian_solver(net, component=0, weight=None, kind='out', q=0.25, alpha=0.15, tol=1e-08, max_iter=None)

Solver computing \(L^+ b\) without forming the pseudoinverse \(L^+\).

The Laplacian is kept sparse (plus a rank two term for the Chung Laplacian), so memory is linear in the number of edges and nodes. Hermitian Laplacians (undirected, "magnetic", "chung") use Jacobi preconditioned conjugate gradient on the range of \(L\); the "out" Laplacian uses CGLS, which converges to the minimum norm least squares solution. Both give \(L^+ b\). Computations run in double precision on the device of the component.

The returned function solve(b) accepts:

  • a vector of length n or an n by k matrix (one right hand side per column), as a numpy.ndarray (the result is a numpy.ndarray) or a torch.Tensor;

  • a numeric node attribute, by position in net.node_attributes or by name (the result is a torch.Tensor). Missing values must be filled beforehand, as they propagate as NaN.

Hypergraphs and simplicial complexes: supported (see Higher-order networks).

Parameters:

  • net – A Network.

  • component – Index of the component (0 is the largest), or None for all components.

  • weight – Name of the edge attribute used as edge weight, or None for unit weights.

  • kind – Laplacian of directed networks: "out", "magnetic" or "chung".

  • q – Charge of the magnetic Laplacian.

  • alpha – Teleportation probability of the Chung Laplacian.

  • tol – Relative residual tolerance.

  • max_iter – Maximum number of iterations, 10 * n if None.

Returns:

The function solve, or a list of them if component is None. Its attribute solve.transpose computes \((L^+)^T b\) in the same way.

Example:

import numpy as np
import graphoskop as gsk

net = gsk.load_network("edges.tsv", "nodes.tsv")
solve = gsk.laplacian_solver(net, weight = "weight")
x = solve("age")                                          # node attribute by name
x = solve(0)                                              # node attribute by position
x = solve(np.random.rand(net.components[0].num_nodes))
graphoskop.stationary_distribution(net, component=0, weight=None, alpha=0.15, tol=1e-12, max_iter=10000)

Stationary distribution of the random walk with teleportation on network components.

At each step the walker follows an out edge with probability proportional to its weight, or, with probability alpha, jumps to a uniformly random node. Dangling nodes (without out edges) always jump. With alpha = 0 this is the plain random walk, whose stationary distribution is unique only on strongly connected aperiodic components. On undirected networks with alpha = 0 it is proportional to the (weighted) degree.

Hypergraphs and simplicial complexes: supported (see Higher-order networks).

Parameters:

  • net – A Network.

  • component – Index of the component (0 is the largest), or None for all components.

  • weight – Name of the edge attribute used as edge weight, or None for unit weights.

  • alpha – Teleportation probability.

  • tol – Convergence threshold of the power iteration (L1 change between iterations).

  • max_iter – Maximum number of power iterations.

Returns:

Float64 vector of length n summing to 1, on the device of the component, or a list of them if component is None.

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv", directed = True)
phi = gsk.stationary_distribution(net)                 # PageRank, damping 0.85
phi = gsk.stationary_distribution(net, alpha = 0)      # plain random walk
