Node vector analysis

Analysis of vectors defined on the nodes of a network: generalized Euclidean distance, network correlation, variance and entropy.

In multilayer networks, vectors are defined on the copies (entity, layer) of a component, and distances use the supra-Laplacian (see Laplacians): this is the multilayer generalized Euclidean distance (Coscia, 2022). An attribute given for a whole entity has its value on every copy; for the probability distributions of network_variance() and network_entropy(), this gives more mass to the entities present in more layers.

graphoskop.generalized_euclidean(net, a, b=None, component=0, lpinv=None, sparse=False, weight=None, kind='out', q=0.25, alpha=0.15)

Generalized Euclidean distance \(\sqrt{(a - b)^H L^+ (a - b)}\) between two node vectors, or norm \(\sqrt{a^H L^+ a}\) of a single one, with \(L^+\) the pseudoinverse of the Laplacian (see laplacian() for the available Laplacians).

\(L^+\) is used as given in lpinv, either as a dense tensor (from laplacian_pinv()) or as a solver (from laplacian_solver()). If lpinv is None it is computed, densely or, if sparse, as a solver. Pass lpinv to reuse it across calls.

For Hermitian Laplacians (undirected, "magnetic", "chung") the quadratic form is non negative. The "out" Laplacian is not symmetric, so the quadratic form can be negative, and the result is then NaN. Missing attribute values propagate as NaN.

Parameters:

  • net – A Network.

  • a – Node attribute (position in net.node_attributes or name), or vector of length n (numpy.ndarray or torch.Tensor).

  • b – Second node vector, same modalities as a, or None.

  • component – Index of the component (0 is the largest), or None for all components. With None, vectors and lpinv are given as lists with one entry per component.

  • lpinv – Cached pseudoinverse or solver, or None.

  • sparse – Compute a solver instead of the dense pseudoinverse when lpinv is None.

  • weight – Name of the edge attribute used as edge weight, or None for unit weights.

  • kind – Laplacian of directed networks: "out", "magnetic" or "chung".

  • q – Charge of the magnetic Laplacian.

  • alpha – Teleportation probability of the Chung Laplacian.

Returns:

Distance, or list of distances if component is None.

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv", "nodes.tsv")
d = gsk.generalized_euclidean(net, "age", "height")       # attributes by name
d = gsk.generalized_euclidean(net, 0, sparse = True)      # norm, attribute by position
lp = gsk.laplacian_pinv(net)
d = gsk.generalized_euclidean(net, x, y, lpinv = lp)      # vectors, cached pseudoinverse
ds = gsk.generalized_euclidean(net, "age", component = None)
graphoskop.network_correlation(net, a, b, component=0, W=None, k=1, lpinv=None, weight=None, kind='out', q=0.25, alpha=0.15)

Network Pearson correlation (Coscia, 2021; Coscia and Devriendt, 2024, https://arxiv.org/abs/2402.09489):

\[\rho_{a, b, G} = \frac{\hat{a}^T W \hat{b}}{\sqrt{(\hat{a}^T W \hat{a}) (\hat{b}^T W \hat{b})}},\]

with \(\hat{a} = a - \bar{a}\) the centered vectors. The numerator is \(\sum W \times (\hat{a} \otimes \hat{b})\): every pair of entries is compared, weighted by the proximity of the two nodes. With \(W = I\) this is the Pearson correlation.

The default weights are \(W = e^{-k \Omega}\) (entrywise), with \(\Omega\) the effective resistance matrix (see effective_resistance()). The correlation is real and in \([-1, 1]\) when \(W\) is positive definite on vectors with zero sum, which holds for any \(k > 0\) when \(\Omega\) is a metric of negative type: true for undirected, "chung" and "magnetic" Laplacians, not guaranteed for "out". k sets how fast proximity decays: as \(k \to 0\) all pairs weigh the same, as \(k \to \infty\) the result tends to the Pearson correlation. Choose it relative to the scale of \(\Omega\): the "chung" Laplacian is scaled by the stationary distribution, which sums to 1, so its resistances are about n times larger and need a k about n times smaller.

\(W\) can be passed precomputed (an n by n tensor), to reuse it across calls; it is then used as given, and k, lpinv and the Laplacian arguments are ignored. Otherwise it is computed from lpinv (cached dense pseudoinverse) or from scratch, in place, needing one n by n matrix besides lpinv.

Parameters:

  • net – A Network.

  • a – Node attribute (position in net.node_attributes or name), or vector of length n (numpy.ndarray or torch.Tensor).

  • b – Second node vector, same modalities as a.

  • component – Index of the component (0 is the largest), or None for all components. With None, vectors, W and lpinv are given as lists with one entry per component.

  • W – Precomputed weight matrix, or None.

  • k – Scale of the effective resistance in \(W = e^{-k \Omega}\).

  • lpinv – Cached dense pseudoinverse of the Laplacian, or None.

  • weight – Name of the edge attribute used as edge weight, or None for unit weights.

  • kind – Laplacian of directed networks: "out", "magnetic" or "chung".

  • q – Charge of the magnetic Laplacian.

  • alpha – Teleportation probability of the Chung Laplacian.

Returns:

Correlation, or list of correlations if component is None. NaN for constant vectors or missing values.

Example:

import torch
import graphoskop as gsk

net = gsk.load_network("edges.tsv", "nodes.tsv")
r = gsk.network_correlation(net, "age", "height")
W = torch.exp(-2 * gsk.effective_resistance(net))         # cached weights, k = 2
r = gsk.network_correlation(net, "age", "height", W = W)
graphoskop.network_entropy(net, a, component=0, W=None, k=1, lpinv=None, weight=None, kind='out', q=0.25, alpha=0.15)

Network entropy of a node vector interpreted as a probability distribution:

\[H(p) = -\sum_i p_i \log (W p)_i,\]

with \(p = a / \sum_i a_i\) and node similarities \(W = e^{-k \Omega}\) (entrywise), \(\Omega\) being the effective resistance matrix (see effective_resistance()). \((W p)_i\) is the probability mass near node \(i\), so mass spread over distant nodes gives a high entropy and mass concentrated on nearby nodes a low one. With \(W = I\) this is the Shannon entropy. It is the order 1 similarity-sensitive diversity of Leinster and Cobbold (2012). Nodes with \(p_i = 0\) add nothing to the sum.

a must be a probability mass up to normalization: a ValueError is raised if it has negative entries or sums to zero.

\(W\) can be passed precomputed (an n by n tensor), to reuse it across calls (for instance the one of network_correlation()); it is then used as given, and k, lpinv and the Laplacian arguments are ignored. Otherwise it is computed from lpinv (cached dense pseudoinverse) or from scratch. As for network_correlation(), choose k relative to the scale of \(\Omega\).

Parameters:

  • net – A Network.

  • a – Node attribute (position in net.node_attributes or name), or vector of length n (numpy.ndarray or torch.Tensor), with non negative entries.

  • component – Index of the component (0 is the largest), or None for all components. With None, vectors, W and lpinv are given as lists with one entry per component.

  • W – Precomputed similarity matrix, or None for \(e^{-k \Omega}\).

  • k – Scale of the effective resistance in \(W = e^{-k \Omega}\).

  • lpinv – Cached dense pseudoinverse of the Laplacian, or None.

  • weight – Name of the edge attribute used as edge weight, or None for unit weights.

  • kind – Laplacian of directed networks: "out", "magnetic" or "chung".

  • q – Charge of the magnetic Laplacian.

  • alpha – Teleportation probability of the Chung Laplacian.

Returns:

Entropy (in nats), or list of entropies if component is None. NaN for missing values.

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv", "nodes.tsv")
h = gsk.network_entropy(net, "population")
graphoskop.network_variance(net, a, component=0, R=None, lpinv=None, weight=None, kind='out', q=0.25, alpha=0.15)

Network variance of a node vector interpreted as a probability distribution (Devriendt, Martin-Gutierrez and Lambiotte, 2022, https://arxiv.org/abs/2008.09155):

\[\mathrm{var}(p) = \frac{1}{2} \sum_{i, j} p_i p_j d^2(i, j) = \frac{1}{2} p^T \Omega p,\]

with \(p = a / \sum_i a_i\), \(\Omega\) the effective resistance matrix (see effective_resistance()) and \(d = \sqrt{\Omega}\) the square root effective resistance distance, as in the paper. On an undirected network, Kemeny’s constant is \(\kappa = 2 m \, \mathrm{var}(\pi)\), with \(\pi\) the stationary distribution of the random walk and \(m\) the total edge weight, and the Kirchhoff index is \(n^2 \, \mathrm{var}(u / n)\), with \(u / n\) the uniform distribution.

a must be a probability mass up to normalization: a ValueError is raised if it has negative entries or sums to zero.

\(\Omega\) can be passed precomputed as R, to reuse it across calls; it is then used as given and left unchanged, and lpinv and the Laplacian arguments are ignored. Otherwise it is computed from lpinv (cached dense pseudoinverse) or from scratch.

Parameters:

  • net – A Network.

  • a – Node attribute (position in net.node_attributes or name), or vector of length n (numpy.ndarray or torch.Tensor), with non negative entries.

  • component – Index of the component (0 is the largest), or None for all components. With None, vectors, R and lpinv are given as lists with one entry per component.

  • R – Precomputed effective resistance matrix, or None.

  • lpinv – Cached dense pseudoinverse of the Laplacian, or None.

  • weight – Name of the edge attribute used as edge weight, or None for unit weights.

  • kind – Laplacian of directed networks: "out", "magnetic" or "chung".

  • q – Charge of the magnetic Laplacian.

  • alpha – Teleportation probability of the Chung Laplacian.

Returns:

Variance, or list of variances if component is None. NaN for missing values.

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv", "nodes.tsv")
v = gsk.network_variance(net, "population")
R = gsk.effective_resistance(net)
v = gsk.network_variance(net, "income", R = R)       # cached resistances
graphoskop.pairwise_generalized_euclidean(net, component=0, lpinv=None, sparse=None, weight=None, kind='out', q=0.25, alpha=0.15, output_device=None, output_dtype=torch.float64)

Generalized Euclidean distances between all pairs of node attributes.

Works like generalized_euclidean(), applied to every pair of columns of node_attr. Instead of one product with \(L^+\) per pair, it computes \(Y = L^+ X\) once for the k attributes \(X\) and then all squared distances from the k by k matrix \(G = X^H Y\), as \(G_{ii} + G_{jj} - G_{ij} - G_{ji}\). The attributes are first centered across attributes for each node, which leaves the distances unchanged and reduces rounding errors. The cost is k products with \(L^+\) (or k solves, run together) plus an n by k by k product.

\(L^+\) is used as given in lpinv (dense tensor or solver). If lpinv is None, a solver is built when sparse is True or None (the default, usually faster, since only k solves are needed), and the dense pseudoinverse when sparse is False.

Parameters:

  • net – A Network.

  • component – Index of the component (0 is the largest), or None for all components. With None, lpinv is given as a list with one entry per component.

  • lpinv – Cached pseudoinverse or solver, or None.

  • sparse – Laplacian solver (True or None) or dense pseudoinverse (False) when lpinv is None.

  • weight – Name of the edge attribute used as edge weight, or None for unit weights.

  • kind – Laplacian of directed networks: "out", "magnetic" or "chung".

  • q – Charge of the magnetic Laplacian.

  • alpha – Teleportation probability of the Chung Laplacian.

  • output_device – Device of the result, None for the device of the component. With "cpu" the computation still runs on the device of the component (e.g. the GPU), one block of rows at a time, and only the result is kept on the CPU: useful when the k by k result does not fit in GPU memory.

  • output_dtype – Dtype of the result. torch.float32 halves its memory (a k by k float64 matrix needs \(8 k^2\) bytes, 3.2 GB for 20,000 attributes); the computation itself stays in double precision.

Returns:

k by k tensor, rows and columns ordered as net.node_attributes, or a list of them if component is None. NaN where the quadratic form is negative (possible only for the "out" Laplacian) or for attributes with missing values.

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv", "nodes.tsv")
D = gsk.pairwise_generalized_euclidean(net, weight = "weight")
D = gsk.pairwise_generalized_euclidean(net, weight = "weight", output_device = "cpu")
graphoskop.pairwise_network_correlation(net, component=0, W=None, k=1, lpinv=None, weight=None, kind='out', q=0.25, alpha=0.15, output_device=None, output_dtype=torch.float64)

Network Pearson correlations between all pairs of node attributes.

Works like network_correlation(), applied to every pair of columns of node_attr. With \(\hat{X}\) the centered attributes, it computes \(G = \hat{X}^T W \hat{X}\) with a single product of \(W\) with the n by k matrix \(\hat{X}\), and then all correlations as \(G_{ij} / \sqrt{G_{ii} G_{jj}}\). \(W\) is computed once, or reused if given.

Parameters:

  • net – A Network.

  • component – Index of the component (0 is the largest), or None for all components. With None, W and lpinv are given as lists with one entry per component.

  • W – Precomputed weight matrix, or None for \(e^{-k \Omega}\).

  • k – Scale of the effective resistance in \(W = e^{-k \Omega}\).

  • lpinv – Cached dense pseudoinverse of the Laplacian, or None.

  • weight – Name of the edge attribute used as edge weight, or None for unit weights.

  • kind – Laplacian of directed networks: "out", "magnetic" or "chung".

  • q – Charge of the magnetic Laplacian.

  • alpha – Teleportation probability of the Chung Laplacian.

  • output_device – Device of the result, None for the device of the component. With "cpu" the computation still runs on the device of the component (e.g. the GPU), one block of rows at a time, and only the result is kept on the CPU: useful when the k by k result does not fit in GPU memory.

  • output_dtype – Dtype of the result. torch.float32 halves its memory (a k by k float64 matrix needs \(8 k^2\) bytes, 3.2 GB for 20,000 attributes); the computation itself stays in double precision.

Returns:

k by k tensor, rows and columns ordered as net.node_attributes, or a list of them if component is None. NaN for constant attributes or missing values.

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv", "nodes.tsv")
C = gsk.pairwise_network_correlation(net, weight = "weight")
C = gsk.pairwise_network_correlation(net, weight = "weight", output_device = "cpu")
