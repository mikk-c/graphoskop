Shortest paths

Shortest paths between the nodes of a network.

Paths are computed on the CPU with Dijkstra’s algorithm (breadth first search for unit lengths) from scipy.sparse.csgraph, whatever the device of the network: on sparse networks this needs \(O(m + n \log n)\) work per source, while GPU alternatives either need \(O(n^3)\) work (Floyd-Warshall) or synchronize at every step of the search. Searches from many sources are split across processes, since scipy’s implementation does not release the Python global interpreter lock and so cannot run in parallel threads. The processes are started by the first parallel search and kept, idle, for the next ones until Python exits (or until a search asks for a different n_jobs), so their start, which takes seconds where processes are spawned and import the library again, is paid once per session and not at every call. Matrices of lengths are returned on the device of the component. On platforms where new processes do not fork (the default on Windows and macOS, and on Linux from Python 3.14), scripts that compute all pairs on large components must protect their entry point with if __name__ == "__main__":, and n_jobs = 1 turns the processes off.

Edge lengths are the values of an edge attribute (weight), or 1. For edge attributes that measure affinity, as the weights used by the Laplacians do, inverse = True uses their reciprocal as length. Parallel edges keep the shortest length; lengths must be non negative. Directed networks are searched along edge directions. Nodes are given by their input ids; nodes in different components are not connected.

In multilayer networks, paths run on the supra-graph: couplings and other interlayer edges are edges like the others, so changing layer is a step of the path, with the length of the coupling (1 with unit lengths). Couplings store weights read as affinities by the Laplacians (the larger, the easier to change layer), so use inverse = True for lengths consistent with them; a coupling of length 0 makes changing layer free. Nodes are copies (entity, layer), and paths are lists of copies, showing where they change layer. An entity can be given instead of a copy: then all its copies are origins (or destinations), and the shortest path from (or to) any of them is used.

graphoskop.all_pairs_shortest_path_lengths(net, component=0, weight=None, inverse=False, matrix=True, n_jobs=None)

Lengths of the shortest paths between all pairs of nodes of a component.

Parameters:

  • net – A Network.

  • component – Index of the component (0 is the largest), or None for all components.

  • weight – Name of the edge attribute used as edge length, or None for unit lengths.

  • inverse – Use the reciprocal of the edge attribute as length.

  • matrix – Return an n by n tensor, in the same format as effective_resistance() (rows and columns ordered by internal node index, dtype of the edge attributes, device of the component; inf where there is no path). If False, return a dictionary from each source id to the dictionary of its lengths (as in single_source_shortest_path_lengths()).

  • n_jobs – Number of processes for the searches, None for all CPUs.

Returns:

Lengths, or a list of them if component is None.

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv")
P = gsk.all_pairs_shortest_path_lengths(net, weight = "weight", inverse = True)
c, i = net.node_map["alice"]
c, j = net.node_map["carol"]
P[i, j]                                                  # if both are in component 0
graphoskop.all_pairs_shortest_paths(net, component=0, weight=None, inverse=False, n_jobs=None)

Shortest paths between all pairs of nodes of a component.

The number of paths grows with the square of the number of nodes, so this is meant for small components; for large ones, use all_pairs_shortest_path_lengths() or single_source_shortest_paths() on the sources of interest.

Parameters:

  • net – A Network.

  • component – Index of the component (0 is the largest), or None for all components.

  • weight – Name of the edge attribute used as edge length, or None for unit lengths.

  • inverse – Use the reciprocal of the edge attribute as length.

  • n_jobs – Number of processes for the searches, None for all CPUs.

Returns:

Dictionary from each source id to the dictionary of its paths (as in single_source_shortest_paths()), or a list of them if component is None.

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv")
paths = gsk.all_pairs_shortest_paths(net)
paths["alice"]["carol"]                                  # ['alice', 'bob', 'carol']
graphoskop.diameter(net, component=0, weight=None, inverse=False, n_jobs=None, lengths=None)

Diameter: the length of the longest shortest path, \(\max_{s, t} d(s, t)\) over the pairs connected by a path.

Paths are those of the rest of the module (weight and inverse, directions followed in directed networks, the supra-graph in multilayer networks); with unit lengths the diameter is in number of edges. Pairs without a path are left out: with component = None the result is the largest diameter over the components, and in directed networks the longest shortest path between pairs where one reaches the other (NetworkX instead raises an error unless the network is strongly connected). A single node has diameter 0.

In undirected networks the diameter is found exactly with BoundingDiameters (Takes and Kosters, 2011): each search from a node bounds the eccentricities (largest lengths) of all the others, and searches stop when the lower and upper bounds of the diameter meet, usually after a handful of searches instead of one per node. Directed networks search from every node, in blocks and processes as all_pairs_shortest_path_lengths() (n_jobs). With lengths (from all_pairs_shortest_path_lengths() with the same component, weight and inverse) nothing is searched.

Parameters:

  • net – A Network.

  • component – Index of the component (0 is the largest), or None for all components.

  • weight – Name of the edge attribute used as edge length, or None for unit lengths.

  • inverse – Use the reciprocal of the edge attribute as length.

  • n_jobs – Number of processes for the searches of directed networks, None for all CPUs.

  • lengths – Precomputed lengths: a tensor for one component, or the list of tensors of all_pairs_shortest_path_lengths(net, None, ...) for component = None.

Returns:

The diameter: an int with unit lengths, a float otherwise.

Raises:

ValueError – If some lengths are negative or NaN, or lengths does not match.

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv")
gsk.diameter(net)                                        # largest component, in edges
gsk.diameter(net, weight = "distance")                   # weighted
graphoskop.shortest_path(net, source, target, weight=None, inverse=False)

Shortest path between two nodes.

Parameters:

  • net – A Network.

  • source – Input id of the origin (or entity, in multilayer networks).

  • target – Input id of the destination (or entity, in multilayer networks).

  • weight – Name of the edge attribute used as edge length, or None for unit lengths.

  • inverse – Use the reciprocal of the edge attribute as length.

Returns:

List of input node ids from source to target, empty if there is no path. With entities, the shortest of the paths between any of their copies (ties: the first component, then the first copy in layer order).

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv")
gsk.shortest_path(net, "alice", "carol")                 # ['alice', 'bob', 'carol']

net = gsk.load_network("multiplex.tsv", multilayer = True, coupling = "all")
gsk.shortest_path(net, "alice", "carol")                 # [('alice', 'work'), ('bob', 'work'), ('bob', 'home'), ('carol', 'home')]

graphoskop.shortest_path_length_distribution(net, component=None, samples=None, seed=0, n_jobs=None, lengths=None)

Distribution of the lengths of shortest paths, in number of edges: how many pairs of nodes are joined by a shortest path of each length.

In undirected networks pairs are unordered, so the count for length 1 is the number of edges (parallel edges once, self loops left out); in directed networks pairs are ordered (a path from the source to the target), so the count for length 1 is the number of distinct directed edges. Pairs without a path (in different components, or not reachable in directed networks) are not counted. Lengths are in number of edges, whatever the edge attributes. In multilayer networks paths run on the supra-graph, where changing layer along a coupling is one edge.

Lengths from each block of sources are counted as soon as they are found, so memory stays at a few rows of lengths, with searches split across processes for large work (see the module description for n_jobs). samples uses only that many random source nodes (drawn uniformly from the nodes considered, seed for reproducibility) and scales the counts up to all sources, as an estimate. With lengths (computed by all_pairs_shortest_path_lengths() with unit lengths, weight = None, for the same component) nothing is searched again.

Parameters:

  • net – A Network.

  • component – Index of the component (0 is the largest), or None for the whole network.

  • samples – Number of random source nodes, or None for all nodes (exact).

  • seed – Seed of the random sources.

  • n_jobs – Number of processes for the searches, None for all CPUs.

  • lengths – Precomputed lengths: a tensor for one component, or the list of tensors of all_pairs_shortest_path_lengths(net, None) for component = None.

Returns:

pandas.DataFrame with columns length (1, 2, …) and count (integer, or float when estimated with samples), one row per length that occurs.

Raises:

ValueError – If lengths does not match.

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv")
dist = gsk.shortest_path_length_distribution(net)
dist.loc[dist.length == 1, "count"]          # the number of edges
gsk.shortest_path_length_distribution(net, samples = 1000)   # estimate on large networks

Lengths of the shortest paths from one node to every node it reaches.

Parameters:

  • net – A Network.

  • source – Input id of the origin (or entity, in multilayer networks: lengths from the nearest of its copies, 0 for the copies themselves).

  • weight – Name of the edge attribute used as edge length, or None for unit lengths.

  • inverse – Use the reciprocal of the edge attribute as length.

Returns:

Dictionary from the input id of each reachable node to its length.

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv")
lengths = gsk.single_source_shortest_path_lengths(net, "alice")
graphoskop.single_source_shortest_paths(net, source, weight=None, inverse=False)

Shortest paths from one node to every node it reaches.

Parameters:

  • net – A Network.

  • source – Input id of the origin (or entity, in multilayer networks: paths from the nearest of its copies, each copy reaching itself with a path of one node).

  • weight – Name of the edge attribute used as edge length, or None for unit lengths.

  • inverse – Use the reciprocal of the edge attribute as length.

Returns:

Dictionary from the input id of each reachable node to its path (list of input ids).

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv")
paths = gsk.single_source_shortest_paths(net, "alice")
paths["carol"]                                           # ['alice', 'bob', 'carol']

The average shortest path length is average_shortest_path_length(), in Network statistics, and centralities based on shortest paths are in Centrality; all of them accept the lengths computed by all_pairs_shortest_path_lengths().
