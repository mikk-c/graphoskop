Communities

Communities: quality of partitions of the nodes into groups, and maximal cliques (community discovery algorithms will come here too).

A partition assigns every node to a community, given either as the name of a node attribute (numeric or qualitative; its values are community labels) or as labels in a dictionary (or pandas.Series) indexed by input node id, or in a sequence ordered as the nodes of the network (component by component, by internal index: np.concatenate(net.node_ids)). Labels can be of any type; only equality matters. In multilayer networks every copy (entity, layer) has its own label, so a community can span several layers. A node in several communities has a list, tuple or set of labels (see Several values per node: overlapping communities): the partition is then a cover, for which modularity() is the overlapping modularity.

import graphoskop as gsk

net = gsk.load_network("edges.tsv", "nodes.tsv")         # nodes.tsv has a "party" column
gsk.modularity(net, "party")                             # partition from a node attribute
gsk.modularity(net, {"alice": 0, "bob": 0, "carol": 1})  # or from labels by node id
cliques = gsk.maximal_cliques(net)                       # node sets of the cliques of 3+ nodes

Cliques

graphoskop.maximal_cliques(net, component=None, min_size=3, batch_size=4194304)

Maximal cliques: sets of nodes all joined to each other, not contained in a larger such set.

Only non-trivial cliques are returned, with at least min_size nodes (3 by default: single nodes and edges are left out). Edges are taken as undirected and unweighted (in directed networks, two nodes are joined if there is an edge in either direction), self loops and parallel edges are ignored. In multilayer networks only intra-layer edges count, so cliques are within a layer (couplings would make the copies of each entity a clique).

Edges in no triangle cannot be in a clique of 3 or more nodes, so they are removed first, with the triangle enumeration of global_clustering() (on the device of the network); maximal cliques are then listed by Bron-Kerbosch with pivoting (Tomita et al., 2006) on what remains, on the CPU. The number of maximal cliques can grow exponentially with the size of dense networks.

Parameters:

  • net – A Network.

  • component – Index of the component (0 is the largest), or None for the whole network.

  • min_size – Smallest clique returned (at least 3).

  • batch_size – Number of 2-paths expanded at once in the triangle enumeration.

Returns:

List of arrays of input node ids, one per clique, largest first.

Raises:

ValueError – If min_size is below 3.

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv")
cliques = gsk.maximal_cliques(net)
len(cliques[0])                          # size of the largest clique
big = gsk.maximal_cliques(net, min_size = 5)

Quality of a partition

graphoskop.modularity(net, partition, weight=None, resolution=1, component=None, overlap='shen')

Modularity of a partition of the nodes into communities: the weight of the edges within communities minus its expected value in a null model that keeps the degrees.

The variant follows the kind of network:

  • undirected (Newman, 2006): \(Q = \sum_c \left[ \frac{L_c}{m} - \gamma \left( \frac{K_c}{2m} \right)^2 \right]\), with \(L_c\) the weight of the edges within community \(c\), \(K_c\) the sum of the degrees (strengths) of its nodes and \(m\) the total edge weight;

  • directed (Leicht and Newman, 2008): \(Q = \sum_c \left[ \frac{L_c}{m} - \gamma \frac{K^{out}_c K^{in}_c}{m^2} \right]\);

  • bipartite (Barber, 2007): the null model only joins nodes of different types, \(Q = \sum_c \left[ \frac{L_c}{m} - \gamma \frac{K^{(0)}_c K^{(1)}_c}{m^2} \right]\), with \(K^{(0)}_c\) and \(K^{(1)}_c\) the degrees of its nodes of each type (directed bipartite networks use the directed variant);

  • multilayer (Mucha et al., 2010): each layer has its own null model (its own \(m_l\) and degrees, with \(\gamma\) the same for all layers), and couplings and other interlayer edges add their weight when both ends are in the same community, without a null model term: \(Q = \frac{1}{2\mu} \sum \left[ (A_{ij} - \gamma \frac{k_i k_j}{2 m_l}) \delta_{l_i l_j} + C_{ij} \right] \delta(g_i, g_j)\), with \(2\mu\) the total weight of intra-layer and interlayer edges (both directions); directed networks use the directed null model in each layer. With one layer and no interlayer edges this is the ordinary modularity.

Communities can overlap: a node in several communities has a list, tuple or set of labels (see Networks and their attributes). Overlapping modularity then weighs every pair of nodes by their belonging to each community they share, in the same variants (directed, bipartite, multilayer), following overlap:

  • "shen" (Shen et al., 2009): a node in \(O_i\) communities belongs to each with \(a_{ic} = 1 / O_i\), and \(Q = \frac{1}{2m} \sum_c \sum_{ij} \left[ A_{ij} - \gamma \frac{k_i k_j}{2m} \right] a_{ic} a_{jc}\). Without overlaps this is the modularity above;

  • "nicosia" (Nicosia et al., 2009): belonging \(\alpha_{ic} = 1 / O_i\) (0 outside the community) enters through \(g(\alpha) = 1 / (1 + e^{-(2 p \alpha - p)})\), with \(p = 30\) as in the paper, and \(Q = \frac{1}{2m} \sum_c \sum_{ij} \left[ g_{ic} g_{jc} A_{ij} - \gamma G_c^2 \frac{g_{ic} k_i g_{jc} k_j}{2m} \right]\), with \(G_c\) the mean of \(g_{jc}\) over all nodes (of the layer). It is sharper than Shen’s (a node in 3 communities barely belongs to any) and, unlike it, it differs from the classic modularity even without overlaps (its null model shrinks by \(G_c^2\)); it is used whenever asked.

A self loop counts once in \(L_c\) and twice in the degree of its node (in undirected networks), and parallel edges add up, as in NetworkX and igraph. resolution (\(\gamma\)) above 1 favors smaller communities. Modularity is at most 1; it is 0 for a single community containing everything (with \(\gamma = 1\)). NaN if there are no edges. The computation is one pass over the edges, on the device of the network.

Parameters:

  • net – A Network.

  • partition – The communities: name of a node attribute, dictionary (or Series) from node id to label, or sequence of labels in network wide node order (see the module description).

  • weight – Edge attribute used as weight, or None for unit weights.

  • resolution – Resolution \(\gamma\).

  • component – Index of the component (0 is the largest), or None for the whole network.

  • overlap – Overlapping modularity: "shen" (used only if some node is in several communities; otherwise it is the classic modularity) or "nicosia".

Returns:

The modularity, a float.

Raises:

  • ValueError – If a node has no label, a sequence has the wrong length, or overlap is not valid.

  • KeyError – If there is no such node or edge attribute.

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv", "nodes.tsv")            # nodes.tsv has a "party" column
gsk.modularity(net, "party")
gsk.modularity(net, {"alice": 0, "bob": 0, "carol": 1, ...})
gsk.modularity(net, labels, weight = "weight", resolution = 0.5)
gsk.modularity(net, {"alice": [0, 1], "bob": 0, "carol": 1, ...})   # alice in both communities
gsk.modularity(net, "community", overlap = "nicosia")
