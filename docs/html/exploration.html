Exploration

Graph exploration: breadth first and depth first search from a node.

Both return the nodes reached from the source, in the order they are visited, with the node they were reached from (their parent in the search tree) and their depth in that tree; in breadth first search the depth is the number of edges of a shortest path from the source. Only the component of the source is explored. Searches run on the CPU with scipy.sparse.csgraph (compiled code, \(O(n + m)\)), whatever the device of the network, as in shortest_paths. Neighbors are visited in order of internal index; parallel edges and self loops do not matter.

In directed networks direction chooses the edges followed: "out" (along their direction), "in" (against it) or "both". In multilayer networks the search runs on the supra-graph (couplings are edges like the others), and an entity given as source stands for all its copies, which are all searched from at once (as one source linked to each of them).

import graphoskop as gsk

net = gsk.load_network("edges.tsv")
gsk.bfs(net, "alice")                     # node, depth, parent, in visit order
gsk.bfs(net, "alice", max_depth = 2)      # neighborhood up to two edges away
gsk.dfs(net, "alice")
graphoskop.bfs(net, source, direction='out', max_depth=None)

Breadth first search: the nodes reachable from source, by increasing number of edges from it (see the module description).

Parameters:

  • net – A Network.

  • source – Starting node (input id, internal id (component, index), or entity in multilayer networks).

  • direction – In directed networks, "out", "in" or "both"; ignored otherwise.

  • max_depth – Only nodes at most this many edges away, or None for all.

Returns:

pandas.DataFrame in visit order, with columns node (input id), depth (number of edges from the source, 0 for the source) and parent (input id of the node it was reached from, missing for the source).

Raises:

  • ValueError – If direction is not valid.

  • KeyError – If there is no such node.

Example:

import graphoskop as gsk

net = gsk.load_network("edges.tsv")
tree = gsk.bfs(net, "alice")
friends_of_friends = tree.node[tree.depth == 2]
gsk.bfs(net, "alice", max_depth = 1)          # alice and her neighbors
graphoskop.dfs(net, source, direction='out')

Depth first search: the nodes reachable from source, each followed by all the nodes reached through it before backtracking (preorder; see the module description).

Parameters:

  • net – A Network.

  • source – Starting node (input id, internal id (component, index), or entity in multilayer networks).

  • direction – In directed networks, "out", "in" or "both"; ignored otherwise.

Returns:

pandas.DataFrame in visit order, with columns node (input id), depth (depth in the search tree, 0 for the source) and parent (input id of the node it was reached from, missing for the source).

Raises:

  • ValueError – If direction is not valid.

  • KeyError – If there is no such node.

Example:

tree = gsk.dfs(net, "alice")
tree.node.tolist()                            # visit order
